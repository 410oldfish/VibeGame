# VibeGame Godot Combat Prototype

This is a small Godot 4 project extracted from the Unity VibeGame combat direction.

Current scope:

- Axial hex board.
- Player turn with energy, armor, deck, hand, discard, and card play.
- Enemy intent preview, enemy movement, enemy attacks, and turn cycling.
- Victory, defeat, and restart loop.

Open `project.godot` in Godot 4 and run the main scene.
