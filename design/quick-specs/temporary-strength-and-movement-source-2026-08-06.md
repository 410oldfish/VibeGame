# Quick Design Spec：临时力量与移动来源

**类型**：Addition

**系统**：战斗状态、移动结算、战士移动体系

**GDD Reference**：`design/策划案/状态效果系统/Foundation-增益状态.md`、`design/策划案/职业系统/战士/Feature-战士体系-移动.md`

**日期**：2026-08-06
**实现范围**：设计文档、运行时代码、卡牌资产与自动化测试

## Change Summary

临时力量改为由统一入口授予，并明确区分“当前回合末”与“本场战斗末”两种生命周期；所有移动同时标记为主动或强制来源。踏风预备改为本回合每次成功主动移动触发，支持同回合多张叠加。

## Motivation

旧实现由各来源直接修改力量并手工登记待清除值，地形拾取物与消耗品生命周期容易互相误扣。移动结算也无法可靠区分单位自身移动和外部位移，使踏风、游斗等战士被动可能被击退或拉拽错误触发。

## Design Delta

旧规则：

> 临时力量共用单一待清除计数；踏风只在本回合第一次位移触发；移动来源依赖调用位置隐式判断。

新规则：

- 临时力量来源必须指定 `UntilEndOfTurn` 或 `UntilEndOfBattle`。
- 当前回合结束只移除回合制临时力量；战斗结束或重置清除全部临时力量。
- 主动移动由单位自身通过体力、卡牌、技能或意图发起；强制移动由其他单位、状态或环境造成。
- 只有成功且距离至少 1 格的主动移动触发战士位移事件、踏风与游斗。
- 主动和强制移动都必须结算路径地形、拾取物与陷阱。

## New Rules / Values

| 来源 | 临时力量 | 生命周期 |
| --- | ---: | --- |
| 踏风预备 | 每次成功主动移动获得卡牌实例的有效数值；基础为 2 | 当前回合末 |
| 力量药水 | 3 | 当前回合末 |
| 力量仪式 | 3 | 当前回合末 |
| 可视区拾取物·临时力量 | 2 | 本场战斗末 |

踏风预备按一次成功移动动作触发一次，不按格数触发。多张踏风预备将各自的有效数值累加；失败、零距离或强制移动不触发。

## Affected Systems

| 系统 | 影响 | 动作 |
| --- | --- | --- |
| 单位状态 | 临时力量拆分双生命周期 | 新增统一获得和清除入口 |
| 移动结算 | 所有移动显式携带来源 | 统一移动收尾与路径触发 |
| 战士移动体系 | 踏风与游斗只监听主动移动 | 更新卡牌效果与事件规则 |
| 消耗品 | 药水、仪式迁移到回合制临时力量 | 移除调用方手工计数 |
| 地形拾取物 | 临时力量持续至战斗结束 | 主动或强制进入均可拾取 |
| 状态展示 | 永久力量与临时力量分栏 | Tooltip 显示两类到期值 |

## Acceptance Criteria

- [x] 永久、回合制临时和战斗制临时力量可独立累计与清除。
- [x] 诅咒阻止增益时不产生待清除计数。
- [x] 单张踏风后两次成功主动移动累计获得两次收益，多张踏风数值叠加。
- [x] 强制移动不触发踏风、游斗或战士 `位移` 事件。
- [x] 强制移动仍触发路径地形、拾取物和陷阱。
- [x] 状态栏拆分永久力量和临时力量，顶部力量保持显示实际攻击总值。
- [x] 已删除的幸运、闪避、残废、诱惑、混乱、冰冻未恢复到已投入登记。
