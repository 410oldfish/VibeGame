## Summary

定义章节路线地图、节点类型标识与路线选择的 UI 与交互。MVP 为 **单人** 路线选择；本文件不定义路线结构或节点规则。

## 1. 信息架构

[待 UX 设计]

需展示的信息（来自 Feature 层文档接口）：

- `10×4` 纵向路线与当前进度。
- MVP 节点类型可识别标识：**普通战斗**、**精英战斗**、**首领**、**商店**、**休息处（火堆）**、**特殊事件**。
- 下一可选节点与确认状态（MVP 单人确认即可）。
- 可选：下一场战斗地形标签预览（与事件 E04 联动，见 [`Feature-事件收益设计.md`](../奖励成长系统/Feature-事件收益设计.md)）。

## 2. 交互流程

[待 UX 设计]

MVP 最小流程：

1. 地图高亮可达下一节点 → 玩家点击选择 → 确认进入。
2. 进入战斗/商店/火堆/事件后，结算完成返回地图并更新进度。
