# 战士武器系统

> **Layer**：Feature  
> **Priority**：MVP  
> **所属职业**：[`Feature-战士.md`](Feature-战士.md)  
> **设计规范**：[`../../设计规范/Foundation-卡牌与角色五维设计.md`](../../设计规范/Foundation-卡牌与角色五维设计.md) §8.2~§8.3

## Summary

战士专属 **装备武器** 规则：持握 × 锋型四类；与卡牌 **武器需求** 联动。**切换武器不算位移事件**（见 [`Feature-战士事件节点.md`](Feature-战士事件节点.md)）；切换由 [`Feature-战士过渡卡牌.md`](Feature-战士过渡卡牌.md)「换刃」或 UI 操作触发。

## 1. 武器分类

| 代码 | 名称 | 持握 | 锋型 | 战术身份 |
| --- | --- | --- | --- | --- |
| `1H-B` | 单手钝器 | 单手 | 钝器 | 格挡、稳固 |
| `1H-S` | 单手锐器 | 单手 | 锐器 | 快攻、易伤 |
| `2H-B` | 双手钝器 | 双手 | 钝器 | 猛冲/震地、撞墙 |
| `2H-S` | 双手锐器 | 双手 | 锐器 | 流血压制 |

## 2. 装备规则

| 规则 | 说明 |
| --- | --- |
| 槽位 | **主手** + **副手**；`2H-*` 占用双手 |
| 切换 | 每回合可多次切换；每次 **1 体力**；**不触发 `位移` 事件** |
| 开局 | **训练木棒（2H-B）** |
| 被动 | 当前武器类别被动常驻；切换后立即更换 |

### 2.1 类别被动（MVP）

| 类别 | 被动 |
| --- | --- |
| `1H-B` | 格挡牌额外 **+2 格挡** |
| `1H-S` | 攻击对 **易伤** 目标 **+2 伤** |
| `2H-B` | 碰撞/撞墙链收益 **+25%**（乘 M(n) 前） |
| `2H-S` | 攻击额外 **+1 流血** |

## 3. MVP 武器条目

| 武器名 | 类别 | 解锁 | 简述 |
| --- | --- | --- | --- |
| 训练木棒 | `2H-B` | 初始 | 猛冲/震地 |
| 行刑巨斧 | `2H-S` | 奖励/商店 | 流血 |
| 战锤 | `2H-B` | 奖励/商店 | 撞墙 +2（固定） |
| 短剑 | `1H-S` | 奖励/商店 | 易伤快攻 |
| 钉头锤 | `1H-B` | 奖励/商店 | 格挡后下次攻击 +3 伤 |

## 4. 与卡牌体系关系

| 体系 | 关系 |
| --- | --- |
| 减益 | 不限；燃烧与持握无关 |
| 塞牌 | 不限 |
| 卖血 | 不限 |
| 位移 | 部分收束需 `2H-B`；**位移事件 = 移动**，非切换 |
