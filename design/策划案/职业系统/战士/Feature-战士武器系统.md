# 战士武器系统

> **Layer**：Feature  
> **Priority**：MVP  
> **所属职业**：[`Feature-战士.md`](Feature-战士.md)  
> **设计规范**：[`../../设计规范/Foundation-卡牌与角色五维设计.md`](../../设计规范/Foundation-卡牌与角色五维设计.md) §8.2~§8.3

## Summary

战士专属 **装备武器** 规则：按 **持握（单手/双手）× 锋型（钝器/锐器）** 分为四类；与卡牌 **武器需求** 标签联动。**武器切换体系** 鼓励频繁切换以换取移动与收束收益。旧「斧/锤/剑切换技能」由本系统取代。

## 1. 武器分类

| 代码 | 名称 | 持握 | 锋型 | 战术身份 |
| --- | --- | --- | --- | --- |
| `1H-B` | 单手钝器 | 单手 | 钝器 | 格挡、反击、稳固；副手可持盾或空 |
| `1H-S` | 单手锐器 | 单手 | 锐器 | 快攻、易伤、低费连击 |
| `2H-B` | 双手钝器 | 双手 | 钝器 | 冲撞、破墙、撞墙爆发（切换流 **收束形态** 之一） |
| `2H-S` | 双手锐器 | 双手 | 锐器 | 横扫、流血、中距压制 |

**MVP 实现四类武器各 1 把**（见 §3）；卡牌可声明 `武器需求: 2H-B` 等，未装备时 **无法打出**（灰显）。

## 2. 装备规则

| 规则 | 说明 |
| --- | --- |
| 槽位 | **主手** + **副手**；装备 `2H-*` 时占用双手，副手清空 |
| 切换 | 每回合可 **多次** 切换背包内已解锁武器；每次切换不消耗能量，消耗 **1 体力** |
| 开局 | 默认装备 **训练木棒（2H-B）**；副手空 |
| 解锁 | 战斗奖励/商店可获 **武器牌** 或 **武器解锁条目**，加入本局可用武器列表 |
| 被动 | 当前武器 **类别被动** 常驻生效；切换后被动 **立即** 切换为新武器 |
| 切换事件 | 每次成功切换记 1 次 **`切换` 事件**（武器切换体系链用） |

### 2.1 类别被动（MVP）

| 类别 | 被动 |
| --- | --- |
| `1H-B` | 打出格挡牌时额外获得 **2 点格挡** |
| `1H-S` | 攻击牌对带 **易伤** 目标伤害 **+2** |
| `2H-B` | **撞墙/碰撞** 链收益 **+25%**（与事件链 `M(n)` 叠算前计入基础值） |
| `2H-S` | 攻击牌额外施加 **1 层流血** |

**武器切换体系额外规则**（见 [`Feature-战士体系-武器切换.md`](Feature-战士体系-武器切换.md)）：本回合第 2 次及以上 `切换` 后，可触发 **奖励移动 1**（与「换刃」等共用每回合 1 次上限）；`1H-S` 切换后下一张攻击对易伤 **再 +2**（每回合 1 次）。

## 3. MVP 武器条目

| 武器名 | 类别 | 解锁 | 简述 |
| --- | --- | --- | --- |
| 训练木棒 | `2H-B` | 初始 | 开局默认；猛冲/震地收束形态 |
| 行刑巨斧 | `2H-S` | 奖励/商店 | 双手锐器；流血强化 |
| 战锤 | `2H-B` | 奖励/商店 | 撞墙追加 +2（固定，非 M(n)） |
| 短剑 | `1H-S` | 奖励/商店 | 切换后易伤快攻 |
| 钉头锤 | `1H-B` | 奖励/商店 | 格挡后下次攻击 +3 伤 |

## 4. 与卡牌体系关系

| 体系 | 主要武器关系 |
| --- | --- |
| 状态 | 不限；`1H-S` / `2H-S` 协同更佳 |
| 武器切换 | **核心**：解锁 **≥2 类武器** 后收益最大；部分收束需临时切至 `2H-B` 等 |
| 烧牌 | 不限；消耗联动可减免下一次切换体力 |
| 烧血 | 不限；与持握无关 |
