## Summary

**消耗 / 烧牌**（抽牌运转 + 费用）：唯一机制输入 **`消耗`**。通过消耗词缀与烧牌引擎换取费用、过牌与条件兑现，服务集中收束与塞牌节奏，而不是主打直伤。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 抽牌运转 |
| 副维度 | 费用 |
| 机制输入 | `消耗` |
| 协同类型 | **指示式**（消耗发生 ↔ 费/抽兑现） |
| 标准链型 | `[输入·消耗/烧牌] → [输出·费或过牌收束]` |

## 2. 设计注意

- **弃牌 ≠ 消耗**；须进入消耗堆或牌面标明烧牌。
- 输入牌应稳定制造 `消耗`；输出牌读「本链已触发 `消耗`」换费、检索、连打消耗牌。
- 与过渡遗留的「麻木 / 精简」同轴：严苛条件与特殊协同可保留在体系内。
- 单卡数值见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §3.1。
