## Summary

**集中**（输出）：唯一机制输入 **`集中`**——成功施加「**下一张攻击 +X 伤**」。输入叠伤窗口，输出牌在窗口内收束爆发；回路重复或延长集中。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 输出 |
| 副维度 | —（可轻触费用） |
| 机制输入 | `集中` |
| 协同类型 | **指示式**（下一击加成 ↔ 攻击收束） |
| 标准链型 | `[输入·下一张攻击+伤] → [输出·攻击收束]` |

## 2. 设计注意

- **唯一输入签名**：牌面必须出现「下一张攻击 +N」（或等价表述）；打出并成功挂上加成即触发 `集中`。
- 收束牌使用「本链已触发 `集中`」追加伤害或效果；裸打应弱于有集中窗口。
- 不以格挡/治疗作为主强度；需要生存时走 **移动** 或塞牌导出。
- 单卡数值见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §3.2。
