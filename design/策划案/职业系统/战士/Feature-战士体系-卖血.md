## Summary

**卖血**（输出 + 费用）：唯一链事件 **`流血`**（施加或获得流血层数）。体系牌裸打伤害低于过渡「重击」，叠流血 / 利用回合末 DoT 后收束二次爆发。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 输出 |
| 副维度 | 费用 |
| 唯一事件 | `流血` |
| 标准链型 | `[流血] → [卖血收束]` |

## 2. 设计注意

- **流血层数伤害**（回合末 DoT）**不参与** 链收益 `M(n)` 乘算。
- 自身流血层数仅作跨体系联动 **条件**，非事件 ID。
- 流血状态语义见 [`Foundation-减益状态.md`](../../状态效果系统/Foundation-减益状态.md)。
- 单卡数值见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §3.3。
