## Summary

**卖血**（输出 + 费用）：唯一 **机制输入** **`流血`**（施加或获得流血层数；指示式协同，源于 **流血** DoT）。该体系已迁入创意池，当前版本不进入实现排期。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 输出 |
| 副维度 | 费用 |
| 机制输入 | `流血` |
| 协同类型 | **指示式**（流血层数 × 回合末 DoT） |
| 标准链型 | `[输入·流血] → [输出·卖血收束]` |

## 2. 设计注意

- **流血层数伤害**（回合末 DoT）**不参与** 链收益 `M(n)` 乘算。
- 自身流血层数仅作跨体系联动 **条件**，非事件 ID。
- 流血状态语义见 [`Foundation-减益状态.md`](../../状态效果系统/Foundation-减益状态.md)。
- 当前状态：**暂缓实现**（创意池存档），见 [`Feature-战士卡牌创意池.md`](Feature-战士卡牌创意池.md) §8.2。
