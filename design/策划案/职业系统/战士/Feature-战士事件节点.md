## Summary

战士 **四体系各 1 个** 事件 ID；仅战士使用，非全职业注册表。事件用于同体系链判重与收束 `M(n)`；**词缀**（如 **消耗**）不自动等价于事件。

## 1. 事件表

| 体系 | 事件 ID | 触发条件 | 不计入 |
| --- | --- | --- | --- |
| **减益** | `施加燃烧` | 本回合内对任意单位成功施加 ≥1 层 **燃烧** | 仅预览未结算 |
| **塞牌** | `敌方塞牌` | 向敌方 **抽牌堆** 塞入 ≥1 张 **状态牌/卡壳牌** | 向己方牌堆塞牌 |
| **卖血** | `自伤` | 本回合内 **主动** 失去 ≥1 当前生命（牌/效果；非敌人伤害、非 DoT） | 被动受伤 |
| **位移** | `位移` | 本回合内 **主动** 移动 ≥1 格（含「前进」等牌面移动） | **武器切换**；被动击退/拉拽 |

## 2. 链规则（战士 MVP）

| 规则 | 说明 |
| --- | --- |
| 链窗口 | 同一玩家回合内；收束后该体系链清零 |
| 判重 | 同一体系链内 **同一事件 ID 只计 1 次** → 单体系 **n 自然上限为 1**（`M(1)=1.5`） |
| 收束 | 每体系每回合最多收束 1 次 |
| `n=0` | 未触发本体系事件即收束 → `M(0)=1.0`，偏弱但允许 |
| 跨体系 | 联动 **固定数值加成** 为主；虚拟叠 n 见 [`Feature-战士体系联动.md`](Feature-战士体系联动.md) §1、§3 |
| 多次动作 | 同回合可多次位移/自伤/塞牌，但 **同 ID 不叠 n**；额外次数走牌面固定效果或联动 |

## 3. 与词缀关系

| 情况 | 说明 |
| --- | --- |
| **消耗** 词缀 | 移入消耗牌堆；**不**触发 `敌方塞牌` 或任何战士事件，除非牌面另有塞牌效果 |
| **命中无耗** | 返还能量；不触发战士事件 |
| 牌面同时有事件效果 | 例：燃刃造成燃烧 → 可触发 `施加燃烧`；余烬仅弃抽 → **不**触发任何战士事件 |
