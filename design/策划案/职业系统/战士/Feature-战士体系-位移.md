## Summary



**位移**（移动 + 输出）：唯一链事件 **`位移`**（主动移动 ≥1 格）。单卡数值见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) 附录 A。



## 1. 体系定位



| 项目 | 内容 |

| --- | --- |

| 主维度 | 移动 |

| 副维度 | 输出 |

| 唯一事件 | `位移` |

| 标准链型 | `[位移] → [位移收束]` |



## 2. 设计注意



- 同回合多次移动可发生；链内 `位移` 仍只计 **1** 次 n。

- Post-MVP 可与武器系统（[`Feature-战士武器系统.md`](Feature-战士武器系统（废弃.md)）联动撞墙加成。
