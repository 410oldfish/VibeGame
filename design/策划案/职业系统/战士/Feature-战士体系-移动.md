## Summary

**移动**（生存为主，输出为副）：唯一链事件 **`位移`**（主动移动 ≥1 格）。强度来自 **走位规避** 与 **破障/造障** 改善落点与通路，格挡为无法规避时的低风险兜底。

原「位移」Post-MVP 文档升格为本体系；文件名以 **移动** 为准（事件 ID 仍为 `位移`）。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 生存（规避） |
| 副维度 | 输出 |
| 唯一事件 | `位移` |
| 协同类型 | **指示式**（位移发生 ↔ 生存/轻输出兑现） |
| 标准链型 | `[位移] → [生存兑现或轻收束]` |

## 2. 设计注意

- 同回合多次移动可发生；链内 `位移` 仍只计 **1** 次 `n`。
- **破障**：破坏邻格障碍/残骸，优先服务通路与掩体；可与移动同牌触发 `位移`。
- 被动击退/拉拽不触发 `位移`。
- 单卡数值见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §3.3。
