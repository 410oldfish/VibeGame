## Summary

**移动**（生存为主，输出为副）：唯一链事件 **`位移`**（一次成功的主动移动动作，移动 ≥1 格）。强度来自 **走位规避** 与 **破障/造障** 改善落点与通路，格挡为无法规避时的低风险兜底。

原「位移」Post-MVP 文档升格为本体系；文件名以 **移动** 为准（事件 ID 仍为 `位移`）。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 生存（规避） |
| 副维度 | 输出 |
| 唯一事件 | `位移` |
| 协同类型 | **指示式**（位移发生 ↔ 生存/轻输出兑现） |
| 标准链型 | `[位移] → [生存兑现或轻收束]` |

## 2. 设计注意

- 同回合多次主动移动可发生；每次成功动作可触发移动被动，但链内 `位移` 仍只计 **1** 次 `n`，不按格数重复计次。
- **破障**：破坏邻格障碍/残骸，优先服务通路与掩体；可与移动同牌触发 `位移`。
- **主动移动**：单位自身通过体力、卡牌、技能或意图发起；成功移动至少 1 格才触发 `位移`、踏风预备和游斗等战士被动。
- **强制移动**：由其他单位、状态或环境改变位置，例如击退、拉拽与活墙推动；不触发战士移动被动，但仍结算路径地形、拾取物和陷阱。
