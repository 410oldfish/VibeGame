## 1. 文档定位

本文件记录战士 **核心概念**：定位、属性、五维倾向与 **三卡牌体系（MVP）** 索引。事件、词缀与 **全部卡牌** 见 [`Feature-战士事件节点.md`](Feature-战士事件节点.md)、[`Foundation-卡牌词缀与效果语义.md`](../../设计规范/Foundation-卡牌词缀与效果语义.md)、[`Feature-战士卡牌.md`](Feature-战士卡牌.md)。

## 2. 职业定位

战士是强调 **重击、燃烧压制、叠流血卖血与塞牌干扰** 的前线职业。核心乐趣来自：

1. **MVP 三体系**——减益 / 塞牌 / 卖血——各 **1 个战士事件**，事件链收束（[`Foundation-卡牌与角色五维设计.md`](../../设计规范/Foundation-卡牌与角色五维设计.md) §8.3）。
2. 六边形站位下的 **体力移动 + 出牌** 同权决策。

位移体系 Post-MVP，见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) 附录 A。武器系统 Post-MVP，见 [`Feature-战士武器系统.md`](Feature-战士武器系统（废弃.md)。

## 3. 初始构成

### 3.1 初始属性

- 生命：70
- 能量上限：3

### 3.2 关键词

- 燃烧、恐惧牌、流血、吸血
- 词缀：消耗、命中无耗（见 Foundation 词缀表）

### 3.3 MVP 初始牌组

- 牌组 **9 张**：见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §4（打击×4、防御×4、燃烧×1）。

## 4. 五维定位

| 维度 | 初始倾向 | 主要体系 | 设计说明 |
| --- | --- | --- | --- |
| 输出 | 高 | 减益、卖血 | 燃烧收束、流血叠层与回合末 DoT |
| 生存 | 中低 | — | 中性「防御」+ 卖血格挡牌 |
| 移动 | 中 | —（Post-MVP：位移） | MVP 靠基础体力移动；位移链延后 |
| 费用 | 中 | 减益、卖血、塞牌 | 命中无耗、流血事件、塞牌干扰 |
| 抽牌运转 | 中低→成长 | 塞牌 | 敌方恐惧牌 + 过渡牌消耗引擎 |

## 6. 与其他系统的关系

| 系统 | 关系 |
| --- | --- |
| 战斗系统 | 流血事件 = 施加/获得流血层数；体力主动移动 |
| 卡牌构筑 | 三体系 + 词缀（≤3）+ 范围 + 子类别 / 所属体系 + 预期前置 |
| 地形系统 | 高台阻挡移动与 LOS；废墟有 HP 可穿透攻击清除；位移撞高台深化 Post-MVP |
| 敌人系统 | 塞牌体系向敌方抽牌堆塞 **恐惧牌** |
