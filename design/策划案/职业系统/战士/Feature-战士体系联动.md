## Summary

战士 **四体系并存**：消耗（烧牌）、集中、移动、塞牌。每体系 **1 个机制输入**；单体系 **禁止** 主维度同时占满「输出 + 生存」。跨体系靠 **导出** 与过渡牌衔接，不共享同一事件 ID。

## 1. 体系维度总表

| 体系 | 主维度 | 副维度 | 事件 | 禁止并存 |
| --- | --- | --- | --- | --- |
| 消耗（烧牌） | 抽牌运转 | 费用 | `消耗` | 不以高额直伤为主轴 |
| 集中 | 输出 | —（可轻触费用） | `集中` | 不以格挡/治疗为主轴 |
| 移动 | 生存 | 输出（副） | `位移` | 不以过牌引擎为主轴 |
| 塞牌 | 抽牌运转 | 费用 | `敌方塞牌` | 不以纯站桩格挡为主轴 |

## 2. 标准链

| 体系 | 标准链型 |
| --- | --- |
| 消耗 | `[输入·消耗/烧牌] → [输出·费或过牌收束]` |
| 集中 | `[输入·下一张攻击+伤] → [输出·攻击收束]` |
| 移动 | `[输入·位移/破障通路] → [输出·生存兑现或轻输出]` |
| 塞牌 | `[输入·敌方塞牌] → [输出·塞牌收束]` |

`M(1)=1.5`；同回合同体系事件 `n` 上限见事件节点。

## 3. 推荐跨体系导出（非强制）

| 从 → 到 | 典型导出 | 说明 |
| --- | --- | --- |
| 消耗 → 集中 | 消耗后获得 **1** 费 / 抽 **1**，便于打出集中输入 | 导出牌标「所属体系=消耗，协同=导出」 |
| 集中 → 塞牌 | 下一击命中后额外塞 **1** 恐惧（草案） | 勿把塞牌事件算进集中 `n` |
| 移动 → 集中 | 本回合已位移时，集中输入 **+1** 伤（草案） | 生存兑现，不改集中事件定义 |
| 塞牌 → 移动 | 意图槽有恐惧时额外移动 **1** / 格挡 | 已有规避预案、体系战吼等 |

跨体系导出 **默认不** 触发目标体系事件，除非牌面写明「同时触发 `…`」。

## 4. 与过渡牌

- 过渡牌可弱触发事件作启动，但 **不以 `M(n)` 为强度主体**。
- 明显绑定「下一张攻击+伤」的牌应归 **集中**；明显「消耗/烧牌换费」归 **消耗**；「移动+格挡/破障」归 **移动**。
