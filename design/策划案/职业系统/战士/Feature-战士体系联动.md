## Summary

战士 **四体系** 共用的链规则与跨体系联动。体系：**状态 / 武器切换 / 烧牌 / 烧血**。

## 1. 共通规则

| 规则 | 说明 |
| --- | --- |
| 链窗口 | 默认 **同一玩家回合内**；收束后该体系链清零 |
| 收束次数 | 每体系每回合 **最多收束 1 次** |
| 事件判重 | 同一 `事件节点类型` 在同一链中只计 1 次 |
| MVP 链长上限 | `n ≤ 4`，`M(n) ≤ 6.25` |
| 倍率公式 | 见设计规范 §8.3 |
| 武器 | 部分收束牌有 **武器需求**；切换本身记 `切换` 事件，见武器系统 |

## 2. MVP 初始牌组

| 牌名 | 数量 | 体系 | 备注 |
| --- | ---: | --- | --- |
| 打击 | 4 | 状态 | 弱收束 |
| 防御 | 4 | — | 中性基础牌，不归属四体系 |
| 前进 | 1 | 武器切换 | 位移事件 |
| 换刃 | 1 | 武器切换 | 切换事件；开局仅 1 把武器时仍可切换回训练木棒 |

升级模板见 [`Feature-休息处成长设计.md`](../../奖励成长系统/Feature-休息处成长设计.md)。

奖励/商店见 [`Feature-商店与服务设计.md`](../../奖励成长系统/Feature-商店与服务设计.md) §3.3。

## 3. 跨体系联动

| 联动 | 条件 | 效果 |
| --- | --- | --- |
| 状态 → 武器切换 | 目标 ≥2 易伤或 ≥2 流血，武器切换收束命中 | 收束伤害 **+目标 debuff 层数**（固定，上限 +4） |
| 烧血 → 状态 | 本回合「烧血」体系已成功收束且当前 **低血** | 状态体系 **+1 虚拟事件**（`低血`，上限仍 4） |
| 烧牌 → 武器切换 | 本回合打出 ≥1 张 **消耗** 牌 | 下一次 **切换** **不耗体力**（每回合 1 次） |
| 烧血 → 烧牌 | 自伤后打出烧牌「消耗」牌 | 该消耗牌 **额外抽 1 张** |
| 武器切换 → 烧血 | 本回合 `切换` ≥2 次且武器切换收束造成伤害 | 回复 **3** 生命（固定，每战斗 2 次） |
