## Summary

战士 **四体系**（减益 / 塞牌 / 卖血 / 位移）各 **1 个战士事件**；共通链规则与跨体系联动。初始牌组见 [`Feature-战士过渡卡牌.md`](Feature-战士过渡卡牌.md) §3。

## 1. 共通规则

| 规则 | 说明 |
| --- | --- |
| 链窗口 | 同一玩家回合内；收束后该体系链清零 |
| 收束次数 | 每体系每回合 **最多收束 1 次** |
| 事件判重 | 同一 **战士事件 ID** 在同一链中只计 1 次 → 单体系 **n≤1** |
| MVP 链长 | 跨体系虚拟叠 n 少见；单链 `n≤4` 上限仍适用 |
| 倍率公式 | 见设计规范 §8.3；战士标准节奏 **1 事件 → 1 收束** → `M(1)=1.5` |
| 词缀 | 最多 3 个/牌；见 [`Foundation-卡牌词缀与效果语义.md`](../../设计规范/Foundation-卡牌词缀与效果语义.md) |

## 3. 跨体系联动

| 联动 | 条件 | 效果 |
| --- | --- | --- |
| 减益 → 位移 | 本回合已触发 `施加燃烧` 且位移收束命中 | 收束伤害 + 目标 **燃烧** 层数（固定，上限 +4） |
| 卖血 → 减益 | 本回合已触发 `自伤` 且当前 **低血**（≤50% 最大生命） | 下一次减益收束 **命中无耗**（每回合 1 次） |
| 塞牌 → 位移 | 本回合已触发 `敌方塞牌` | 下一次主动 **位移**（含牌面移动） **不耗体力**（每回合 1 次） |
| 卖血 → 塞牌 | 本回合已触发 `自伤` 后打出触发 `敌方塞牌` 的牌 | 额外再向敌方抽牌堆 +1 **卡壳** |
| 位移 → 卖血 | 本回合 **主动移动** 累计 ≥2 次且位移收束造成伤害 | 回复 **3** 生命（固定，每战斗 2 次） |
