## Summary

**塞牌**（抽牌运转 + 费用）：唯一 **机制输入** **`敌方塞牌`**（指示式协同，源于 **牌区污染**）。体系牌靠塞牌层数叠 **输出（收束）**；过渡牌的己方消耗引擎见 [`Feature-战士卡牌.md`](Feature-战士卡牌.md) §2。

## 1. 体系定位

| 项目 | 内容 |
| --- | --- |
| 主维度 | 抽牌运转 |
| 副维度 | 费用 |
| 机制输入 | `敌方塞牌` |
| 协同类型 | **指示式**（塞牌 ↔ 消耗引擎） |
| 标准链型 | `[输入·敌方塞牌] → [输出·塞牌收束]` |
