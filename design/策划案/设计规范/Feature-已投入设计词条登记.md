## 3. 地形与格子状态

三层模型见 [`Feature-地形与地形改装规则.md`](../地形系统/Feature-地形与地形改装规则.md) §3.1。下表为 **第一章已投入**。

### 3.1 MVP 已投入 · 格子地形

| ID | 分类 | 通行 | 破坏/交互 | 触发来源 | 详述 |
| --- | --- | --- | --- | --- | --- |
| 普通地面 | 基础地面 | 正常 | — | 默认战场 | [`Feature-地形与地形改装规则.md`](../地形系统/Feature-地形与地形改装规则.md) |
| 石台 | **高台** | 不可通行 | **仅**「破坏高台/特殊行动」；**阻挡 LOS** | 遭遇布局 | 普通攻击 **不能** 破坏或穿透 |
| 木箱 | **废墟** | 不可通行 | **攻击穿透**并扣 **HP**（默认 **4**）；击退撞上按 Content | 遭遇布局；酋长落岩 | HP 归零移除；可掉落拾取物 |
| 深坑 | 基础地面 | 不可主动进入 | 击退落点伤害 | 遭遇布局 | 数值见平衡验证 |

> **高台** 与 **废墟** 均属构筑物层，规则不同。**石台** 为 MVP 高台示例；**木箱** 为 MVP 废墟示例。**生命树** 为高台示例，Post-MVP 见 §3.2。

### 3.2 参考池 · 构筑物与覆盖（未投入 MVP）

| ID | 分类 | 说明 |
| --- | --- | --- |
| 生命树 | 高台 | 仅指定卡牌/特殊行动破坏；破坏后可配置大额拾取 |
| 水域、泥沼 | 基础地面 | 见地形 Feature 完整池 |
| 冰冻 / 冰面、火焰覆盖、电场、毒雾、圣域 | 临时覆盖 | 第二章及以后 |

### 3.3 MVP 已投入 · 可视区拾取物

战场格子上的 **可见掉落**；**仅玩家** 移动进入该格时拾取。规则见地形 Feature「可视区拾取物」。

| 效果 ID | 说明 | MVP 数值/行为 |
| --- | --- | --- |
| 生命回复 | 立即恢复生命 | +15（可调） |
| 临时力量 | 获得力量；战斗结束清除 | +2 力量 |
| 临时牌·投斧 | 本场加入 **临时牌池** 1 张「投斧」 | 1 费，**射程3**，**10** 伤；打出后 **下回合开始时** 回到手牌 |

**临时牌·投斧**（本场，非持久牌组）：

| 牌名 | 费用 | 范围 | 效果 |
| --- | ---: | --- | --- |
| 投斧 | 1 | 射程3 | **10** 伤；下回合回到手牌 |

**默认掉落（Content 配置）**：废墟（木箱）HP 归零 → 随机 1 项（生命回复 / 临时力量 / 临时牌·投斧）。

## 4. 卡牌词缀（MVP 已投入）

结算语义与 StS 对照见 [`Foundation-卡牌词缀与效果语义.md`](Foundation-卡牌词缀与效果语义.md)。下表为 **已有牌面使用的词缀**。

| ID   | 结算摘要            | MVP | 使用示例           |
| ---- | --------------- | --- | -------------- |
| 消耗   | 打出后进消耗牌堆，本场不再循环 | ✓   | 战吼、灰烬之拥、熔炼、瘟疫… |
| 命中无耗 | 攻击命中后返还本牌全部能量   | ✓   | 冲刺、余烬烙印、鲜血铸就   |
| **首发** | 仅本回合第一张可打出；否则移出游戏；打出后亦移出游戏 | ✓   | **快步**（玩家回合基准牌） |
| 虚无   | 回合结束未打出移入弃牌堆      |     |                |
| 保留   | 回合结束未打出保留在手牌中   |     |                |



**Post-MVP 词缀**（参考表有定义、第一章无牌面）：虚无、保留、固有、命中后抽。

## 5. 状态卡牌（token）

塞入 **牌堆** 的 token，**不是** §2 单位状态。规则以 [`Feature-敌人牌组与意图机制.md`](../敌人系统/Feature-敌人牌组与意图机制.md) §3.1.1 为准。

| ID   | 牌面标签 | 类别 | 塞入目标       | 抽到时 / 持有               | MVP | 触发来源              |
| ---- | ---- | --- | ---------- | --------------------- | --- | ----------------- |
| 恐惧牌  | `恐惧` | —（`token`，非玩家类别） | 敌方 **抽牌堆** | 无效果，立即进敌方 **弃牌堆** | ✓   | 污言、传染、塞啸、瘟疫；联动 +1 |
| 头晕目眩 | `头晕目眩` | **状态** | 玩家 **手牌**（战斗内） | 持有期间：**类别=行动** 的牌费用 **+1**；战斗结束清除 | ✓   | 玩家被击退撞到敌人或 **高台** |

> **恐惧牌** 为敌方 token，**不** 使用玩家 `类别` 枚举。**头晕目眩** 为玩家侧 **状态** 类别 token，与单位 debuff「眩晕」不同。

## 6. 玩家战斗基准牌（MVP）

不属于局外牌组；每 **玩家回合** 资源恢复后加入手牌。规则全文见 [`Core-卡牌与构筑系统设计.md`](../卡牌构筑系统/Core-卡牌与构筑系统设计.md) §3.1。

| 卡牌名称 | 卡牌描述 | 费用 | 范围 | 词缀 | 类别 | 子类别 | 所属体系 | 移出游戏 |
| --- | --- | ---: | --- | --- | --- | --- | --- | --- |
| **快步** | 移动 **1** 格 | 1 | — | **首发** | **行动** | **纯粹移动** | **无** | ① 作为本回合第一张打出并结算后；② 本回合已打出其他牌后仍在手牌；③ 回合结束仍在手牌 |

- **移出游戏** = 销毁该临时实例，**不** 进入弃牌堆/抽牌堆/消耗牌堆。
- 战士 **`位移`** 事件：快步牌面移动计入主动移动。

## 8. 类别（MVP 枚举）

权威定义与复合判定见 [`Foundation-卡牌词缀与效果语义.md`](Foundation-卡牌词缀与效果语义.md) §4。配置字段 **`类别`** 必填。

### 8.1 玩家类别

| 类别 | MVP 摘要 |
| --- | --- |
| **行动** | 自身移动、破高台/清废墟、敌被动位移为主；**快步** |
| **攻击** | 对敌伤害为主；打击、旋风斩等 |
| **技能** | 一次性格挡/抽牌/引擎；防御、战吼等 |
| **能力** | 打出后进 **能力区**；Post-MVP 完整池 |
| **诅咒** | 污染牌；跨战斗保留；Post-MVP 完整池 |
| **状态** | 战斗内污染 token；**头晕目眩** |

### 8.2 敌人类别

| 类别 | MVP 摘要 |
| --- | --- |
| **行动** | 接近、冲撞 |
| **攻击** | 打击、重击、投矛 |
| **技能** | 网索、一次性格挡 |
| **能力** | 稳固、战鼓；底牌「越战越勇」类 |
