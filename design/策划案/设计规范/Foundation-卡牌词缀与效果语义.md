## Summary

全局 **卡牌词缀**、**类别** 与 **卡牌条目字段** 的结算语义与跨游戏对照表（**参考 + 协议**）。词缀描述「牌如何进入/离开牌区」或「何时触发额外结算」；**类别** 描述「牌在系统中的类型角色」；**子类别 / 所属体系** 供设计筛选与构筑归类。与 **战士事件节点** 分层：**词缀/类别全局复用，事件战士专属**。  
**已有牌面使用的词缀** 以 Feature 词条登记为准；本文件维护 **全量词缀定义** 与 Post-MVP 备选。

## 1. 硬上限

| 规则 | 说明 |
| --- | --- |
| 词缀数量 | 单张卡牌 **最多 3 个** 词缀；设计/配置/导出均不得超限 |
| 优先级 | UI 按 §6 展示顺序排列；结算按 §2~§4 时机顺序，与 UI 顺序无关 |

## 2. 牌区与生命周期词缀

| 本作词缀 | 结算语义 | 触发时机 | MVP | StS | 斗技场的阿丽娜 | 炉石 |
| --- | --- | --- | --- | --- | --- | --- |
| **消耗** | 打出并结算后，移入 **消耗牌堆**；本场不再进入抽/弃牌循环 | 打出结算完成时 | ✓ | Exhaust | Banish（近似） | — |
| **虚无** | 回合结束时若仍在手牌 → 移入 **弃牌堆**（不进入消耗堆，除非牌面另声明） | 玩家回合结束 | 延后 | Ethereal | — | — |
| **保留** | 回合结束时不弃置，留至下回合（仍占手牌上限） | 玩家回合结束 | 延后 | Retain | — | — |
| **首发** | 仅可当 **本回合第一张打出的牌** 正常打出；违反时 **移出游戏**（不进弃牌堆）；合法打出并结算后亦 **移出游戏** | 打出校验 / 本回合首次打出其他牌后 / 玩家回合结束 | ✓ | — | Opening 类 | — |
| **固有** | 战斗开始置于手牌（先于常规抽牌） | 战斗开始 | 延后 | Innate | Opening 类 | 起手相关 |
| **无法打出** | 条件不满足时灰显；满足前不可选中 | 出牌校验 | ✓ | Unplayable | — | — |

与 [`Core-卡牌与构筑系统设计.md`](../卡牌构筑系统/Core-卡牌与构筑系统设计.md) §3.1 牌区定义一致。

## 3. 结算触发词缀

| 本作词缀 | 结算语义 | 触发时机 | MVP | StS | 阿丽娜 | 炉石 |
| --- | --- | --- | --- | --- | --- | --- |
| **命中无耗** | **类别=攻击** 的牌对 ≥1 合法目标造成 **命中伤害**（格挡后仍 >0）后，返还本牌消耗的 **全部能量**；不返体力 | 伤害结算后 | ✓ | 个别 refund | Free on hit 类 | — |
| **未命中则弃** | 攻击 **未造成命中伤害** → 本牌额外移入弃牌堆一次（或改为 **消耗**，按牌面） | 攻击结算后 | 延后 | — | whiff 惩罚 | — |
| **打出后抽** | 本牌主效果结算完成后抽 N 张 | 打出结算完成时 | ✓ | draw on play | — | Battlecry 抽牌 |
| **命中后抽** | 仅当本牌攻击 **命中** 时抽 N 张 | 伤害结算后 | 延后 | Rebound 类 | — | — |

**与链收益 `M(n)`**：词缀触发的返还/抽牌 **默认不乘** 链收益乘数，除非牌面或效果明确将该项纳入 **输出（收束）** 的链收益。

## 4. 目标 / 范围 / 类别

**类别** 与 **五维**、**词缀**、**子类别** 分层：类别回答「系统类型与 UI/结算分类」；子类别/所属体系回答「设计归类」；五维作平衡分析备注。一张牌 **有且仅有 1 个类别**（必填配置字段 `类别`）。

### 4.1 玩家类别总表

| 类别 | 判定要点 | 打出 / 持有 | StS 近似 |
| --- | --- | --- | --- |
| **行动** | 以 **自身移动**、**破坏/清除地形**、或 **使敌人被动位移**（击退/拉拽/冲撞）为主效果，且 **不以对敌直接伤害为主** | 正常打出；结算后进 **弃牌堆**（词缀另定除外） | 无独立类型；部分 Skill |
| **攻击** | 以对 **敌人** 的直接伤害、状态伤害、命中 debuff 为主 | 正常打出；进弃牌堆 | Attack |
| **技能** | **格挡/治疗/抽牌/能量/净化/塞牌** 等 **一次性** 非攻击收益 | 正常打出；进弃牌堆 | Skill |
| **能力** | 打出后在本场 **常驻**（力量成长、每回合触发、改规则） | 打出后移入 **能力区**；不进抽/弃牌循环 | Power |
| **诅咒** | **局外或局内** 塞入玩家牌组的 **污染牌**；多为 **无法打出** 或打出有害 | 按牌面；默认 **跨战斗保留** | Curse |
| **状态** | **战斗内** 塞入的 **污染牌**；占用抽牌/手牌；战斗结束 **默认清除** | 抽到手牌时 / 打出时按牌面 | Status（Burn/Wound 等） |

### 4.2 敌人类别总表

敌人意图牌、底牌（除 token）使用下列 **4 类**；**无** 诅咒/状态类别。塞入敌方的 **恐惧牌** 等为 **token**，不适用 `类别` 字段（配置用 `token=true`）。

| 类别 | 判定要点 | MVP 示例 |
| --- | --- | --- |
| **行动** | 以 **移动**、**强制位移**、**改场站位** 为主，不以对玩家直接伤害为主 | 接近、冲撞 |
| **攻击** | 以对玩家/友方的 **直接伤害** 为主 | 打击、重击、投矛 |
| **技能** | **一次性** 控制、debuff、格挡、抽牌干扰等 | 网索、格挡（一次性） |
| **能力** | 打出后 **本场常驻** buff/debuff 规则 | 稳固、战鼓 |

### 4.3 复合牌唯一类别规则

多张效果并存时，按 **优先级 1→4** 取 **第一个匹配** 的类别（每张牌仅 1 个类别）：

1. 含 **对敌直接伤害/状态伤害** 且占主要费用价值 → **攻击**（例：冲刺、旋风斩、恐惧降临）
2. 否则主效果为 **自身移动 / 破坏障碍 / 纯击退无伤害** → **行动**（例：快步、破障、前进）
3. 否则打出后 **本场常驻** → **能力**
4. 其余一次性非攻击 → **技能**（例：防御、余烬、战吼）

### 4.4 诅咒 vs 状态（污染牌）

与 **单位 debuff**（§5 状态系统）区分：下列为 **牌组内的卡牌实体**。

| 维度 | 诅咒 | 状态 |
| --- | --- | --- |
| 典型来源 | 事件代价、奖励负面 | 战斗内塞牌、击退撞墙 token |
| 跨战斗 | 默认 **保留** | 默认 **清除** |
| 牌区 | 进玩家抽牌堆循环 | 进玩家抽牌堆；战斗结束移除 |
| token 标记 | 可选 | 塞入物 token（如 **头晕目眩**）配 `token=true`，类别仍为 **状态** |

**恐惧牌** 塞入 **敌方** 抽牌堆，为敌方 token，**不** 使用玩家类别枚举。

### 4.5 范围与塞入物

| 类别 | 本用术语 | 说明 |
| --- | --- | --- |
| 范围 | **邻格** / **直线** / **范围** | 见 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md) |
| 塞入物 | **状态 token** | 按目标牌堆规则结算；玩家侧 token 类别=**状态**；敌方 **恐惧牌** 见敌人文档 |

### 4.6 与减益状态的接口

单位 debuff 引用 **类别** 而非旧称「攻击牌/技能牌」：

| debuff | 效果 |
| --- | --- |
| **缴械** | 无法打出 **攻击** 类别 |
| **沉默** | 只能打出 **攻击** 类别（**行动/技能/能力** 不可打） |
| **困惑** | 打出 **技能** 类别时受到 X 点伤害（**行动** 不计入） |

详见 [`Foundation-减益状态.md`](../状态效果系统/Foundation-减益状态.md)。

## 6. 词缀与类别 · 配置字段（摘要）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `类别` | enum，**必填** | 玩家 6 类 / 敌人 4 类；见 §4 |
| `词缀列表` | string[]，**长度 1~3** | 有序；UI 建议顺序：无法打出 → 固有 → **首发** → 保留 → 虚无 → 消耗 → 命中无耗 → 其余 |
| `token` | bool，可选 | 塞入牌堆的 token；玩家 token 默认 `类别=状态` |

**类别 UI 色条/图标建议顺序**：行动 → 攻击 → 技能 → 能力 → 诅咒 → 状态

完整卡牌条目字段见 **§7**。

## 7. 卡牌条目字段

策划表 / Card Creator **推荐列顺序**（牌面信息在前，分类/配置在后）：

| 顺序 | 字段 | 类型 | 说明 |
| ---: | --- | --- | --- |
| 1 | **`卡牌名称`** | string | 显示名 |
| 2 | **`卡牌描述`** | string | 玩家可读 + 机制摘要（主文案；取代原表内「效果」列） |
| 3 | **`费用`** | int | 能量费用 |
| 4 | **`范围`** | enum | 邻格 / 射程 / 直线 / 环形等；战斗实现必填 |
| 5 | **`词缀列表`** | string[]，1~3 | §2~§3 |
| 6 | **`稀有度`** | enum | 初始 / Common / Uncommon / Rare |
| 7 | **`类别`** | enum，必填 | §4 |
| 8 | **`子类别`** | enum，可选 | §7.1；非法组合 Content 校验拒绝 |
| 9 | **`所属体系`** | enum | 战士构筑；§7.2 |
| 10 | **`协同角色`** | enum | `输入` / `输出` / `回路` / `导出` / `—`；§7.3 |
| 11 | **`过渡子类`** | enum | 仅 `所属体系=过渡`；§7.3 |
| — | **`预期前置事件数量`** | int | 战士体系链 **输入** 门槛；基础/过渡填 `0` |

**已废弃卡牌表列**：`收益维度`（改由 **子类别 + 所属体系** 承担设计归类；五维仍见 [`Foundation-卡牌与角色五维设计.md`](Foundation-卡牌与角色五维设计.md) 作分析备注）。

### 7.1 子类别

| 类别 | 子类别 | 含义 |
| --- | --- | --- |
| **攻击** | `短期爆发` | 单回合高伤 / 斩杀向 |
| **攻击** | `长期成长` | 叠层、多次触发、本场渐强 |
| **攻击** | `—` | 无细分 |
| **技能** | `防御·短期爆发` | 一次性格挡 / 大盾 |
| **技能** | `防御·长期成长` | 保留、叠甲、持续减伤 |
| **技能** | `引擎·运转` | 抽牌 / 弃牌 / 循环 |
| **技能** | `工具` | 能量、净化、塞牌等一次性工具 |
| **技能** | `—` | |
| **行动** | `纯粹移动` | 主要为自身换位 |
| **行动** | `敌人位置控制` | 击退 / 拉拽 / 限制行为 |
| **行动** | `地形互动` | 破障碍、清除残骸、改落点 |
| **行动** | `—` | |
| **能力** | `长期成长` | 力量 / 每回合触发等 |
| **能力** | `规则常驻` | 改规则、监听器型 |
| **能力** | `—` | |
| **诅咒** / **状态** | `—` | 污染牌通常无子类别 |

### 7.2 所属体系（战士）

| 值 | 对应定位 | 事件 ID |
| --- | --- | --- |
| **`无`** | 基础牌 | — |
| **`过渡`** | 无体系纯过渡 | 弱 / 无链 |
| **`燃烧`** | 减益体系 | `施加燃烧` |
| **`塞牌`** | 塞牌体系 | `敌方塞牌` |
| **`流血`** | 卖血体系 | `流血` |
| **`位移`** | Post-MVP | `位移` |

> 体系 **「流血」** = 事件/状态 **流血**；与类别 **状态**（污染 token 牌）不同。

敌人卡牌通常 **不填** `子类别` / `所属体系` / `协同角色` / `过渡子类`（或填 `—`）。敌人使用 **施压维度 + 子维度**（见 [`Feature-敌人牌组与意图机制.md`](../敌人系统/Feature-敌人牌组与意图机制.md) §3.1），标注 **对玩家的惩罚方向**，**不** 使用上表战士 `子类别`，也 **不** 把敌人自用收益（如「格挡」）直接当作子维度名。

### 7.3 协同角色与过渡子类

与 [`Foundation-卡牌与角色五维设计.md`](Foundation-卡牌与角色五维设计.md) §8.3 对齐；与 `所属体系` **正交**。

**`协同角色`**

| 值 | 适用 | 含义 |
| --- | --- | --- |
| **`—`** | 基础牌；多数过渡牌 | 无体系内协同结构角色 |
| **`输入`** | 体系牌；过渡·特殊协同 | 产生本体系机制（战士：触发体系内事件） |
| **`输出`** | 体系牌；过渡·特殊协同 | 利用/收束本体系机制（战士：收束牌） |
| **`回路`** | **仅体系牌** | 既输入又输出（自循环） |
| **`导出`** | 体系牌 | 把本体系收益导向其他能力维度 |

**`过渡子类`**（`所属体系` = **`过渡`** 时 **必填**；其余填 `—`）

| 值 | 说明 |
| --- | --- |
| **`成长`** | 每次使用累积数值成长 |
| **`严苛条件`** | 严苛条件达成时超标，否则过渡水平 |
| **`特殊协同`** | 可标 `输入`/`输出`，协同绑定 **特定卡牌**（非整个体系） |
| **`纯过渡`** | 无协同；单卡牌效偏高 |

**Content 校验（战士牌）**

| 规则 | 处理 |
| --- | --- |
| `所属体系` = 无 | `协同角色` = `—`；`过渡子类` = `—` |
| `所属体系` = 过渡 | `协同角色` **≠** `回路`；`过渡子类` **必填** |
| `所属体系` = 过渡 且 `过渡子类` ≠ 特殊协同 | `协同角色` = `—` |
| `所属体系` = 燃烧/塞牌/流血/位移 | `协同角色` ∈ {输入, 输出, 回路, 导出}；`过渡子类` = `—` |
| `预期前置事件数量` ≥ 1 | 通常 `协同角色` = **输出** |
| `预期前置事件数量` = 0 且牌面触发事件 | 通常 `协同角色` = **输入** |
