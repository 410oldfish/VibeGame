## 2. 全局参考

### 2.1 《杀戮尖塔》1 / 2（Slay the Spire）

| 借鉴轴 | 本项目改法 |
| --- | --- |
| 铁甲战士：**打击 / 防御** 轴 + **消耗 / 过牌 / 能力成长** | 战士 **过渡牌** 承担通用轴；三体系（燃烧/塞牌/流血）承担 build 身份 |
| 敌人 **公开意图**、可读威胁 | 保留；扩展为 **N 槽组合意图**（条目级 `每回合槽位`） |
| 无战场网格时的简化位移 | 改为 **六边形主动移动 + 被动击退**；地形 **障碍挡 LOS、残骸可穿透扣 HP** |

### 2.2 《斗技场的阿丽娜》（Alina of the Arena）

| 借鉴轴 | 数据路径 | 本项目改法 |
| --- | --- | --- |
| **移动 + 击退 + 格挡** 同牌 | `D:\Games\Alina.of.the.Arena.v1.2.2\...\Cards\output\cards.csv` | 战士 **行动/攻击** 复合牌（侧步、断头台、恐惧降临） |
| **燃烧** school：叠层、引燃、直线火球 | 同上 CSV `Burn` 相关行 | 战士 **燃烧体系**；敌人 **地狱犬** 多段咬 + 燃烧 |
| **掩体 / 可破坏物** | Alina 战场物件 | 本项目 **障碍**（不可穿透 LOS）与 **残骸**（HP 制、可掉落） |

## 5. 地形 ↔ 灵感

| 本项目 | 灵感 | 差异 |
| --- | --- | --- |
| **障碍**（Barrier） | Alina 实心掩体；曾用高台/障碍物/石墙 | **不可站、不可过**；**阻挡 LOS**；无 HP；仅特殊行动破坏 |
| **残骸**（Ruin） | Alina 木箱/吧台杂物 | **不可站、不可过**；**HP 制**（默认 4）；攻击 **穿透**；归零 **掉落**；程序 enum 为 `Ruin`（非旧称 Barricade） |
| **深坑 / 普通地面** | Sts 无格；Alina 陷坑 | 六边形 **主动移动** 与 **击退撞格** 规则见 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md) |

历史对照：正式类型名为 **障碍 / 残骸**（`Barrier` / `Ruin`）；曾用 **高台 / 废墟**（v0.3）。Content **实例** 如石台、木箱见 [`Feature-已投入设计词条登记.md`](Feature-已投入设计词条登记.md) §3.1。
