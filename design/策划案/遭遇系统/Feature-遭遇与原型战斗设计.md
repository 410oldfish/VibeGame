## 2. 内容编排规则

### 遭遇职责划分

| 遭遇类型 | 主要职责 |
| --- | --- |
| 普通战斗 | 教会玩家一种清晰交互 |
| 精英战斗 | 检验玩家当前构筑方向是否成立 |
| 首领战斗 | 总结章节主题并要求玩家主动改写战场 |

### 不同遭遇的设计重点

- 普通战斗：单场只强调一到两个关键词，例如「接近→打击」或「远程→贴脸」。
- 精英战斗：必须有能够循环出现的危险点，并至少提供两种破解方式。
- 首领战斗：应通过阶段性牌组和战场改写形成压迫感，而不是只靠数值碾压。

### 遭遇作为系统教学器

遭遇内容让玩家按顺序学会移动、站位、敌方意图和构筑收益，而非简单堆叠敌人。

### MVP 验证问题

第一章 MVP 优先回答：

1. 六边形移动与出牌结合后，每回合的位置抉择是否有趣且清晰？
2. 敌人公开意图并使用牌堆循环后，玩家是否感到在「应对一手牌」而非机械躲技能？
3. **障碍/残骸/深坑** 与撞障碍、清除残骸掉落是否能支撑战士核心乐趣，而不引入水域/电场等额外认知负担？

## 3. 具体内容

### 3.1 MVP 范围（第一章垂直切片）

| 模块 | MVP 内容 |
| --- | --- |
| 模式 | 单人；仅战士 |
| 冒险 | 第一章完整路线：战斗 + 商店 + 火堆 + 事件 + 章首领 |
| 敌人 | 新分层池：1 级哥布林/骷髅兵、2 级兽人战士、3 级活墙壁、4 级待定；旧 MVP 条目在重新分级前不进入新随机池 |
| 战场 | 中等六边形竞技场；地形见 [`Polish-MVP第一章垂直切片.md`](../平衡验证/Polish-MVP第一章垂直切片.md) §4 |
| 状态 | 力量、格挡、稳固、流血、易伤、束缚、燃烧（仅卡牌/事件，见 MVP 锚点 §3） |
| 胜负 | 章首领击败 = 第一章通关；单场战斗后三选一 + 金币 |

### 3.2 第一章遭遇编排表

普通战的敌人池由本层实际战斗序号决定：第 **1～3** 场使用弱怪池，第 **4** 场起使用正常池；地图行区间只决定地形与教学主题，不替代战斗序号。MVP 固定地图阶段不按比例随机铺设地形，而是按战斗序号或节点类型读取 [`Feature-战斗地图预设表.md`](../冒险系统/Feature-战斗地图预设表.md) 中的完整预设。地形标签仅用于文档归类、遭遇预览与后续扩池。

| 阶段 | 行区间 | 推荐敌人 | MVP 预设地图 | 地形标签 | 教学关键词 |
| --- | --- | --- | --- | --- | --- |
| 前段 | 1–3 | 弱怪池：2～3 只哥布林/骷髅兵 | `BMAP-01_Goblin_Open`、`BMAP-02_SpearGoblin_Cover` | 开阔 / 掩体 | 意图、格挡、换位、贴脸远程 |
| 中段 | 4–7 | 正常池：兽人战士 + 1 级杂兵 | `BMAP-03_Orc_NarrowLane` | 狭道 | 直线冲锋、击退、撞障碍入门 |
| 后段 | 8–9 | 正常池高压模板：2 兽人战士 + 1 杂兵 | `BMAP-03_Orc_NarrowLane`（临时复用） | 狭道 / 深坑密集 | 冲锋落点、深坑伤害 |
| 精英 | 5–7 | 活墙壁专属遭遇 | `BMAP-04_LivingWall_Elite` | 狭道 / 精英 | 配对推进、挤压 vs 控场 |
| 首领 | 10 | 部落酋长 | `BMAP-05_TribalChieftain_Boss` | 深坑密集 / 首领 | 章节主题总结 |

E04 在固定预设阶段只预览下一场地图标签；付费调整为同序号后备地图的功能延后到地图池扩充后再启用。

### 3.3 Post-MVP（明确不做）

- 第二、三章完整内容与全部扩展事件池
- 骑士、德鲁伊及多职业遭遇适配
- 水域、感电、电场、火焰覆盖传播
- 复杂地形连锁、动态天气、大量可交互设施
- 大量敌方牌库操纵牌
- 联机合作、Host 迁移、公开匹配
