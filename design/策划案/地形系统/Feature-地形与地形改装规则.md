# 《VibeGame》地形与地形改装规则

> **文档状态**：草案 v0.3  
> **Layer**：Feature
> **Priority**：MVP  
> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> **Quick reference**：关键依赖 六边形战斗规则、卡牌构筑、状态效果、冒险

## Summary

地形系统定义战场三层地形结构、基础地形池、临时覆盖与六种改装动作的统一语义。地形是可运营资源，支持路径、风险与构筑路线的变化；章节具体场景编排见冒险 Feature 层文档。

## 1. 文档定位

本文件是地形系统的主文档，负责定义战场地形的组织方式、地形改装动作和地形对其他系统的影响边界。

本文件负责：

- 地形分层模型。
- 基础地形池与临时覆盖层。
- 地形改装动作。
- 地形反应与封路约束的设计边界。

本文件不负责：

- 六边形路径本身的公共定义。
- 某个职业如何具体利用地形。
- 奖励投放节奏和章节场景编排。

## 2. 玩家体验目标

- 让地形从静态障碍升级为可生成、破坏、转化和组合利用的战斗资源。
- 让玩家能够通过提前铺设和临场改造创造优势回合。
- 让地形与移动、敌方意图、状态和构筑路线形成稳定联动。
- 改装动作必须有限且可读，避免组合失控。
- 地形收益应支持击退陷阱、火焰传播、防线堡垒、生长领域、水电控制等构筑路线。

## 3. 详细设计

### 3.1 核心规则

#### 地形的三层结构

为避免组合规则失控，一个格子最多由三层信息共同决定：

| 层级   | 含义                | 示例             |
| ---- | ----------------- | -------------- |
| 基础地面 | 决定基本通行和固有属性       | 普通地面、水域、深坑  |
| 构筑物  | 可生成/破坏的实体，占位或提供遮挡 | **高台**、**废墟**、荆棘、炮台    |
| 临时覆盖 | 具有持续回合或传播规则的效果    | 火焰、毒雾、冰面、圣域、电场 |

同一层通常只保留一种状态；跨层反应通过明确规则表处理。

#### 构筑物分型：高台 vs 废墟

构筑物层分两类，**视线、破坏与击退交互不同**：

| 类型 | 含义 | 示例 | 通行 | 破坏方式 |
| --- | --- | --- | --- | --- |
| **高台** | 固定阻挡；**阻挡视线与远程/直线攻击穿透** | 章节石台、**生命树**（Post-MVP） | **不可**移动穿过 | **不可**被普通攻击破坏；**仅**「破坏高台/特殊行动」类效果 |
| **废墟** | 可互动、有耐久、可掉落 | **木箱**、落岩碎块、宝箱怪伪装箱 | **不可**移动穿过 | **有 HP**；攻击可 **穿透**并对废墟扣血；HP **归零**移除；击退撞上按 Content 配置 |

- 遭遇/layout 配置时分别标注 `高台:` / `废墟:`；二者 **不可**混称。
- 旧称 **障碍物（石墙）** → **高台**；旧称 **残骸（木箱）** → **废墟**（HP 制）。

**废墟默认 HP（Content）**：MVP 建议 **4**（木箱类）；精英/首领放置的可调至 **6~8**。

#### 破坏、视线与移除

| 动作 | 高台 | 废墟 |
| --- | --- | --- |
| 移动穿过 | **否** | **否** |
| 远程/直线攻击 **穿透**该格 | **否**（阻挡 LOS；见 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md)） | **是**（对格内 **单位** 正常结算；同时对 **废墟 HP** 扣伤） |
| 普通攻击命中该格（无单位） | 无效 | 对废墟 **扣 HP** |
| 「破坏高台」类效果 | **移除** | 不生效（除非牌面写「破坏废墟」） |
| 击退路径终点为该格 | **撞高台**：停前一格，高台 **不**移除 | **撞废墟**：停前一格；废墟 **−1 HP** 或 Content 配置额外碰撞伤 |
| 移除后 | 基础地面保留；默认 **无** 掉落 | 基础地面保留；**可**生成 **可视区拾取物** |

#### 击退与废墟

击退/拉拽/冲撞结算时：

1. **废墟与高台均视为 solid 地形**（占用格子、不可穿越）。
2. 被动移动 **因废墟/高台终止**（单位停在前一格，或该格为终点）：
   - **废墟**：按上表扣 HP 或移除；触发 **碰撞** 衍生效果（若有）。
   - **高台**：**不**移除；仅 **撞高台** 规则（停步、伤害、眩晕等，见单位状态登记）。
3. **高台** 被击退撞上时：**永不**因碰撞移除。
4. 攻击 **穿透** 废墟格时：先对路径上 **单位** 结算，再对 **废墟 HP** 结算（同一次攻击可多次穿透多格废墟，按 Content）。

#### 可视区拾取物（Field Pickup）

部分 **废墟**（及 Content 配置的高台）**被破坏或移除后**，在同格（或配置相邻格）生成 **可视区拾取物**——战场上的独立图标，**不是** 构筑物层。

| 规则 | 说明 |
| --- | --- |
| 可见性 | 全战场可见；Presentation 层需与地形/单位分层显示 |
| 拾取方式 | **玩家** 主动移动 **进入** 该格时 **立即拾取**（含体力移动、卡牌位移落点）；**敌人不拾取** |
| 同格优先级 | 单位占位与拾取物可共存规则：**进入空格且存在拾取物** → 先拾取再完成停留；该格若无构筑物则正常站位 |
| 拾取后 | 拾取物消失；效果立即结算 |
| 战斗结束 | 未拾取物 **清除**，不带入下一场 |

**拾取效果类型（Content 配置）**

| 效果 ID | 说明 | 示例数值 |
| --- | --- | --- |
| **生命回复** | 恢复生命 | +15 生命 |
| **临时力量** | 获得力量层数；**本场战斗结束** 清除 | +2 力量 |
| **临时牌** | 向本场 **`临时牌池`** 加入 1 张牌；**不** 进入持久牌组；战斗结束移除 | 见下表 |

**临时牌（本场）**

| 牌名 | 费用 | 范围 | 效果 | 特殊规则 |
| --- | ---: | --- | --- | --- |
| 投斧 | 1 | 射程3 | **10** 伤 | 打出并结算后，**下回合开始时** 回到手牌（本场可重复循环） |

- 临时牌加入位置：默认 **洗入抽牌堆** 或 **直接入手**（由掉落表配置）；实现需与 [`Core-卡牌与构筑系统设计.md`](../卡牌构筑系统/Core-卡牌与构筑系统设计.md) 牌区扩展 **`临时牌池`**。
- 更多临时牌在 Content 掉落表中扩展；词条登记见 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §3.3。

**掉落配置（Content）**

| 构筑物 | 默认掉落 |
| --- | --- |
| **废墟**（木箱等，HP 归零） | 随机 1：生命回复 / 临时力量 / 临时牌·投斧 |
| **高台** | 无（除非关卡单独配置） |
| 生命树（高台） | Post-MVP：生命回复 + 临时力量（示例） |

#### MVP 第一章子集

MVP 仅实现下列地形与改装；完整池见 §3.1 下文。**已投入登记** 见 [`../设计规范/Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §3。权威边界见 [`../平衡验证/Polish-MVP第一章垂直切片.md`](../平衡验证/Polish-MVP第一章垂直切片.md) §4。

| 类别 | MVP 必须 | Post-MVP |
| --- | --- | --- |
| 基础地面 | 普通地面、深坑 | 水域、泥沼、植物地 |
| 构筑物 | **高台**、**废墟**（含木箱类）；规则见上节 | 生命树；更多陷阱类 |
| 可视区拾取物 | 生命回复、临时力量、临时牌·投斧 | 更多临时牌与组合掉落 |
| 临时覆盖 | 无（燃烧等由卡牌直接施加状态） | 火焰、冰面、电场、毒雾、圣域 |
| 改装动作 | 破坏 **高台**（指定牌）；攻击穿透并削减 **废墟 HP** | 生成、覆盖、转化、推动、引爆及元素连锁 |

遭遇场景比例见 [`../遭遇系统/Feature-遭遇与原型战斗设计.md`](../遭遇系统/Feature-遭遇与原型战斗设计.md) §3.2。

#### 基础地形池

| 地形 | 移动影响 | 战斗影响 | 改装或组合方向 |
| --- | --- | --- | --- |
| 普通地面 | 正常通行 | 无 | 可建造、覆盖；其上可生成拾取物 |
| **高台** | 不可通行 | **阻挡 LOS**；仅 **指定效果** 破坏 | 章节石台、生命树（Post-MVP） |
| **废墟** | 不可通行 | **攻击可穿透**；有 **HP**；归零移除可掉落 | 木箱；落岩底牌 |
| 深坑 | 不可主动进入 | 击退落点高额伤害 | 遭遇布局 |
| 水域 | 额外限制移动或冲撞 | 与电、冰、火产生交互 | 冰冻、通电、蒸发 |
| 泥地/毒沼 | 移动受阻 | 施加残废或中毒 | 可净化、点燃或种植 |
| 植物地 | 通行 | 德鲁伊和藤蔓效果强化 | 可生长为阻挡物或被焚毁 |

#### 临时覆盖效果

| 覆盖 | 建议效果 | 典型反应 |
| --- | --- | --- |
| 火焰 | 进入或回合开始时获得燃烧 | 水域使火焰熄灭或生成蒸汽遮挡 |
| 冰面 | 移动结束后可能沿方向滑行一格 | 火焰融化为水域 |
| 电场 | 进入或停留时受到感电影响 | 水域扩大影响区域 |
| 毒雾 | 回合结束时施加中毒 | 火焰可引爆并清除毒雾 |
| 圣域 | 友方获得恢复/净化或敌方受到削弱 | 被污染效果覆盖或破坏 |

#### 地形改装动作

| 操作 | 含义 | 示例 |
| --- | --- | --- |
| 生成 | 在满足条件的格子创造新内容 | 种下一块植物地；升起一面 **高台** |
| 覆盖 | 为地面附加临时区域效果 | 点燃三格直线；生成圣域 |
| 转化 | 将现有地形换为另一种地形 | 水域冻结；毒沼净化 |
| 破坏 | 清除构筑物或危险覆盖 | 指定牌破坏 **高台**；攻击削减 **废墟 HP** |
| 推动 | 改变可互动构筑物的位置 | 将箱子推入通道形成掩体 |
| 引爆 | 消耗地形换取即时强效果 | 引燃毒雾；摧毁藤蔓造成束缚 |

### 3.2 状态与流转

本系统以格子三层状态组合描述战场；临时覆盖通常带持续回合或传播规则，具体持续时间见调参项与 Content 编排。

## 4. 边界情况

- **战场上必须始终保留可到达的有效战斗区域**，避免双方被永久隔离。
- **即时致死的坑落、连锁爆炸等效果**需要有明确预览与敌我一致的规则。
- **大范围持续地形**应有持续时间、清除手段或覆盖上限。
- **首个原型不追求完整元素模拟**，优先验证可读性和收益感。

## 9. 验收标准

- **GIVEN** 玩家移动进入含可视区拾取物的空格，**WHEN** 移动结算完成，**THEN** 拾取物效果触发且仅对玩家生效。
- **GIVEN** 击退使单位撞上 **废墟**，**WHEN** 位移结算结束，**THEN** 废墟按 HP/碰撞规则扣减或移除，且单位停于合法前一格。
- **GIVEN** 直线/远程攻击路径上有 **废墟**，**WHEN** 伤害结算完成，**THEN** 攻击 **穿透** 并对废墟 **扣 HP**（格内单位仍正常受伤）。
- **GIVEN** 攻击路径被 **高台** 遮挡，**WHEN** 判定 LOS，**THEN** 远程/直线攻击 **不可** 穿透高台格。
- **GIVEN** 废墟 **HP 归零**，**WHEN** 移除完成，**THEN** 可生成掉落拾取物。
- **GIVEN** 火焰覆盖与水域相邻，**WHEN** 触发典型反应规则，**THEN** 按本文临时覆盖反应表结算（如熄灭或蒸汽）。
- **GIVEN** 改装可能导致双方无法接触，**WHEN** 系统检测封路，**THEN** 拒绝该改装或提供强制可达保障。
