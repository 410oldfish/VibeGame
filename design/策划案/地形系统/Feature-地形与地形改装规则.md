# 《VibeGame》地形与地形改装规则

> **文档状态**：草案 v0.4  
> **Layer**：Feature
> **Priority**：MVP  
> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> **Quick reference**：关键依赖 六边形战斗规则、卡牌构筑、状态效果、冒险

## Summary

地形系统定义战场三层地形结构、基础地形池、临时覆盖与六种改装动作的统一语义。地形是可运营资源，支持路径、风险与构筑路线的变化；章节具体场景编排见冒险 Feature 层文档。

## 1. 文档定位

本文件是地形系统的主文档，负责定义战场地形的组织方式、地形改装动作和地形对其他系统的影响边界。

本文件负责：

- 地形分层模型。
- 基础地形池与临时覆盖层。
- 地形改装动作。
- 地形反应与封路约束的设计边界。

本文件不负责：

- 六边形路径本身的公共定义。
- 某个职业如何具体利用地形。
- 奖励投放节奏和章节场景编排。
- 单个构筑物实例的 **完整互动表**（见 [`Feature-构筑物互动图鉴.md`](Feature-构筑物互动图鉴.md)）。

## 2. 玩家体验目标

- 让地形从静态障碍升级为可生成、破坏、转化和组合利用的战斗资源。
- 让玩家能够通过提前铺设和临场改造创造优势回合。
- 让地形与移动、敌方意图、状态和构筑路线形成稳定联动。
- 改装动作必须有限且可读，避免组合失控。
- 地形收益应支持击退陷阱、火焰传播、防线堡垒、生长领域、水电控制等构筑路线。

## 3. 详细设计

### 3.1 核心规则

#### 地形的三层结构

为避免组合规则失控，一个格子最多由三层信息共同决定：

| 层级 | 英文 | 含义 | 示例 |
| ---- | --- | ---- | ---- |
| **Zone（区域/地面属性）** | `HexTerrainZoneType` | 决定基本通行与固有落点规则；**不是**构筑物 | 普通地面 `Normal`、深坑 `Pit`、水域（Post-MVP） |
| **构筑物** | `Barrier` / `Ruin` + `propId` | 可生成/破坏的实体，占格并提供遮挡 | **障碍**、**残骸**（木箱、石台…） |
| **临时覆盖** | overlay / effects | 具有持续回合或传播规则的效果 | 火焰、毒雾、冰面、圣域、电场 |

同一层通常只保留一种状态；跨层反应通过明确规则表处理。

**Zone 与构筑物分离**：深坑等属于 **Zone 地面属性**，不得建模为「地面之上的障碍/残骸」。单位能否进入由 `Zone` 通行规则与是否存在构筑物共同决定。

#### 构筑物分型：障碍 vs 残骸

> **英文 enum**：`Barrier` \| `Ruin`。Content 配置键建议 `barrier:` / `ruin:`。

构筑物层分两类，**视线、破坏与击退交互不同**；二者 **均不可移动穿过、不可站立**（单位 **不能** 进入构筑物格）。

| 类型 | 含义 | 示例 | 通行 / 站立 | 破坏方式 |
| --- | --- | --- | --- | --- |
| **障碍**（Barrier） | 实心挡格；**阻挡视线与远程/直线攻击穿透** | 章节石台、石墙、**生命树**（Post-MVP） | **不可**穿过；**不可**站立 | **无 HP**；**不可**被普通攻击破坏；**仅**「破坏障碍/特殊行动」类效果 |
| **残骸**（Ruin） | 可互动、有耐久、可穿透射击 | **木箱**、碎木堆、吧台栏、落岩碎块 | **不可**穿过；**不可**站立 | **有 HP**；攻击可 **穿透**并对残骸扣血；HP **归零**移除；击退撞上按 Content 配置 |

- 遭遇/layout 分别标注 `barrier:` / `ruin:`（或中文 **障碍** / **残骸**）；二者 **不可**混称。
- 历史命名：**高台 / 废墟**（v0.3）→ 现 **障碍（Barrier）/ 残骸（Ruin）**；见 [`Feature-卡牌与敌人设计灵感来源.md`](../设计规范/Feature-卡牌与敌人设计灵感来源.md) §5。

**敌人条目 override：活体构筑物**

[`Feature-活墙壁.md`](../敌人系统/敌人条目/已投入使用并实现/Feature-活墙壁.md) 使用“活体构筑物”规则。它仍是敌方单位，不占用格子的 `Barrier / Ruin` 构筑物枚举；空间上按实体障碍处理，并额外具有 `BarrierTarget`、`RuinTarget` 两个交互标签，使两类破坏效果都可选中。其生命、占地、破坏替代伤害与移除规则完全由敌人条目负责，不继承普通残骸 HP、攻击穿透或掉落规则。

**残骸默认 HP（Content）**：MVP 建议 **4**（木箱类）；精英/首领放置的可调至 **6~8**。具体实例 HP 与 `onRemove` 见 [`Feature-构筑物互动图鉴.md`](Feature-构筑物互动图鉴.md)。

#### 构筑物实例层（Content）

**类型**（障碍/残骸）决定 LOS、HP、破坏方式；**实例**（`propId`）决定 **移除后果、受击/碰撞、邻接光环、敌人联动**。

| 层级 | 负责文档 | 示例 |
| --- | --- | --- |
| 分型规则 | 本文 §3.1 | Barrier 挡 LOS；Ruin 有 HP 可穿透 |
| 实例图鉴 | [`Feature-构筑物互动图鉴.md`](Feature-构筑物互动图鉴.md) | `wood_crate`、`life_tree_bough`、`bone_pile` |
| 遭遇引用 | 遭遇 / layout | `propId: wood_crate` |

**移除后果**（实例配置，非全局）：

| 类型 | 常见 `onRemove` |
| --- | --- |
| 拾取 | `field_pickup` 生命/力量/临时牌 |
| 区域 | `temp_overlay` 治疗雾气、圣域、火焰… |
| 战斗 | `spawn_unit`、`area_damage`、`enemy_trigger` |
| 战后 | `postBattleReward`：**宝箱** HP 归零后 **不** 生成战场拾取，改为战斗结束发放金币/卡牌（见图鉴 `treasure_chest`） |
| 延迟引爆 | `fuseTurns`：**火药桶** 等受击 **`arm`** 后 **下回合开始** 引爆（`area_damage`）；Presentation 显示引信 |
| 联动 | `adjacentAura` 亡灵邻接骸骨堆回血 |

#### 破坏、视线与移除

| 动作 | 障碍 | 残骸 |
| --- | --- | --- |
| 移动穿过 | **否** | **否** |
| 单位站立该格 | **否** | **否** |
| 远程/直线攻击 **穿透**该格 | **否**（阻挡 LOS；见 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md)） | **是**（对格内 **单位** 正常结算；同时对 **残骸 HP** 扣伤） |
| 普通攻击命中该格（无单位） | 无效 | 对残骸 **扣 HP** |
| 「破坏障碍」类效果 | **移除** | 不生效（除非牌面写「破坏残骸」） |
| 击退路径终点为该格 | **撞障碍**：停前一格，障碍 **不**移除 | **撞残骸**：停前一格；残骸 **−1 HP** 或 Content 配置额外碰撞伤 |
| 移除后 | 基础地面保留；默认 **无** 掉落 | 基础地面保留；**可**生成 **可视区拾取物** |

#### 击退与残骸

击退/拉拽/冲撞结算时：

1. **残骸与障碍均视为 solid 地形**（占用格子、不可穿越、不可站立）。
2. 强制移动 **因残骸/障碍终止**（单位停在前一格，或该格为终点）：
   - **残骸**：按上表扣 HP 或移除；触发 **碰撞** 衍生效果（若有）。
   - **障碍**：**不**移除；仅 **撞障碍** 规则（停步、伤害、眩晕等，见单位状态登记）。
3. **障碍** 被击退撞上时：**永不**因碰撞移除。
4. 攻击 **穿透** 残骸格时：先对路径上 **单位** 结算，再对 **残骸 HP** 结算（同一次攻击可多次穿透多格残骸，按 Content）。

#### 可视区拾取物（Field Pickup）

部分 **残骸**（及 Content 配置的障碍）**被破坏或移除后**，在同格（或配置相邻格）生成 **可视区拾取物**——战场上的独立图标，**不是** 构筑物层。

| 规则 | 说明 |
| --- | --- |
| 可见性 | 全战场可见；Presentation 层需与地形/单位分层显示 |
| 拾取方式 | **玩家** 以主动或强制移动 **进入** 该格时 **立即拾取**；**敌人不拾取** |
| 同格优先级 | 单位占位与拾取物可共存规则：**进入空格且存在拾取物** → 先拾取再完成停留；该格若无构筑物则正常站位 |
| 拾取后 | 拾取物消失；效果立即结算 |
| 战斗结束 | 未拾取物 **清除**，不带入下一场 |

**拾取效果类型（Content 配置）**

| 效果 ID | 说明 | 示例数值 |
| --- | --- | --- |
| **生命回复** | 恢复生命 | +15 生命 |
| **临时力量** | 通过统一临时力量入口获得；使用“本场战斗末”生命周期，**本场战斗结束** 清除 | +2 力量 |
| **临时牌** | 向本场 **`临时牌池`** 加入 1 张牌；**不** 进入持久牌组；战斗结束移除 | 见下表 |

**临时牌（本场）**

| 牌名 | 费用 | 范围 | 效果 | 特殊规则 |
| --- | ---: | --- | --- | --- |
| 投斧 | 1 | 射程3 | **10** 伤 | 打出并结算后，**下回合开始时** 回到手牌（本场可重复循环） |

- 临时牌加入位置：默认 **洗入抽牌堆** 或 **直接入手**（由掉落表配置）；实现需与 [`Core-卡牌与构筑系统设计.md`](../卡牌构筑系统/Core-卡牌与构筑系统设计.md) 牌区扩展 **`临时牌池`**。
- 更多临时牌在 Content 掉落表中扩展；词条登记见 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §3.3。

#### 基础地形池

| 地形 | 移动影响 | 战斗影响 | 改装或组合方向 |
| --- | --- | --- | --- |
| 普通地面 | 正常通行 | 无 | 可建造、覆盖；其上可生成拾取物 |
| **障碍** | 不可通行 | **阻挡 LOS**；仅 **指定效果** 破坏 | 章节石台、生命树（Post-MVP） |
| **残骸** | 不可通行 | **攻击可穿透**；有 **HP**；归零移除可掉落 | 木箱；落岩底牌 |
| 深坑 | 不可主动进入 | 击退落点高额伤害 | 遭遇布局 |
| 水域 | 额外限制移动或冲撞 | 与电、结冰地形、火产生交互 | 结冰地形转化、通电、蒸发 |
| 泥地/毒沼 | 移动受阻 | 施加束缚或中毒 | 可净化、点燃或种植 |
| 植物地 | 通行 | 德鲁伊和藤蔓效果强化 | 可生长为阻挡物或被焚毁 |

#### 临时覆盖效果

| 覆盖 | 建议效果 | 典型反应 |
| --- | --- | --- |
| 火焰 | 进入或回合开始时获得燃烧 | 水域使火焰熄灭或生成蒸汽遮挡 |
| 冰面 | 移动结束后可能沿方向滑行一格 | 火焰融化为水域 |
| 电场 | 进入或停留时受到感电影响 | 水域扩大影响区域 |
| 毒雾 | 回合结束时施加中毒 | 火焰可引爆并清除毒雾 |
| 圣域 | 友方获得恢复/净化或敌方受到削弱 | 被污染效果覆盖或破坏 |

#### 地形改装动作

| 操作 | 含义 | 示例 |
| --- | --- | --- |
| 生成 | 在满足条件的格子创造新内容 | 种下一块植物地；升起一面 **障碍** |
| 覆盖 | 为地面附加临时区域效果 | 点燃三格直线；生成圣域 |
| 转化 | 将现有地形换为另一种地形 | 水域冻结；毒沼净化 |
| 破坏 | 清除构筑物或危险覆盖 | 指定牌破坏 **障碍**；攻击削减 **残骸 HP** |
| 推动 | 改变可互动构筑物的位置 | 将箱子推入通道形成掩体 |
| 引爆 | 消耗地形换取即时强效果 | 引燃毒雾；摧毁藤蔓造成束缚 |

本系统以格子三层状态组合描述战场；临时覆盖通常带持续回合或传播规则，具体持续时间见调参项与 Content 编排。

## 4. 边界情况

- **战场上必须始终保留可到达的有效战斗区域**，避免双方被永久隔离。
- **即时致死的坑落、连锁爆炸等效果**需要有明确预览与敌我一致的规则。
- **大范围持续地形**应有持续时间、清除手段或覆盖上限。
- **首个原型不追求完整元素模拟**，优先验证可读性和收益感。

## 9. 验收标准

- **GIVEN** 玩家以主动或强制移动进入含可视区拾取物的空格，**WHEN** 移动结算完成，**THEN** 拾取物效果触发且仅对玩家生效。
- **GIVEN** 击退使单位撞上 **残骸**，**WHEN** 位移结算结束，**THEN** 残骸按 HP/碰撞规则扣减或移除，且单位停于合法前一格。
- **GIVEN** 直线/远程攻击路径上有 **残骸**，**WHEN** 伤害结算完成，**THEN** 攻击 **穿透** 并对残骸 **扣 HP**（格内单位仍正常受伤）。
- **GIVEN** 攻击路径被 **障碍** 遮挡，**WHEN** 判定 LOS，**THEN** 远程/直线攻击 **不可** 穿透障碍格。
- **GIVEN** 残骸 **HP 归零**，**WHEN** 移除完成，**THEN** 可生成掉落拾取物。
- **GIVEN** 火焰覆盖与水域相邻，**WHEN** 触发典型反应规则，**THEN** 按本文临时覆盖反应表结算（如熄灭或蒸汽）。
- **GIVEN** 改装可能导致双方无法接触，**WHEN** 系统检测封路，**THEN** 拒绝该改装或提供强制可达保障。
