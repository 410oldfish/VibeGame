# 《VibeGame》卡牌与构筑系统设计

> **文档状态**：草案 v0.3  
> **Layer**：Core
> **Priority**：MVP  
> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> **Quick reference**：关键依赖 职业系统、奖励成长、战斗系统

## Summary

卡牌与构筑系统定义玩家牌组的生命周期、牌区流转与能量/体力/生命/格挡等资源关系。它连接职业身份与战斗出牌，不负责职业共性、战斗时序或奖励投放节奏。

## 1. 文档定位

本文件是卡牌与构筑系统的主文档，负责定义玩家牌组的生命周期、牌区流转、资源关系以及构筑成长方向。

本文件负责：

- 玩家牌组在战斗中的进入、流转与清理规则。
- 牌区的职责划分。
- 能量、体力、生命与防御资源之间的关系。
- 构筑标签与构筑成长方向。

本文件不负责：

- 职业共性规则与职业选择入口。
- 战斗公共时序与空间规则。
- 奖励池的具体投放节奏。

## 2. 玩家体验目标

- 让构筑成长服务于战术身份，而不是单纯堆叠伤害数字。
- 让玩家每回合同时考虑卡牌价值与空间价值。
- 让牌组成长能够围绕位置、地形和敌方牌局形成不同路线。
- 牌序与空间共同决定回合质量：不仅看抽到什么牌，还要看站在哪里、能否移动到更优位置。
- 构筑强化战场规则的选择方式，如冲撞、守点、地形扩张、敌方牌局干涉等路线。

## 3. 详细设计

### 3.1 核心规则

#### 玩家牌组生命周期

- 玩家进入战斗时，以当前局外牌组初始化战斗牌组。
- 战斗中获得的临时卡牌默认只在本场战斗生效。
- 战斗结束后，临时牌与战斗期临时变化默认清除，局外牌组回到冒险层继续使用。

#### 牌区划分

| 牌区 | 作用 |
| --- | --- |
| 抽牌堆 | 存放当前待抽取的卡牌 |
| 手牌 | 当前可使用的卡牌 |
| 弃牌堆 | 已打出或回合结束被弃掉的卡牌 |
| 消耗牌堆 | 因消耗、虚无等机制暂离本场循环的卡牌 |

基础流转方向：

- 抽牌堆 -> 手牌
- 手牌 -> 弃牌堆 / 消耗牌堆
- 弃牌堆 -> 抽牌堆（重洗）

#### 卡牌功能维度

| 功能 | 作用 |
| --- | --- |
| 攻击牌 | 直接伤害、属性伤害、状态施加、击退与连击 |
| 防御牌 | 格挡、减伤、护卫、净化、移动救援 |
| 技能牌 | 抽牌、能量、体力、职业形态、敌方牌组干涉 |
| 移动牌 | 免费移动、跳跃、冲撞、交换位置、强制位移 |
| 地形牌 | 生成、转化、强化、破坏或引爆地形 |

「移动牌」和「地形牌」更适合作为设计标签，而不是绝对隔离的卡种。

#### 构筑标签与体系

- 局外牌组按 **职业体系** 组织凑链能力；体系维度约束与 **事件链数值联动** 见 [`../设计规范/Foundation-卡牌与角色五维设计.md`](../设计规范/Foundation-卡牌与角色五维设计.md) §8.2~§8.3。
- **词缀** 全局语义见 [`../设计规范/Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md)（单牌 **最多 3 个**）。
- 战士 **事件节点** 见 [`Feature-战士事件节点.md`](../职业系统/战士/Feature-战士事件节点.md)（四体系各 1 个 ID）。
- 单职业体系明细见战士目录（[`Feature-战士.md`](../职业系统/战士/Feature-战士.md) §6 及四体系 + 过渡文档）。
- 战斗实现需支持：`体系标签`、`链角色`、`词缀列表`、`战士事件`、`武器需求`、收束 **链收益乘数** `M(n)` 结算。

#### 资源关系

| 资源 | 主要用途 | 设计意义 |
| --- | --- | --- |
| 能量 | 出牌、主动技能 | 限制单回合卡牌组合上限 |
| 体力 | 主动移动、部分位移强化效果 | 限制位置调整次数，突出路线选择 |
| 生命 | 跨战斗生存资源 | 支撑路线抉择、恢复与风险收益判断 |
| 护甲/格挡 | 当前战斗内防御资源 | 允许玩家承受公开威胁或守住关键格 |

#### 玩家基础卡牌数值基准

玩家基础攻击、防御与移动牌的当前数值标尺，独立记录于 [`Core-玩家基础卡牌数值基准.md`](Core-玩家基础卡牌数值基准.md)。费用操控与抽牌运转的基础数值仍待补充。

### 3.2 状态与流转

| 牌区 | 典型进入 | 典型离开 |
| --- | --- | --- |
| 抽牌堆 | 初始化、弃牌堆洗入 | 抽牌至手牌 |
| 手牌 | 抽牌 | 打出、保留、弃置 |
| 弃牌堆 | 打出、回合结束弃牌 | 洗回抽牌堆 |
| 消耗牌堆 | 消耗/虚无机制 | 战斗结束清除 |

### 3.3 与其他系统的交互

| 类型 | 主要内容 |
| --- | --- |
| 上游依赖 | 职业选择、奖励投放、状态与技能效果、战斗公共时序 |
| 系统产出 | 玩家牌组、牌区状态、资源消耗关系、构筑成长方向 |
| 下游影响 | 战斗系统中的出牌组合、地形系统中的改装手段、敌人系统中的干涉能力 |

## 9. 验收标准

- **GIVEN** 玩家带着局外牌组进入战斗，**WHEN** 战斗初始化完成，**THEN** 战斗牌组由局外牌组正确生成。
- **GIVEN** 战斗中获得临时卡牌，**WHEN** 战斗结束，**THEN** 临时牌默认不保留在局外牌组。
- **GIVEN** 抽牌堆为空且弃牌堆有牌，**WHEN** 需要继续抽牌，**THEN** 弃牌堆洗入抽牌堆后继续流转。
