# 《VibeGame》卡牌与构筑系统设计

> **文档状态**：草案 v0.3  
> **Layer**：Core
> **Priority**：MVP  
> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> **Quick reference**：关键依赖 职业系统、奖励成长、战斗系统

## Summary

卡牌与构筑系统定义玩家牌组的生命周期、牌区流转与能量/体力/生命/格挡等资源关系。它连接职业身份与战斗出牌，不负责职业共性、战斗时序或奖励投放节奏。

## 1. 文档定位

本文件是卡牌与构筑系统的主文档，负责定义玩家牌组的生命周期、牌区流转、资源关系以及构筑成长方向。

本文件负责：

- 玩家牌组在战斗中的进入、流转与清理规则。
- 牌区的职责划分。
- 能量、体力、生命与防御资源之间的关系。
- 构筑标签与构筑成长方向。

本文件不负责：

- 职业共性规则与职业选择入口。
- 战斗公共时序与空间规则。
- 奖励池的具体投放节奏。

## 2. 玩家体验目标

- 让构筑成长服务于战术身份，而不是单纯堆叠伤害数字。
- 让玩家每回合同时考虑卡牌价值与空间价值。
- 让牌组成长能够围绕位置、地形和敌方牌局形成不同路线。
- 牌序与空间共同决定回合质量：不仅看抽到什么牌，还要看站在哪里、能否移动到更优位置。
- 构筑强化战场规则的选择方式，如冲撞、守点、地形扩张、敌方牌局干涉等路线。

## 3. 详细设计

### 3.1 核心规则

#### 玩家牌组生命周期

- 玩家进入战斗时，以当前局外牌组初始化战斗牌组。
- 战斗中获得的临时卡牌默认只在本场战斗生效。
- 战斗结束后，临时牌与战斗期临时变化默认清除，局外牌组回到冒险层继续使用。

#### 牌区划分

| 牌区 | 作用 |
| --- | --- |
| 抽牌堆 | 存放当前待抽取的卡牌 |
| 手牌 | 当前可使用的卡牌 |
| 弃牌堆 | 已打出或回合结束被弃掉的卡牌 |
| 消耗牌堆 | 因消耗、虚无等机制暂离本场循环的卡牌 |
| **能力区** | **类别=能力** 的牌打出后驻留；本场生效，战斗结束清除 |
| **临时牌池** | 本场战斗内由掉落、技能等 **临时加入** 的卡牌（如 **投斧**）；**不** 进入持久牌组；战斗结束清空 |

基础流转方向：

- 抽牌堆 -> 手牌
- 手牌 -> 弃牌堆 / 消耗牌堆 / **能力区**
- 弃牌堆 -> 抽牌堆（重洗）
- **临时牌池** -> 抽牌堆或直接入手（由来源配置；如可视区拾取物）

#### 玩家回合基准牌

每名玩家在 **每场战斗的每个玩家回合**，于 **资源恢复** 阶段（常规抽牌完成之后）向 **手牌** 加入 **1 张** **快步** 的 **临时实例**：

| 字段 | 值 |
| --- | --- |
| **卡牌名称** | **快步** |
| **卡牌描述** | 移动 **1** 格（卡牌移动；路径与占位见六边形战斗规则） |
| **费用** | **1** 能量 |
| **范围** | — |
| **词缀** | **首发** |
| **类别** | **行动** |
| **子类别** | **纯粹移动** |
| **所属体系** | **无** |
| 牌组归属 | **不** 属于局外/战斗牌组；每回合新生成，**不** 进入抽牌堆循环 |

**移出游戏**（本场该实例销毁，不进弃牌堆、不洗回抽牌堆）：

| 时机 | 行为 |
| --- | --- |
| 作为本回合 **第一张打出的牌** 并结算完成 | 发动移动效果后 **移出游戏** |
| 本回合已打出 **任意其他牌** 后，该牌仍在手牌 | **立即移出游戏**（不发动效果、不返还已付费用——因尚未打出该牌） |
| 玩家回合结束，该牌仍在手牌 | **移出游戏**（本回合未作为第一张打出） |

**与其他规则的关系**：

- **体力主动移动** 不算「打出牌」；可在打出或弃置 **快步** 前后照常使用（仍受每回合 1 次体力移动上限约束）。
- 战士 **`位移`** 事件：快步的牌面移动计入「主动移动 ≥1 格」，见 [`Feature-战士事件节点.md`](../职业系统/战士/Feature-战士事件节点.md)。
- 联机 Post-MVP：每名玩家各自获得 1 张 **快步** 实例。

词条登记与验收见 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §4、§6、§8~§10。

#### 类别与功能标签

**类别**（必填配置字段）为全局权威分类，定义见 [`Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md) §4：

| 玩家类别 | 敌人类别 |
| --- | --- |
| 行动、攻击、技能、能力、诅咒、状态 | 行动、攻击、技能、能力 |

- 每张可配置卡牌 **有且仅有 1 个类别**；复合效果按 Foundation §4.3 判定。
- **五维**（输出/生存/移动/费用/抽牌运转）与类别 **独立**：五维描述策略价值，类别描述系统类型与 UI/结算分类。
- **子类别**、**所属体系** 见 Foundation §7；战士牌必填，敌人牌可省略。

**功能标签**（旧称「攻击牌/移动牌/地形牌」等）仅作 **可选设计备注**，**不** 替代 `类别`。新内容以类别为准：

| 旧功能标签 | 对应类别 |
| --- | --- |
| 移动牌、地形牌（改场/破障） | **行动** |
| 攻击牌 | **攻击** |
| 防御牌、抽牌/引擎牌 | **技能** |
| 常驻 buff 牌 | **能力** |
| 污染 token | **诅咒** / **状态** |

#### 构筑标签与体系

- 局外牌组按 **职业体系** 组织凑链能力；体系维度约束与 **事件链数值联动** 见 [`../设计规范/Foundation-卡牌与角色五维设计.md`](../设计规范/Foundation-卡牌与角色五维设计.md) §8.2~§8.3。
- **词缀** 全局语义见 [`../设计规范/Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md)（单牌 **最多 3 个**）。
- 战士 **事件节点** 见 [`Feature-战士事件节点.md`](../职业系统/战士/Feature-战士事件节点.md)（MVP 三体系各 1 个 ID；位移 Post-MVP）。
- 战士 **全部卡牌** 见 [`Feature-战士卡牌.md`](../职业系统/战士/Feature-战士卡牌.md)（基础 / 过渡 / 体系）。
- 战斗实现需支持：`类别`、`子类别`、`所属体系`、`卡牌描述`、`预期前置事件数量`、`词缀列表`、`范围`、收束 **链收益乘数** `M(n)` 结算；事件 ID 见 [`Feature-战士事件节点.md`](../职业系统/战士/Feature-战士事件节点.md)。完整条目字段见 Foundation 词缀 §7。

#### 资源关系

| 资源 | 主要用途 | 设计意义 |
| --- | --- | --- |
| 能量 | 出牌、主动技能 | 限制单回合卡牌组合上限 |
| 体力 | 主动移动、部分位移强化效果 | 限制位置调整次数，突出路线选择 |
| 生命 | 跨战斗生存资源 | 支撑路线抉择、恢复与风险收益判断 |
| 护甲/格挡 | 当前战斗内防御资源 | 允许玩家承受公开威胁或守住关键格 |

### 3.2 状态与流转

| 牌区 | 典型进入 | 典型离开 |
| --- | --- | --- |
| 抽牌堆 | 初始化、弃牌堆洗入 | 抽牌至手牌 |
| 手牌 | 抽牌 | 打出、保留、弃置 |

## 9. 验收标准

- **GIVEN** 玩家带着局外牌组进入战斗，**WHEN** 战斗初始化完成，**THEN** 战斗牌组由局外牌组正确生成。
- **GIVEN** 战斗中获得临时卡牌，**WHEN** 战斗结束，**THEN** 临时牌默认不保留在局外牌组。
- **GIVEN** 抽牌堆为空且弃牌堆有牌，**WHEN** 需要继续抽牌，**THEN** 弃牌堆洗入抽牌堆后继续流转。
- **GIVEN** 玩家回合资源恢复完成，**WHEN** 进入行动窗口，**THEN** 手牌含 **1 张快步** 临时实例。
- **GIVEN** 本回合第一张打出的是 **快步**，**WHEN** 移动结算完成，**THEN** 该实例移出游戏且不进弃牌堆。
- **GIVEN** 本回合已打出其他牌且 **快步** 仍在手牌，**WHEN** 该其他牌结算完成，**THEN** **快步** 立即移出游戏。
