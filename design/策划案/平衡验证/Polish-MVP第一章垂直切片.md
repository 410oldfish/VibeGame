> **文档状态**：草案 v1.0

## Summary

本文件是 **MVP 第一章** 的单一真相源：参照游戏取舍、In/Out 边界、必须实现的状态与地形、数值锚点与验收标准。Feature 层具体内容见各系统子文档；实现与测试以本文为准。

## 1. 参照游戏与取舍

| 维度 | 杀戮尖塔 | 斗技场的阿丽娜 | 本项目 MVP 取舍 |
| --- | --- | --- | --- |
| 路线 | 分支地图、节点类型固定 | 关卡式推进、网格站位核心 | 保留 StS 式 `10×4` 与节点类型；**空间决策**向阿丽娜看齐（六边形移动与出牌同权） |
| 火堆 | 回血 / 升牌 /（铁匠） | 休息恢复 | MVP：**回血 + 升牌二选一**；铁匠/合成延后 |
| 商人 | 卡牌、删牌、药水 | 有限商店 | MVP：**6 格卡牌 + 删牌服务**；装备/附魔/地形道具延后 |
| 事件 | 大事件池、长期风险 | 较少 | MVP：**5 个第一章事件** + 地图权重；全池扩展 Post-MVP |
| 战斗奖励 | 三选一卡牌 + 金币 | 技能/装备 pick | MVP：**三选一战士牌** + 金币；精英提高稀有权重 |

**不照搬边界**

- 无 StS 遗物层：MVP 不做独立遗物系统。
- 敌人用「牌组 + 公开意图」，而非 StS 固定行为树。
- 地形/改装为本作差异化；MVP 以 **减益燃烧 + 塞牌恐惧 + 卖血流血** 为核心 subset（位移撞墙 Post-MVP）。
- MVP 阶段 **不做联机**；单人战士闭环优先，合作模式 Post-MVP。

## 2. MVP In / Out 清单

### 2.1 纳入 MVP

| 模块 | 内容 |
| --- | --- |
| 职业 | 仅战士；见 [`Feature-战士.md`](../职业系统/战士/Feature-战士.md) 及体系文档 |

| 奖励 | 战斗三选一 + 金币；商店买牌/删牌；火堆回血或升牌；5 个事件 |
| 地形 | 普通地面、深坑、高台/废墟、可视区拾取物；规则见 [`Feature-地形与地形改装规则.md`](../地形系统/Feature-地形与地形改装规则.md) |
| 状态 | 见 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §2（9 种单位状态） |
| 玩家基准牌 | 每回合手牌 **快步**（1 费移动 1，**首发**）；见词条登记 §6 |
| 模式 | 单人 |

### 2.2 Post-MVP（明确不做）

- 骑士、德鲁伊及第二/三章完整内容
- 副职业奖励、工作台合成、附魔、情报服务、大量地形道具
- 水域/电场/感电连锁、火焰传播、动态天气
- 联机合作、Host 迁移、公开匹配
- Foundation 状态表中标注为 `延后` 的全部状态

## 8. 验收标准

- **GIVEN** 新局选择战士，**WHEN** 沿第一章路线推进，**THEN** 可经历至少 1 次商店、1 次火堆、1 次事件，并完成章首领战。
- **GIVEN** 任意 MVP 卡牌/敌人/事件，**WHEN** 查 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md)，**THEN** 不引用 §2~§10 未登记词条。
- **GIVEN** MVP 战士/敌人卡牌配置，**WHEN** 导出或验收，**THEN** 每张牌含合法 **`类别`**（玩家 6 类 / 敌人 4 类，见词条登记 §8）。
- **GIVEN** MVP 战士卡牌配置，**WHEN** 导出或验收，**THEN** **`子类别`** 与 **`所属体系`** 组合合法（见 Foundation 词缀 §7）；**`卡牌描述`** 非空。
- **GIVEN** 第一章战斗，**WHEN** 查地形，**THEN** 仅出现词条登记 §3.1 所列地形。
- **GIVEN** MVP 构建，**WHEN** 进入职业选择，**THEN** 仅战士可选；联机入口不可用或隐藏。
- **GIVEN** 玩家回合开始，**WHEN** 资源恢复完成，**THEN** 手牌获得 **快步**；若本回合先打其他牌，**THEN** **快步** 移出游戏。
- **GIVEN** MVP 四名敌人（哥布林、投矛、队长、酋长），**WHEN** 查各 Feature §槽位与意图规则，**THEN** `每回合槽位` 落在遭遇类型上限内且含 `意图抽牌规则` / `意图执行规则`。
