# 《VibeGame》原型数值与测试观察点

> 文档状态：草案 v0.3  
> **Layer**：Polish  
> **Priority**：MVP  
> 文档定位：本文件属于平衡与验证层，不是玩法系统规则源。  
> 关联总案：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> MVP 锚点：[`Polish-MVP第一章垂直切片.md`](Polish-MVP第一章垂直切片.md)

## 1. 文档目的

- 为 **MVP 第一章垂直切片** 提供可快速落地的初期数值假设。
- 明确测试时需要观察的关键指标与主观反馈点。
- 汇总仍需在原型或策划会议中拍板的关键问题。

## 2. 当前验证范围

本文件主要用于验证 **第一章完整闭环** 是否成立：

- 冒险路线：战斗 / 商店 / 火堆 / 事件 / 章首领。
- 战斗系统 + 敌人牌组意图（哥布林、投矛哥布林、队长、酋长）。
- MVP 地形子集（普通地面、**障碍/残骸**、深坑、可视区拾取物、撞障碍/破坏残骸）。
- 战士单职业卡牌构筑与奖励投放。
- **不含联机**（Post-MVP）。

## 3. 初期数值假设

下列为便于搭建原型的假设，不视为最终规则：

| 项目 | 初期假设 | 需观察的问题 |
| --- | --- | --- |
| 玩家能量 | 战士 `3` | 地形牌（Post-MVP）是否挤压攻防空间；MVP 以位移/冲撞牌为主 |
| 玩家体力 | 战士 `4` | 贴脸投矛哥布林时体力是否过紧 |
| 战士生命 | `70` | 火堆 30% 回血是否足够支撑到章末 |
| 火堆回血 | 最大生命 30% 向下取整 | 休息 vs 锻造的选取比例 |
| 删牌价格 | `75` 金 | 与全章金币总量是否匹配 |
| 商店卡牌价 | Common 50 / Uncommon 75 | 是否买得起关键 Uncommon |
| 普通/精英/首领金币 | 15–20 / 35–45 / 95–110 | 全章经济曲线 |
| 场地尺寸 | 约 25–45 有效六边形格 | 撞墙/深坑是否有足够舞台 |
| 敌方意图展示 | 意图槽（1~4）+ 槽位标签 + 目标/落点；可选执行顺序提示 | 信息是否足够规划 |
| 危险地形数量 | 深坑+墙合计约 40%（见遭遇编排表） | 是否影响决策但不锁死 |
| 哥布林队长生命 | `55`（待测） | 双路线是否均可行 |
| 部落酋长生命 | `120`（待测） | P2 震地后章通率 |

## 4. 测试记录重点

测试时应记录：

- 每回合平均移动格数与体力剩余量。
- 路线选择：商店/火堆/事件节点的访问率与顺序。
- 火堆选项分布（休息 vs 锻造）与章末剩余生命。
- 事件 E01–E05 各选项选取率。
- 精英战两种破解路径（rush 队长 vs 清随从）占比。
- 章通率、失败节点分布（精英 vs 酋长）。
- 因撞墙/深坑造成的击杀或大幅伤害占比。
- **体系收束链长**分布（n=0~1 为主）及 **减益/塞牌/卖血/位移** 收束占比。
- 玩家在 UI 上能否正确预判 `M(n)` 后的链收益（主观清晰度）。

## 5. 待确认事项

1. 部落酋长 P2「震地」转化障碍/放置残骸的随机规则：固定最近障碍 vs 真随机。
2. 哥布林队长召唤物生命 `15` 是否与精英难度匹配。
3. 战士 **9 张** 初始牌组（打击×4、防御×4、燃烧×1）是否需补第 10 张教学牌。
4. 删牌 75 金 vs 事件 E05 免费删牌+自伤的经济平衡。
5. 单人 MVP 通过后，联机合作的重启优先级与职业开放顺序。
6. **链倍率**：n=3 时 `M=5.0` 是否在精英/酋长战过强；n=4 上限是否需下调至 `M=5.5`。

## 6. 使用原则

- 每轮原型测试只集中验证少量变量，避免多个系统同时改动导致结论失真。
- 数值记录应同时包含可量化指标与玩家对「清晰度」「满足感」「压力感」的主观反馈。
- 当测试目标是验证系统可读性时，应优先控制复杂度，而不是追求内容丰富度。
