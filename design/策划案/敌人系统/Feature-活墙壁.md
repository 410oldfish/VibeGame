## 1. 敌人定位

活墙壁是 **站桩改地形** 敌人：不主动位移，通过 **生长障碍**、**挤压邻格** 与 **厚皮减伤** 封锁狭道。教会玩家 **破障**、绕 LOS 与 **残骸** 掉落规划。

**移动牌数量：0**（牌组无 **行动** 类别移动牌；条目注明以通过 Content 校验）。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 中低 | 邻格「挤压」与「刺击」 |
| 生存 | 高 | 「厚皮」减伤；「再生」回复 |
| 移动 | **无** | 不主动移动；靠地形扩张占格 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 低 | 抽空打出底牌「墙裂」：邻格放置 **障碍** |

## 3. 牌组构成

活墙壁牌组共 `11` 张牌：

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 刺击 | 攻击 | 3 | 输出 | 持续 | 对距离 1 的敌方单位造成 **5** 点伤害 |
| 根须刺 | 攻击 | 1 | 输出 | 持续 | 邻格 **4** 点伤害；若目标 **束缚** 再 **+3** |
| 挤压 | 攻击 | 2 | 移动 | 击退 | 对距离 1 造成 **3** 点伤害；**击退 1**（撞 **障碍** 停步） |
| 生长 | 技能 | 2 | 移动 | 占点 / 改地形 | 在自身 **距离 1** 内随机 **1** 个 **空格** 放置 **障碍** |
| 厚皮 | 技能 | 2 | 生存 | 拖战 | 获得 **8** 点格挡 |
| 再生 | 能力 | 1 | 生存 | 回复 | 回合开始时回复 **3** 点生命 |
| 合计 | 11 | — | — | — | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **普通**（单只）或 **精英**（多只 + 更高 HP，Content 配置） |
| `每回合槽位` | **1** |
| `槽位模板` | `攻击`（普通）或 `自由`（精英变体，见下） |
| `意图抽牌规则` | **引用** [`Pattern_Stationary`](Feature-敌人牌组与意图机制.md) §3.1 |
| `意图执行规则` | **引用** Pattern_Stationary（**固定 1 槽**，不重排） |
| `攻击范围判定` | **邻格 1** |

**精英 override**：`槽位模板` = `[自由]`；自由槽随机时 **50%** 权重优先抽「生长」（条目内联，仍仅 1 槽）。

## 5. 与障碍 / 残骸 / 构筑物交互

| 情况 | 处理 |
| --- | --- |
| 「生长」放置 **障碍** | 遵循 [`Feature-地形与地形改装规则.md`](../地形系统/Feature-地形与地形改装规则.md)；阻挡 LOS |
| 遭遇 **`propId: life_tree_bough`** / **`wood_crate`** | 哥布林狭道 / 森林场景可预置；生命树移除掉落 **`healing_orb`**，木箱 **`worn_weapon`**（见图鉴 §3） |
| 玩家 **破障** | 移除该格障碍；活墙壁 **不** 因此受伤 |
| 「挤压」击退撞 **障碍** | 目标停于障碍前；不破坏障碍 |
| 击退撞 **残骸** | 按 Content：残骸扣 HP 或额外伤害 |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 墙裂 |
| **类别** | **技能** |
| 效果类型 | 放置地形 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 自身 **距离 1** 内随机 **1** 个空格放置 **障碍**；若无合法空格，获得 **5** 点格挡 |
| 牌区处理 | 视为打出特殊牌，不加入常规牌组 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「刺击/挤压」无邻格目标 | 视为打出但无效果，进入弃牌堆 |
| 「生长」无合法空格 | 视为打出但无效果，进入弃牌堆 |
| 意图生成时抽牌堆不足 | 洗弃牌堆；抽空时打出底牌后继续补抽至 **1** 槽填满 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 玩家是否识别 **1 槽** 可读威胁 | 验证 Pattern_Stationary UI |
| 障碍扩张速率 vs 破障频率 | 验证地形封锁节奏 |
| 厚皮 + 再生是否过拖 | 精英时长调参 |
