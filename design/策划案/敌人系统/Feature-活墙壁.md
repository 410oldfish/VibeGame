## 1. 敌人定位

活墙壁是 **必定成对出现** 的多格移动敌人。每只活墙壁由一个 **本体格** 与多个 **衍生格** 组成，通过向配对墙推进、推动路径上的单位并最终闭合墙体，制造高威胁的夹击与封场。

活墙壁属于 **活体构筑物**：

- 在敌人系统中是拥有生命、牌堆和意图的敌方单位。
- 在空间规则中视为实体构筑物，占格、阻挡移动并阻挡 LOS。
- 同时带有 `BarrierTarget` 与 `RuinTarget` 交互标签，可被「破坏障碍」和「破坏残骸」效果选中；不同时继承 Barrier 与 Ruin 的完整地形数据规则。
- 初始体积为 **3 格**，最大体积为 **6 格**；所有衍生格必须与本体格保持六边形邻接连通。
- 两只初始活墙壁各自拥有独立牌堆，每只每回合只公开并打出 **1 张牌**，因此初始整对每轮共执行 2 个公开意图。

该敌人默认作为 **精英 / 专属遭遇** 使用，不再提供单只普通敌人变体。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 高威胁、低频 | 前沿尖刺 10；推进受阻可能触发 50 点挤压 |
| 生存 | 高 | 多格占位；加固按体积获得防御；破障按生命上限结算 |
| 移动 | 中 | 推进 1；重聚延迟传送并成长 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 每只墙独立 1 槽；抽空底牌召唤子代，场上子代上限 2 |

## 3. 体积、占位与受击

### 3.1 本体与衍生格

| 字段 | 规则 |
| --- | --- |
| 本体格 | 唯一；保存单位生命、牌堆、状态、配对关系和移动锚点 |
| 衍生格 | 无独立生命；将受到的单位伤害转交本体 |
| 初始体积 | 3 格（本体 1 + 衍生 2） |
| 最大体积 | 6 格 |
| 连通要求 | 每个衍生格必须能经由相邻墙体格连接到本体 |
| 多格命中 | 同一次攻击或效果覆盖同一活墙壁的多个格子时，只对本体结算一次 |
| 死亡 | 本体生命归零时，立即移除本体与全部衍生格 |

活墙壁的所有占地格均：

- 不可与深坑、拾取物、其他构筑物或单位重叠。
- 不可穿越单位或其他墙体；整体移动时必须验证完整体积。
- 阻挡主动移动、强制移动路径与 LOS。
- 可作为敌方单位目标，也可作为破障 / 破坏残骸目标。

### 3.2 破障与破坏残骸

主墙的破坏类交互采用 **伤害替代移除**：

- 破坏效果命中主墙的本体格或任一衍生格时，该格不消失；改为使本体受到 `ceil(最大生命 × 20%)` 伤害。
- 同一张牌或同一个效果同时覆盖多个占地格时，每只活墙壁最多触发一次 20% 最大生命伤害。
- 该伤害可以使本体死亡；死亡后移除完整墙体。
- 若衍生格因其他明确的形状修改效果而与本体失去连接，所有失联衍生格立即移除；失联清理不额外触发 20% 伤害。

子代活墙壁使用 §8 的特殊覆盖规则：任一占地格被破障或破坏残骸效果命中时，子代立即死亡。

## 4. 配对规则

每只活墙壁同一时刻最多拥有一个 `pairedWallId`。

1. 遭遇开始时，两只初始主墙互相配对。
2. 子代生成后，优先与当前 **未配对** 的活墙壁配对；候选超过一个时，先选本体距离最近者，再按生成序号选择。
3. 配对对象死亡后，存活墙立即进入未配对状态；其正常抽牌和行动不停止。
4. 每只未配对墙在自身回合开始时重新搜索未配对墙并尝试配对。
5. 没有合法配对对象时，所有“以对向墙为方向 / 目标”的牌改为以玩家主目标为方向 / 目标。
6. 两面墙的任意占地格互为邻格时，视为两墙 **闭合**。

子代可与主墙或其他子代配对。配对只决定方向与闭合判断，不共享生命、牌堆、防御或状态。

## 5. 牌组构成

首轮原型牌组共 `8` 张；主墙与子代均使用同一牌组和独立牌堆。

| 卡牌名称 | 类别 | 数量 | 效果 |
| --- | --- | ---: | --- |
| 推进 | 行动 | 3 | 整面墙向配对墙移动 1 格，并将扫过路径上的敌方单位沿推进方向击退 1 格；该方向没有合法目标格时触发挤压 |
| 尖刺 | 攻击 | 2 | 以配对墙方向确定整条前沿；前沿射程 1 内的敌方单位各受到 10 点伤害，每个单位最多结算一次 |
| 重聚 | 技能 | 1 | 进入重聚准备；下个自身回合开始时传送到距玩家 3 格的合法位置，并使体积 +1（最大 6） |
| 加固 | 技能 | 2 | 每具有 1 格体积获得 8 点防御；直到下个自身回合开始前不可主动或被动移动 |
| 合计 | — | 8 | — |

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | 精英 / 专属遭遇 |
| `每回合槽位` | 每只墙 1；初始整对合计 2 |
| `槽位模板` | `[自由]` |
| `意图模式` | `Pattern_PairedLivingWall` |
| `抽牌规则` | 每只墙从自己的牌堆抽取 1 张，不按类别筛选，不重排 |
| `执行顺序` | 按单位生成序号；同序时主墙先于子代 |
| `公开信息` | 牌名、配对对象或玩家目标、移动方向、完整前沿、预计受影响格与挤压危险 |

重聚的准备状态公开；其具体传送位置在下个自身回合开始时，根据当时玩家位置选择并立即展示后结算。

## 7. 卡牌结算

### 7.1 推进

推进按以下顺序结算：

1. 有配对墙时，以自身本体到配对墙本体的主六方向为推进方向；无配对墙时，改为指向玩家主目标。
2. 生成整面墙沿该方向移动 1 格的临时占位，不允许旋转或改变形状。
3. 临时占位若接触深坑、拾取物、其他构筑物或其他活墙壁占地，推进失败，墙体留在原位，牌正常进入弃牌堆。
4. 临时占位扫到敌方单位时，对每个单位沿墙体推进方向结算一次 **单向击退 1**；只检查该方向正前方 1 格，不允许改走侧方、斜向或后方格；同一单位被多个墙体格扫到时仍只结算一次。
5. 若临时占位与配对墙任意占地格邻接，标记本次行动为 **闭合推进**。
6. 被推动单位在推进方向正前方没有合法目标格时，立即进行一次 **挤压结算**；是否形成闭合不影响该判定。
7. 所有被推动单位完成结算后，若目标格已清空，墙体完成移动；否则墙体回退至行动前位置。

**挤压**不是可叠加状态，而是移动障碍推动失败时的即时结算：

- 当角色被正在移动的活墙壁击退，且推进方向正前方 1 格不可到达时，该角色受到 **50 点伤害**；不搜索其他方向的替代格。
- 触发挤压后，正在移动的活墙壁回退至行动前位置。
- 同一次推进中，同一角色最多受到一次挤压伤害；多个无法移动的角色可分别受到一次伤害。
- 其他已成功完成击退的角色不回退。
- 闭合推进不是触发挤压的前置条件。

### 7.2 尖刺

1. 有配对墙时，以配对墙本体为方向；无配对墙时，以玩家主目标为方向。
2. 使用主六方向确定朝向。墙体中“沿该方向的相邻格不属于自身占地”的格子组成 **前沿**。
3. 每个前沿格攻击其朝向上的相邻 1 格，造成 10 点伤害。
4. 同一单位同时被多个前沿格覆盖时，只受到一次 10 点伤害。
5. 尖刺不穿透其他障碍、墙体或单位。

### 7.3 重聚

1. 打出后获得公开的 `Reforming` 准备状态，本次出牌不立即移动或成长。
2. 下个自身回合开始时，先移除加固带来的不可移动，再结算重聚，然后生成本回合意图。
3. 以玩家当时的位置为中心，所有传送本体均必须落在 **距离恰好为 3** 的环上；候选位置必须容纳当前完整体积，且不得包含深坑、拾取物、其他构筑物、单位或活墙壁占地。
4. 若互相配对的两面墙在同一敌方回合开始时都处于 `Reforming`，按生成顺序较早者作为第一面墙。第一面墙按既定候选顺序选择落点，第二面墙的指定落点为该点以玩家本体为轴心旋转 180° 后的位置，即轴向坐标 `second = player × 2 - first`。
5. 两个目标完整占位必须作为同一事务同时验证；第二面墙的指定位置不合法时，第一面墙不实际移动，并继续尝试第一面墙的下一个候选点，直到找到双方均合法的对称落点。
6. 遍历全部候选仍找不到双方合法落点时，只尝试传送第一面墙。该墙的本体和所有衍生格必须与任意其他活墙壁占地至少隔 1 个空格，即任意墙格之间的最小六角距离不得小于 2；否则两面墙都不传送。
7. 若同一配对中只有一面墙处于 `Reforming`，则根据未重聚的配对墙相对玩家的方向，只尝试距离 3 环上旋转 180° 的唯一对向位置；该指定位置不合法时不搜索其他位置，重聚失败。
8. 传送成功后，在朝向当前配对目标的方向优先添加 1 个合法衍生格；若该方向不可添加，则按固定顺序搜索其他邻格。单墙兜底传送的新增格同样必须满足与其他墙至少隔 1 个空格。
9. 体积已达 6 时只传送不成长；无合法传送位置时，传送与成长均失败，准备状态仍被消耗。

### 7.4 加固

- 防御值为 `当前体积 × 8`，按打出时体积快照计算。
- 不设置额外上限；体积 3–6 时分别获得 24–48 防御。
- 从加固结算后持续到下个自身回合开始前，整面墙不可主动移动、传送或被强制移动。
- 加固只影响打出该牌的墙，不影响配对墙。

## 8. 底牌与子代

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 分裂增殖 |
| 类别 | 技能 |
| 触发时机 | 该墙抽牌堆被抽空 |
| 子代上限 | 场上存活子代总数最多 2 |
| 子代生命 | 50；与召唤者及其他墙体不共享生命 |
| 子代体积 | 初始 3，最大 6 |
| 子代行动 | 独立牌堆、每回合 1 槽；使用同一常规牌组和底牌 |
| 子代破障 | 任一占地格被破障 / 破坏残骸命中时立即死亡 |

底牌结算：

1. 场上存活子代少于 2 时，在召唤者距离 1–2 内寻找能容纳 3 格连通墙体的合法区域并生成 1 个子代。
2. 子代生成后立即执行 §4 配对规则；没有未配对墙时保持未配对，并在行动时以玩家为目标。
3. 场上已有 2 个存活子代，或没有合法的 3 格生成区域时，底牌无效果。
4. 子代死亡后释放上限名额，后续底牌可以再次召唤。
5. 子代的底牌也可尝试召唤子代，但仍受同一个全场上限约束。

## 9. 边界与失败处理

| 情况                      | 处理                          |
| ----------------------- | --------------------------- |
| 配对对象死亡                  | 立即清除配对；本墙继续正常行动，方向牌改为玩家目标   |
| 推进方向存在静态构筑物 / 深坑  / 其他墙 | 推进无效果，不改变朝向或形状              |
| 推进扫到多个单位                | 每个单位各击退一次；同一单位不因多格覆盖重复结算    |
| 前沿多个格命中同一单位             | 尖刺只造成一次 10 伤害               |
| 范围破障覆盖同一主墙多个格           | 只造成一次 `ceil(最大生命 × 20%)` 伤害 |
| 范围破障覆盖子代多个格             | 子代只死亡一次                     |
| 成对重聚的对称落点被阻挡           | 回退当前候选并遍历下一第一落点；不产生半完成位置 |
| 成对重聚遍历后仍失败              | 仅第一面墙尝试与其他墙至少隔 1 个空格的落点，否则均不传送 |
| 单墙重聚的对向指定位置被阻挡        | 不改选其他位置；传送和成长均失败，准备状态消耗   |
| 成长时没有合法邻格               | 保持当前体积，传送结果保留               |
| 体积达到 6                  | 后续成长无效果                     |
| 子代达到 2                  | 任意墙的召唤底牌无效果                 |

## 10. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 两只墙独立公开意图是否仍可读 | 验证整对每轮 2 意图的信息负担 |
| 体积 3–6 的占地与前沿预览 | 验证多格单位视觉和选中反馈 |
| 推进同时推动多个单位 | 验证多目标强制移动与占位事务 |
| 推进受阻时 50 点挤压的可规避性 | 验证高伤害是否有足够预警与逃生空间 |
| 加固 24–48 防御 | 验证双墙同时防守是否造成拖战 |
| 重聚后的合法落点与成长 | 验证传送不会覆盖深坑、拾取物、单位或构筑物 |
| 子代 0–2 的配对变化 | 验证奇数墙、重新配对和玩家目标 fallback |
| 主墙与子代的破障差异 | 验证 20% 最大生命替代伤害与子代立即死亡 |
