## 验证证据

- `VibeGame.sln --no-restore`：0 编译错误；EditMode、PlayMode 测试程序集均成功生成。
- Unity MCP 无 UI 验证：11 个定义、73 张卡、ID 唯一、引用非空、4 个 MVP 牌组快照与 3 个新增沙盒均通过。
- 活墙壁 EditMode 断言：11 项沙盒枚举映射唯一、旧字符串 ID 可迁移、8 张牌组快照、3–6 格连通性、20% 破障伤害向上取整和运行时状态深拷贝均通过。
- 活墙壁 Play Mode 实机验证：单项配置生成两面三格主墙并互相配对；尖刺扣 10；推进整墙移动并推开目标；重聚到玩家距离 3 且体积 3→4；加固按体积×8 获得护甲并锁定移动；子代上限 2 且均为 50 HP；主墙 34→27、子代破障即死。
- 活墙壁重聚追加验证：双墙同时准备时落在玩家轴心 180° 对称点并同时成长；单墙只尝试配对墙的唯一对向点；指定点被占用时保持原位且不改选其他候选。
- 固定随机种子：普通、精英、首领各完成 2 个完整牌堆循环，空牌堆边界各触发 2 次。
- Play Mode：默认哥布林/投矛、哥布林队长、部落酋长 50% P2 沙盒均成功初始化；酋长 P2 已确认震地入池且接近移除。
- 常规三组 Play Mode smoke 结束时 Console 为 0 Error。随后尝试通过 MCP 动态程序集直接调用冲撞私有协程时被工具拒绝；退出该临时 Play Mode 后留下 1 条 TEngine `[UpdateDriver]/[TEngine]` 场景清理日志，不是敌人脚本编译错误。
- Unity TestRunner 代码已编译；MCP 不允许启动需要用户交互的 TestRunner API。牌组、阶段、场景初始化等断言已通过无 UI Unity 命令验证；新增冲撞行为用例需在 Unity Test Runner 中正式执行。
