## 1. 敌人定位

投矛哥布林是第一章第二普通敌人，以 **保持距离 + 远程威胁** 教会玩家「接近消耗体力」与「在读意图后决定是否前压」。

与近战哥布林互补：玩家不能无限拖延换位，必须在格挡、前进与输出之间分配回合资源。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 基础远程 | 距离 2–3 的「投矛」造成固定伤害 |
| 生存 | 无专属卡牌 | 依赖距离而非格挡 |
| 移动 | 基础 | 「后撤」远离最近敌人 1 格 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 低循环压力 | 抽空牌堆获得 1 层力量（弱于近战哥布林） |

## 3. 牌组构成

投矛哥布林牌组共 `9` 张牌：

| 卡牌名称 | 数量 | 主要维度 | 效果 |
| --- | ---: | --- | --- |
| 投矛 | `4` | 输出 | 对距离 2–3 的敌方单位造成 `4` 点伤害 |
| 后撤 | `3` | 移动 | 远离最近敌方单位移动 `1` 距离 |
| 接近 | `2` | 移动 | 朝敌方单位移动 `1` 距离（被逼近战时使用） |
| 合计 | `9` | 输出、移动 | — |

## 4. 卡牌条目

### 4.1 投矛

| 属性 | 内容 |

| 目标 | 距离 2–3 的敌方单位 |
| 效果 | 造成 `4` 点伤害 |

## 5. 行为节奏

- 典型序列：`后撤 → 投矛 → 投矛` 或 `投矛 → 后撤 → 投矛`，迫使玩家用体力追击或承受远程伤害。
- 当玩家进入邻格后，牌组中的「接近」可能空转，投矛因距离不足失效——玩家可借此识别「已成功贴脸」的安全窗口。
- 每回合抽取并依次打出 `3` 张牌；抽空牌堆触发 **越战越勇（弱）**：获得 `1` 点力量。

## 6. 抽空牌堆增益

| 项目 | 内容 |
| --- | --- |
| 名称 | 越战越勇（弱） |
| 触发 | 抽光抽牌堆 |
| 效果 | 获得 `1` 点力量 |

## 7. MVP 状态

本条目仅使用 **力量**（抽空增益）。不使用感电、束缚等 Post-MVP 状态。

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 玩家为贴脸额外消耗的体力 | 验证移动资源压力 |
| 格挡 vs 前进的选择比例 | 验证远程威胁下的生存决策 |
| 后撤 + 投矛组合的可读性 | 验证远程意图展示 |
