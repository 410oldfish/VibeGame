## 1. 敌人定位

地狱犬是 **燃烧 + 多段咬击 + 冲锋** 敌人：普通遭遇 **2 槽**，精英可 **3 槽**；与战士 **燃烧体系** 形成对称压力或叠加燃烧层。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 高 | 「连环咬」「焰牙」多段 |
| 生存 | 低中 | 「舔火」小回复 |
| 移动 | 高 | 「冲锋」直线突进 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 抽空底牌「炼狱吐息」：直线 **燃烧** |

## 3. 牌组构成

地狱犬牌组共 `12` 张牌：

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 撕咬 | 攻击 | 2 | 输出 | 爆发 | 邻格 **5** 点伤害 |
| 连环咬 | 攻击 | 2 | 费用 | 多段 | 邻格 **3** 点伤害，**3** 次 |
| 焰牙 | 攻击 | 2 | 输出 | 持续 | 邻格 **4** 点伤害；**+2** 燃烧 |
| 冲锋 | 行动 | 2 | 移动 | 接近 / 爆发 | **直线 2** 突进；路径首个敌人 **6** 点伤害 |
| 舔火 | 技能 | 1 | 生存 | 回复 | 回复 **5** 生命；自身 **+1** 燃烧（自伤不计入玩家统计） |
| 纵火本能 | 能力 | 1 | 输出 | 持续 | 攻击命中时 **50%** 再 **+1** 燃烧 |
| 嗅探 | 行动 | 1 | 移动 | 接近 | 朝 **燃烧层数最高** 的敌人移动 **1** |
| 余烬舔舐 | 技能 | 1 | 移动 | 改地形 | 邻格 **1** 内随机 **1** 空格施加 **`ignition_field`** **2** 回合（**着火场地**，≠ 燃烧 debuff） |
| 合计 | 12 | — | — | — | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **普通**（2 槽）或 **精英**（3 槽） |
| `每回合槽位` | **2**（普通）或 **3**（精英） |
| `槽位模板` | 普通：`移动`, `攻击`；精英：`移动`, `攻击`, `自由` |
| `意图抽牌规则` | **引用** Pattern_ApproachStrike（含精英 **自由** 槽） |
| `意图执行规则` | **引用** Pattern_ApproachStrike（「冲锋」按直线预览；贴脸时 **攻击 → 移动**） |
| `攻击范围判定` | **邻格 1**（「冲锋」单独展示直线） |

**精英 override**：自由槽 **50%** 优先抽「焰牙」或「连环咬」。

## 5. 与障碍 / 残骸 / 构筑物交互

| 情况 | 处理 |
| --- | --- |
| 「冲锋」遇 **障碍** | 停于障碍前；不对障碍造成伤害 |
| **`ignition_field`** | 「余烬舔舐」与 **`propId: iron_brazier`** 场景联动；**着火场地** ≠ 角色 **燃烧** |
| 燃烧 + **残骸** | 无额外规则；燃烧按状态系统 |
| 击退撞 **残骸** | 残骸扣 HP；可触发掉落 |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 炼狱吐息 |
| **类别** | **攻击** |
| 效果类型 | 自我增益 + 区域 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | **直线 3** 全体 **5** 点伤害并 **+2** 燃烧；地狱犬力量 **+1** |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「连环咬」无目标 | 无效果，进弃牌堆 |
| 「嗅探」无燃烧目标 | 朝最近敌人移动 **1** |
| 精英 3 槽 | `槽位模板` 长度 = **3** |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 多段咬 vs 格挡 | 伤害分布 |
| 燃烧叠加与战士燃烧 build | 体系对抗或协同 |
| 2~3 槽精英变体 | 遭遇类型槽位上限 |
