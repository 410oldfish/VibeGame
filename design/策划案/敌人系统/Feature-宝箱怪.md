## 1. 敌人定位

宝箱怪是 **精英伪装 + 爆发** 敌人：战斗开始前以 **废墟·木箱** 外观出现（Presentation / 遭遇配置）；被攻击或 **揭盖** 后显露本体，以 **2 槽** 高速咬击与 **掉落联动** 制造风险回报。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 高爆发 | 「狂咬」「扑击」多段伤害 |
| 生存 | 中 | 「硬壳」格挡；伪装阶段可选减伤 |
| 移动 | 中 | 「扑击」含位移；「舔舐」后撤 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 抽空底牌「吐宝」：生成可视区拾取物 |

## 3. 牌组构成

宝箱怪牌组共 `11` 张牌：

| 卡牌名称 | 类别 | 数量 | 主要维度 | 效果 |
| --- | --- | ---: | --- | --- |
| 狂咬 | 攻击 | 3 | 输出 | 对邻格造成 **4** 点伤害，**2** 次 |
| 扑击 | 攻击 | 2 | 输出 + 移动 | 朝敌方移动 **1** 并造成 **7** 点伤害 |
| 舔舐 | 行动 | 2 | 移动 + 生存 | 远离最近敌人 **1** 格；回复 **4** 生命 |
| 硬壳 | 技能 | 2 | 生存 | 获得 **10** 点格挡 |
| 揭盖 | 技能 | 1 | 自我增益 | 移除 **伪装**；本回合 **+2** 力量 |
| 贪婪 | 能力 | 1 | 规则 | 死亡时在所在格生成 **废墟·木箱**（HP **4**）；该废墟 HP 归零 **必掉** 精英拾取物（Content） |
| 合计 | 11 | 输出、移动、生存 | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **精英** |
| `每回合槽位` | **2** |
| `槽位模板` | `攻击`, `自由` |
| `意图抽牌规则` | 攻击槽：① **`类别=攻击`** → ② **`技能` 或 `能力`**；自由槽：**随机** 1 张 |
| `意图执行规则` | **固定顺序**：**攻击** → **自由**（**不** 引用 ApproachStrike 距离重排） |
| `攻击范围判定` | **邻格 1**（「扑击」可跨格移动后攻击） |

**伪装阶段（遭遇配置）**：未揭盖前 `每回合槽位` 可临时为 **1**、仅抽「硬壳」或空意图；揭盖后恢复 **2** 槽（细则见遭遇 Content，不写章节表）。

## 5. 与高台 / 废墟 / 掉落联动

| 机制 | 说明 |
| --- | --- |
| 外观 | 遭遇布局可预置 **废墟·木箱** token；揭盖后替换为宝箱怪单位 |
| 「贪婪」 | 死亡格生成 **废墟**（HP **4**）；归零触发 **可视区拾取物**（沿用 [`Feature-地形与地形改装规则.md`](../地形系统/Feature-地形与地形改装规则.md) §掉落） |
| 底牌「吐宝」 | 立即在 **邻格随机 1 空格** 放置 **废墟·木箱**（HP **4**）或生成拾取物 token（Content 二选一） |
| 击退撞 **高台** | 停步；不破坏高台 |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 吐宝 |
| **类别** | **技能** |
| 效果类型 | 放置地形 / 掉落 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 邻格随机 **1** 空格 **废墟·木箱**（HP **4**）；若无空格，对随机敌方 **6** 点伤害 |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「扑击」无路径 | 仍造成 **7** 伤（若邻格可达目标）；否则无效果 |
| 「舔舐」无法后撤 | 仍回复 **4** 生命 |
| 2 槽抽牌不足 | 洗弃牌堆；底牌后继续补抽 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 伪装 → 揭盖节奏 | 精英「惊吓感」与可读性 |
| 死亡废墟 + 掉落 | 验证可视区拾取物管线 |
| 2 槽固定序 vs 玩家走位 | 扑击预判难度 |
