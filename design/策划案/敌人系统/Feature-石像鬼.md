## 1. 敌人定位

石像鬼是 **精英倚障** 敌人：通过 **邻接障碍** 获得减伤，并以 **俯冲** 爆发施压；迫使玩家 **破障** 或绕开 LOS。构筑物格 **不可站立**，石像鬼始终站在 **普通地面**，仅与 **障碍** 邻格时触发收益。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 中高 | 「爪击」「俯冲」 |
| 生存 | 高（倚障） | **邻接 ≥1 格障碍** 时 **减伤 25%**（「守势」） |
| 移动 | 中 | 「盘旋」贴近障碍；「俯冲」直线突进 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 抽空底牌「石落」：邻格放置 **障碍** |

## 3. 牌组构成

石像鬼牌组共 `12` 张牌：

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 爪击 | 攻击 | 3 | 输出 | 持续 | 邻格 **6** 点伤害 |
| 俯冲 | 攻击 | 2 | 输出 | 爆发 / 接近 | **直线 2** 突进；路径上首个敌人 **8** 点伤害 |
| 石肤 | 技能 | 2 | 生存 | 拖战 | 获得 **8** 格挡；**邻接障碍** 时再 **+4** 格挡 |
| 盘旋 | 行动 | 2 | 移动 | 占点 | 移动 **1** 至 **邻接 ≥1 格障碍** 的空格；若无合法落点则普通移动 **1** |
| 守势 | 能力 | 1 | 生存 | 护场 | **邻接障碍** 时受到的伤害 **−25%** |
| 凝视 | 技能 | 1 | 移动 | 封脚 | **射程 2** 随机敌人 **束缚 1** |
| 落石 | 技能 | 1 | 移动 | 改地形 | 距离 **1** 内随机 **1** 空格放置 **障碍** |
| 合计 | 12 | — | — | — | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **精英** |
| `每回合槽位` | **3** |
| `槽位模板` | `移动`, `攻击`, `自由` |
| `意图抽牌规则` | **引用** Pattern_ApproachStrike（含 **自由** 槽随机） |
| `意图执行规则` | **引用** [`Pattern_Ranged`](Feature-敌人牌组与意图机制.md) §3.1（攻击范围 **邻格 1** 对「爪击」；「俯冲」按直线预览） |
| `攻击范围判定` | **邻格 1**（「俯冲」单独展示直线范围） |

**条目 override**：若当前 **邻接障碍** 且攻击槽为「爪击」，执行时 **攻击 → 移动 → 自由**（先打再盘旋换倚障位）。

## 5. 与障碍 / 残骸交互

| 情况 | 处理 |
| --- | --- |
| **邻接障碍** | 「守势」减伤；「石肤」额外格挡 |
| **破障** | 移除相邻 **障碍** 后石像鬼失去倚障收益；不强制位移 |
| 「俯冲」路径遇 **障碍** | 不可穿过；停于障碍前 |
| **残骸** | 俯冲 **可穿透** 对格内单位结算；残骸扣 HP 按 Content |
| 底牌「石落」 | 在 **距离 1** 内随机 **1** 空格放置 **障碍**（**不** 覆盖单位格） |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 石落 |
| **类别** | **行动** |
| 效果类型 | 放置地形 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 距离 **1** 内随机 **1** 个 **空格** 放置 **障碍** |
| 失败 fallback | 若无合法格，力量 **+2** |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「俯冲」无路径目标 | 无效果，进弃牌堆 |
| 「盘旋」无倚障落点 | 按普通移动 **1** 执行 |
| 3 槽补抽 | 洗弃牌堆；底牌后继续 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 倚障减伤是否过硬 | 精英 TTK |
| 破障 vs 俯冲预判 | 地形决策权重 |
| Pattern_Ranged + 3 槽 UI | 多槽可读性上限 |
