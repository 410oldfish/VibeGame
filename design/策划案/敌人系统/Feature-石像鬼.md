## 1. 敌人定位

石像鬼是 **精英占点** 敌人：偏好站立 **高台**，获得 **石肤减伤** 与 **俯冲** 爆发；迫使玩家处理 LOS 或 **破台** 逼其落地。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 中高 | 「爪击」「俯冲」 |
| 生存 | 高（高台） | 占 **高台** 时 **减伤 25%**（被动，Content） |
| 移动 | 中 | 「盘旋」换高台；「俯冲」直线突进 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 抽空底牌「石落」：当前格或邻格 **高台** |

## 3. 牌组构成

石像鬼牌组共 `11` 张牌：

| 卡牌名称 | 类别 | 数量 | 主要维度 | 效果 |
| --- | --- | ---: | --- | --- |
| 爪击 | 攻击 | 3 | 输出 | 邻格 **6** 点伤害 |
| 俯冲 | 攻击 | 2 | 输出 + 移动 | **直线 2** 突进；路径上首个敌人 **8** 点伤害 |
| 石肤 | 技能 | 2 | 生存 | 获得 **8** 格挡；若站立 **高台** 再 **+4** 格挡 |
| 盘旋 | 行动 | 2 | 移动 | 移动 **1** 至 **高台** 格（若无高台则普通移动 **1**） |
| 守势 | 能力 | 1 | 规则 | 站立 **高台** 时受到的伤害 **−25%** |
| 凝视 | 技能 | 1 | 控制 | **射程 2** 随机敌人 **束缚 1** |
| 合计 | 11 | 输出、移动、生存 | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **精英** |
| `每回合槽位` | **3** |
| `槽位模板` | `移动`, `攻击`, `自由` |
| `意图抽牌规则` | **引用** Pattern_ApproachStrike（含 **自由** 槽随机） |
| `意图执行规则` | **引用** [`Pattern_Ranged`](Feature-敌人牌组与意图机制.md) §3.1（攻击范围 **邻格 1** 对「爪击」；「俯冲」按直线预览） |
| `攻击范围判定` | **邻格 1**（「俯冲」单独展示直线范围） |

**条目 override**：若当前站立 **高台** 且攻击槽为「爪击」，执行时 **攻击 → 移动 → 自由**（先打再盘旋换点）。

## 5. 与高台 / 废墟交互

| 情况 | 处理 |
| --- | --- |
| 站立 **高台** | 「守势」减伤；「石肤」额外格挡 |
| **破台** | 石像鬼若占该格则 **落入** 普通地面（不额外伤害，Content 可配 **1** 回合眩晕 Post-MVP） |
| 「俯冲」路径遇 **高台** | 不可穿过；停于高台前 |
| **废墟** | 俯冲 **可穿透** 对格内单位结算；废墟扣 HP 按 Content |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 石落 |
| **类别** | **行动** |
| 效果类型 | 放置地形 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 自身所在格若不是 **高台**，则将该格设为 **高台**；若已是高台，邻格随机 **1** 空格 **高台** |
| 失败 fallback | 若无合法格，力量 **+2** |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「俯冲」无路径目标 | 无效果，进弃牌堆 |
| 「盘旋」无高台可达 | 按普通移动 **1** 执行 |
| 3 槽补抽 | 洗弃牌堆；底牌后继续 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 高台减伤是否过硬 | 精英 TTK |
| 破台 vs 俯冲预判 | 地形决策权重 |
| Pattern_Ranged + 3 槽 UI | 多槽可读性上限 |
