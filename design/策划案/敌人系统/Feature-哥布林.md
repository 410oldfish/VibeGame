# 《VibeGame》敌人条目：哥布林

> 文档状态：基础敌人牌组 v0.1  
> **Layer**：Feature
> 所属系统：敌人系统  
> 关联主文档：[`Feature-敌人牌组与意图机制.md`](Feature-敌人牌组与意图机制.md)  
> 关联规范：[`../设计规范/Foundation-卡牌与角色五维设计.md`](../设计规范/Foundation-卡牌与角色五维设计.md)

## 1. 敌人定位

哥布林是首批普通敌人模板之一，以最基础的`接近 -> 邻格打击`行为验证敌人卡组、公开意图和玩家移动回应是否成立。

当前条目只确定牌组构成及牌面效果，不额外确定生命、状态抗性、出生位置、目标选择优先级或奖励。

## 2. 五维定位

| 维度   | 当前表现   | 设计说明                  |
| ---- | ------ | --------------------- |
| 输出   | 基础     | 使用 **攻击** 类别「打击」造成固定伤害     |
| 生存   | 基础     |                       |
| 移动   | 基础     | 使用 **行动** 类别「接近」向敌方单位靠近         |
| 费用   | 无专属卡牌  | 当前不包含蓄力、减费或行动预算操作     |
| 抽牌运转 | 基础循环压力 | 抽牌堆抽空时打出底牌「越战越勇」，获得力量 |

## 3. 牌组构成

哥布林牌组共`9`张牌：

| 卡牌名称 | 类别 |  数量 |    牌组占比 | 主要维度  | 效果                  |
| ---- | --- | --: | ------: | ----- | ------------------- |
| 打击   | 攻击 | `4` | `4 / 9` | 输出    | 对距离`1`的敌方单位造成`6`点伤害 |
| 接近   | 行动 | `3` | `3 / 9` | 移动    | 朝敌方单位移动`1`距离        |
| 翻滚   | 技能 | `2` | `2 / 9` | 移动+生存 | 朝敌方单位移动`1`距离 防5     |
| 合计   | `9` | `9 / 9` | 输出、移动 | -                   |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **普通** |
| `每回合槽位` | **2** |
| `槽位模板` | `移动`, `攻击` |
| `意图抽牌规则` | **引用** [`Pattern_ApproachStrike`](Feature-敌人牌组与意图机制.md) §3.1 |
| `意图执行规则` | **引用** Pattern_ApproachStrike（执行时按是否在 **邻格 1** 重排移动/攻击槽） |
| `攻击范围判定` | **邻格 1**（攻击槽内牌为「打击」时） |

## 5. 底牌

| 字段   | 内容                    |
| ---- | --------------------- |
| 底牌名称 | 越战越勇                  |
| **类别** | **能力**                |
| 效果类型 | 自我增益                  |
| 触发时机 | 哥布林抽牌时抽光自己的抽牌堆        |
| 效果   | 哥布林下回合获得 `5` 点临时力量    |
| 牌区处理 | 视为打出一张特殊牌，不加入普通牌组     |

## 6. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| `打击`执行时不存在距离`1`的合法目标 | 该牌视为打出但无效果，进入弃牌堆，继续执行后续槽 |
| `接近`执行时已经邻接目标 | 该牌视为打出但无效果，进入弃牌堆，继续执行后续槽 |
| `接近`执行时没有合法接近路径或落点 | 该牌视为打出但无效果，进入弃牌堆，继续执行后续槽 |
| 意图生成时抽牌堆不足 | 洗弃牌堆；抽空时打出底牌后继续补抽至 **2** 槽填满 |
| 能量费用 | 按 **意图执行规则** 依次结算 **2** 个意图槽，不受能量约束 |

## 7. 规则待确认

哥布林牌组已经确定，但下列执行细节仍需在敌人通用规则或遭遇文档中确认：

1. 多个玩家同时可作为目标时，哥布林的目标选择规则。
2. 多个等价接近落点同时存在时，是否采用固定方向顺序、随机或按距离队友/地形风险加权选择。
3. 意图槽展示除槽序外，应展示目标单位、移动落点和失败条件中的哪些信息。

## 8. 原型验证用途

哥布林可用于首轮战斗测试中的基础观察：

| 观察项                          | 用途                      |
| ---------------------------- | ----------------------- |
| 玩家能否从 **2 槽意图** 理解「接近 / 打击」及执行顺序翻转 | 验证敌方组合意图可读性             |
| 玩家面对`打击`时选择移动或防御的比例          | 验证基础空间与生存决策             |
| `打击`因目标离开邻格而无法命中的频率          | 判断邻格攻击压力是否足够            |
| 移动槽与攻击槽均为空转的频率   | 判断 2 槽 + Pattern 抽牌是否匹配牌组 |
| 底牌触发后的伤害压力变化                 | 验证「越战越勇」力量 +5 是否能制造循环压力 |
