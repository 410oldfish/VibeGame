## 1. 敌人定位

寄生藤蔓是 **普通束缚 + 扩散** 敌人：通过 **缠绕** 施加 **束缚**，利用 **残骸** 受击与 **蔓延** 占格，与战士位移/燃烧形成互动。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 中 | 「藤刺」+ 束缚后续伤害 |
| 生存 | 低中 | 「根须」格挡 |
| 移动 | 中 | 「爬移」向最近敌人靠近 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 中 | 抽空底牌「孢子」：邻格 **+1** 束缚层 |

## 3. 牌组构成

寄生藤蔓牌组共 `12` 张牌：

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 藤刺 | 攻击 | 3 | 输出 | 持续 | 邻格 **5** 点伤害 |
| 缠绕 | 攻击 | 2 | 移动 | 封脚 | 邻格 **3** 点伤害；施加 **束缚 1** |
| 缠足 | 技能 | 1 | 移动 | 封脚 / 拉拽 | **射程 2** 随机敌人 **束缚 1**；若已束缚再 **拉拽 1** |
| 爬移 | 行动 | 2 | 移动 | 接近 | 朝最近敌人移动 **1** |
| 根须 | 技能 | 2 | 生存 | 拖战 | 获得 **6** 点格挡 |
| 蔓延 | 技能 | 1 | 移动 | 封脚 / 改地形 | 邻格 **残骸** 受击时（含穿透攻击）：对该格敌人 **+1** 束缚（本回合每残骸 **1** 次） |
| 孢囊 | 技能 | 1 | 移动 | 改地形 | 邻格 **1** 内随机 **1** 空格放置 **`propId: thorn_bramble`**（HP **3**） |
| 合计 | 12 | — | — | — | — |

> 「蔓延」为 **被动触发** 技能牌：进入意图槽执行时本回合激活该被动标记（具体被动时机 Post-MVP 细化为能力 token；MVP 按「打出即激活至下回合开始」）。

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **普通** |
| `每回合槽位` | **2** |
| `槽位模板` | `移动`, `攻击` |
| `意图抽牌规则` | **引用** Pattern_ApproachStrike |
| `意图执行规则` | **引用** Pattern_ApproachStrike |
| `攻击范围判定` | **邻格 1** |

## 5. 与障碍 / 残骸 / 构筑物交互

| 情况 | 处理 |
| --- | --- |
| 战场 **残骸** 被攻击穿透 | 「蔓延」可对 **该格单位** 追加束缚（若本回合已打出「蔓延」） |
| **`propId: thorn_bramble`** | 寄生藤蔓遭遇可预置；**寄生残骸** 邻格互动见 [`Feature-构筑物互动图鉴.md`](../地形系统/Feature-构筑物互动图鉴.md) §3.11 |
| 藤蔓邻格 **障碍** | 不主动放置；爬移 **不可穿** 障碍 |
| 玩家破坏 **残骸** 掉落 | 与藤蔓无额外联动；标准掉落规则 |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 孢子 |
| **类别** | **技能** |
| 效果类型 | 对玩家干扰（debuff） |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 随机 **1** 名敌方施加 **束缚 2** |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「缠绕」无邻格目标 | 无效果，进弃牌堆 |
| 「爬移」已邻接 | 无效果，进弃牌堆 |
| 束缚与玩家 **主动移动** | 按状态系统：束缚层消耗规则 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 束缚 + 爬移 2 槽可读性 | 对比哥布林 ApproachStrike |
| 残骸旁作战是否鼓励打箱 | 地形 + debuff 协同 |
| 底牌孢子触发频率 | 长跑战斗压力 |
