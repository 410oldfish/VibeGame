> **文档状态**：草案 v0.4  
> **Layer**：Feature

> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)

## Summary

敌人系统定义敌方牌区、**意图槽**、公开意图流程及玩家干涉敌方牌局的方式。**抽牌与执行顺序由条目规则定义**；本文提供全局框架与 **参考模式**（非强制）。具体敌人见 Content 条目文档。

**设计灵感对照**（非机制正文）：[`../设计规范/Feature-卡牌与敌人设计灵感来源.md`](../设计规范/Feature-卡牌与敌人设计灵感来源.md)

## 1. 文档定位

本文件是敌人系统的主文档，负责定义敌方牌组、公开意图、执行流程以及玩家如何与敌方「打牌」。

本文件负责：

- 敌方牌区与信息公开层级。
- 敌方意图的生成和执行框架。
- 玩家干涉敌方牌局的方式。
- 防止敌人系统被完全锁死的约束规则。

本文件不负责：

- 敌人在六边形空间中的移动合法性。
- 具体地形词典与地形效果。
- 状态词条表本身。

## 2. 玩家体验目标

- **可预判**：玩家能看到足够信息，从而通过移动和构筑做出决策。
- **有变化**：相同敌人在不同洗牌与地形下不会完全按脚本重复。
- **可干涉**：玩家不只承受攻击，还能影响敌人下一轮会如何出牌。
- **可读性优先**：不要求玩家记住敌人整套牌库才能做出合理选择。
- 敌人也拥有牌局节奏：每回合 **N 个意图槽** 构成可阅读的行动组合（N 由条目配置）。
- 首领需要最低行动保障，避免玩家彻底锁死首领。

## 3. 详细设计

### 3.1 核心规则

#### 敌方牌区

建议每个主要敌人拥有以下数据：

| 区域/信息 | 对玩家是否公开 | 说明 |
| --- | --- | --- |
| 敌人牌库构成摘要 | 部分公开 | 遭遇开始时显示关键词，例如「冲撞 / 燃烧 / 防守」 |
| 抽牌堆 | 数量公开，顺序隐藏 | 首领可通过阶段改变牌库 |
| 当前意图槽 | 公开且有序 | 展示敌方下一敌人回合 **N 个意图槽** 中的牌、槽位标签、目标/范围预览 |
| 弃牌堆 | 可查看 | 玩家可判断危险牌多久可能再次出现 |
| 消耗/封印区 | 公开 | 记录被永久处理或阶段性禁用的敌方牌 |

普通敌人应使用规则清晰、易于读懂的小型个人牌组；精英和首领应拥有更鲜明的牌组循环。**每回合意图槽数量** 由条目 `每回合槽位` 配置，须落在遭遇类型允许范围内（见下节）。

#### 遭遇类型与意图槽上限（全局）

| 遭遇类型 | `每回合槽位` 允许范围 | MVP 示例 |
| --- | --- | --- |
| **普通** | 1 ~ 2 | 哥布林、投矛哥布林 = **2** |
| **精英** | 2 ~ 3 | 哥布林队长 = **3** |
| **首领** | 3 ~ 4 | 部落酋长 = **4** |

**敌人模板必填字段**（抽牌/执行细则 **不在此全局写死**，见条目或参考模式）：

| 字段 | 说明 |
| --- | --- |
| `遭遇类型` | `普通` \| `精英` \| `首领` |
| `每回合槽位` | 整数；须落在上表范围内 |
| `槽位模板` | 长度 = `每回合槽位`；槽位 **标签** 由条目自定义（如 `移动`、`攻击`、`自由`） |
| `意图抽牌规则` | **条目级**；可引用参考模式 ID 或条目内联描述 |
| `意图执行规则` | **条目级**；可引用参考模式 ID 或条目内联描述 |

配置校验：`槽位模板`.length 须等于 `每回合槽位`；超出遭遇类型上限 → 非法。

#### 敌方执行流程（全局框架）

```text
按条目「意图抽牌规则」填充 N 个意图槽 → 公开意图
  -> 玩家回合读取威胁并做出响应
  -> 按条目「意图执行规则」依次结算意图槽中的牌
  -> 已打出、未执行或被打断的牌进入对应牌区
  -> 下一轮重新生成意图
```

**全局确定规则**：

- 战斗开始时先为第一轮敌方回合 **按各条目规则** 生成并公开意图槽，再给予玩家先手。
- 意图生成时若需从抽牌堆取牌：抽牌堆不足则洗弃牌堆；抽空触发 **底牌**（见下节）；补抽直至本条目规则填满各槽或牌堆无牌。
- 某张牌因没有合法目标、路径被阻挡或被状态打断而无法生效时，仍视为打出该牌，但无效果，随后进入弃牌堆并继续执行后续槽（若条目规则尚有后续槽）。
- 敌人 **不受玩家能量约束**；按条目执行规则依次尝试结算意图槽。
- **意图由条目规则生成，执行由条目规则排序**——主文档 **不** 强制全局「先抽行动再抽攻击」或「按距离重排」。

#### 参考模式：Pattern_ApproachStrike（接近-打击）

> **非全局强制**。供 MVP 哥布林系条目 **引用**；其他敌人可不采用。条目也可内联等价规则或完全自定义。

**适用槽位模板（2 槽）**：`[移动, 攻击]`。3+ 槽时常见扩展：`[移动, 攻击, 自由, …]`。

**参考抽牌**（逐槽从抽牌堆取 1 张；洗弃/底牌同全局）：

| 槽标签 | 参考抽法 |
| --- | --- |
| **移动** | ① 抽 **`类别=行动`** → ② 若无可用牌，抽 **`技能` 或 `能力`** |
| **攻击** | ① 抽 **`类别=攻击`** → ② 若无，抽 **`技能` 或 `能力`** |
| **自由** | 从剩余抽牌堆 **随机** 1 张 |

「抽某类别」= 自抽牌堆 **顶向下首张匹配**；占槽后从抽牌堆移除。

**参考执行**（仅当条目 **引用本模式执行规则** 时生效）：

在 **敌方执行窗口开始**、结算移动/攻击槽 **之前**，按 **执行时刻** 主目标是否在 **攻击范围内** 重排 **移动槽 vs 攻击槽**（攻击范围由攻击槽内牌或条目定义）：

| 主目标在攻击范围内 | 移动/攻击槽顺序 | 自由槽 |
| --- | --- | --- |
| **是** | **攻击** → **移动** | 其后按槽位模板顺序 |
| **否** | **移动** → **攻击** | 其后按槽位模板顺序 |

意图在 **玩家回合前** 生成；玩家走位可在执行时 **翻转** 先打先移（若条目引用本重排规则）。

**条目 override 示例**（写在各 Feature 条目，不升格为全局）：固定槽序不重排、1 槽只抽攻击、按 CD 抽指定牌名、远程优先 `后撤` 等。

#### 参考模式：Pattern_Stationary（站桩）

> 供 **无移动牌** 或 **不主动位移** 的敌人引用（如活墙壁）。

**适用槽位模板（1 槽）**：`[攻击]` 或 `[自由]`（条目二选一固定）。

**参考抽牌**：

| 槽标签 | 参考抽法 |
| --- | --- |
| **攻击** | ① 抽 **`类别=攻击`** → ② 若无，抽 **`技能` 或 `能力`** |
| **自由** | 从抽牌堆 **随机** 1 张（可含 **技能** 放置地形等） |

**参考执行**：**不重排**；按槽位模板 **固定顺序** 结算。移动类牌 **不在牌组** 时，移动槽 **不出现**。

#### 参考模式：Pattern_Ranged（远程保持距离）

> 供 **远程攻击 + 后撤/占位** 敌人引用（如投矛哥布林、石像鬼、夺心魔）。

**适用槽位模板**：`[移动, 攻击]`（2 槽）或 `[移动, 攻击, 自由]`（3+ 槽）。

**参考抽牌**：同 Pattern_ApproachStrike（移动槽优先 `行动`，攻击槽优先 `攻击`，自由槽随机）。

**参考执行**：

| 主目标在 **条目攻击范围** 内 | 移动/攻击槽顺序 |
| --- | --- |
| **是** | **攻击** → **移动**（打完再拉开或微调站位） |
| **否** | **移动** → **攻击** |

**条目 override**：投矛哥布林攻击范围 **2~3**；石像鬼占 **高台** 时可将「移动槽」改为优先抽 **`技能` 俯冲** 等——写在各 Feature §槽位与意图规则。

**底牌（全局）**：所有敌人都拥有 **底牌**——当 **抽牌堆被抽空** 时，额外打出一张不在常规牌组中的特殊牌；效果由敌人条目定义。抽牌过程中每当抽取使抽牌堆变为 **空**，立即 **打出该敌人的底牌**；若还需要继续补抽意图，则在底牌结算后洗回弃牌堆并继续抽牌。

#### 玩家与敌人「打牌」的交互类型

| 交互方式 | 规则概念 | 示例 |
| --- | --- | --- |
| 躲避 | 离开意图攻击覆盖区 | 敌人展示直线突进，玩家移出直线 |
| 阻挡 | 通过防御或地形使牌收益降低 | 骑士升起掩体挡住射线 |
| 诱导 | 改变敌人位置或可选目标 | 嘲讽后将重击引向高格挡角色 |
| 打断 | 满足条件后取消公开意图 | 眩晕敌人，使其蓄力攻击进入弃牌堆 |
| 污染牌组 | 向敌方牌堆加入弱化牌/状态牌 | 向敌人抽牌堆塞入 **恐惧牌** |
| 窃取/复制 | 获得敌人牌的临时友方版本 | 精英掉落或职业特色机制 |
| 强迫出牌 | 令敌人提前在不佳位置执行牌 | 诱发冲撞撞墙或提前引爆区域 |

#### 底牌

每个敌人模板配置 **1 张底牌**（Post-MVP 可扩展为多张轮换）。底牌 **不在** 常规抽牌堆中，仅在抽牌堆被抽空时打出。

| 规则项 | 说明 |
| --- | --- |
| 触发时机 | 敌人 **抽牌** 时，抽取动作使抽牌堆从 **非空变为空** |
| 结算顺序 | 立即打出底牌并结算效果 → 若本回合仍需补抽意图，洗回弃牌堆后继续 |
| 表现归类 | 视为敌人打出一张 **特殊牌**；参与「敌方打牌」类触发，但 **不占用** 当回合 **意图槽** |
| 牌区处理 | 默认 **不** 进入抽牌堆、弃牌堆或消耗堆；除非条目写明「底牌洗入弃牌堆」等 |
| 多次触发 | 每次抽牌堆被抽空都可再次打出底牌（同一张，效果可叠加或按条目封顶） |
| 意图展示 | 底牌 **不** 提前进入公开意图槽；在抽牌瞬间以 **底牌触发** 反馈（见 Presentation 层） |
| 配置来源 | 由敌人 Feature 条目定义：显示名、效果类型、具体数值与失败 fallback |

> 旧称「抽空牌堆增益」= 底牌的一种效果类型（多为 **自我增益**）；新敌人条目统一使用 **底牌** 术语。

**底牌效果类型（Content 填表枚举）**

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| **自我增益** | 对自身施加状态或属性 | 哥布林「越战越勇」：力量 +3 |
| **召唤** | 在合法空格生成单位 | 队长底牌「增援」：召唤 1 只哥布林 |
| **放置地形** | 在空格放置 **废墟**（如木箱）或 **高台** | 酋长底牌「落岩」：邻格随机 1 空格 **废墟·木箱** |
| **放置陷阱** | 放置延迟触发或区域效果 token（Post-MVP 细化为地形子类） | 哥布林萨满：邻格放置「尖刺陷阱」 |
| **群体增益** | 对友方全体或范围内友方 | 战鼓手：所有哥布林 +1 力量 |
| **对玩家干扰** | 塞牌、施加 debuff 等 | 向玩家抽牌堆 +1 诅咒 token |

**配置字段建议**

| 字段 | 含义 |
| --- | --- |
| `类别` | **必填**；敌人：`行动` \| `攻击` \| `技能` \| `能力`（见 [`Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md) §4.2） |
| `特殊` | 可选；`底牌` \| `token`（底牌仍填 `类别`；token 如恐惧牌 **不** 填玩家类别） |
| `底牌名称` | UI 显示名，如「越战越勇」「增援」 |
| `效果类型` | 上表枚举 |
| `效果` | 具体数值与目标规则 |
| `失败 fallback` | 无合法目标/达上限时的替代效果（可选） |

**MVP 第一章底牌一览**

| 敌人 | 底牌 | 类别 | 类型 | 效果 |
| --- | --- | --- | --- | --- |
| 哥布林 | 越战越勇 | **能力** | 自我增益 | 力量 +3 |
| 投矛哥布林 | 越战越勇（弱） | **能力** | 自我增益 | 力量 +1 |
| 哥布林队长 | 增援 | **技能** | 召唤 | 若随从未达上限，召唤 1 只哥布林（生命 15）；否则力量 +1 |
| 部落酋长 | 落岩 | **行动** | 放置地形 | 距离 1 内随机 **1** 个空格 **废墟·木箱**（HP **4**）；若无合法空格，力量 +2 |

详见各敌人 Feature 条目 §底牌。

#### 玩家塞入的状态牌（MVP）

| 规则项 | 说明 |
| --- | --- |
| 入口 | 战士 **塞牌** 体系 `敌方塞牌`；牌面指定塞入 **抽牌堆** |
| **恐惧牌** | MVP 默认 token：牌面标签 `恐惧`；抽到时 **无效果**，立即进入敌方 **弃牌堆**，不占用意图槽；**不**自动施加 **恐惧** debuff（debuff 由其它牌/效果单独施加） |
| **意图恐惧** | 公开 **意图槽** 中牌带 `恐惧` 标签；供「惊啸突袭」等消耗 |
| 洗牌 | 塞入后若需洗牌，按敌方抽牌堆规则洗入 |
| 首领抗性 | 首领可 Post-MVP 增加「塞牌 −1 张」；MVP 酋长不免疫 |

详见 [`Feature-已投入设计词条登记.md`](../设计规范/Feature-已投入设计词条登记.md) §5、[`Feature-战士卡牌.md`](../职业系统/战士/Feature-战士卡牌.md) §3.2、[`Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md)。

### 3.2 状态与流转

| 阶段 | 行为 |
| --- | --- |
| 意图生成 | 按条目 **意图抽牌规则** 填充 N 槽并公开 |
| 玩家回合 | 玩家响应威胁 |
| 意图执行 | 按条目 **意图执行规则** 结算各槽 |
| 牌区更新 | 弃牌/保留/消耗 |
| 下一轮准备 | 重新生成意图 |

### 3.3 与其他系统的交互

| 类型 | 主要内容 |
| --- | --- |
| 上游依赖 | 战场位置、敌人模板、敌方牌组、状态效果、地形约束、遭遇编排 |
| 系统产出 | 敌方公开意图、敌方执行结果、敌方牌区变化、敌人压迫节奏 |
| 下游影响 | 玩家移动与出牌决策、打断与诱导选择、遭遇难度表现 |

## 4. 边界情况

- **若干涉敌方牌组的卡牌过多**：需控制数量与费用，首领保留抗性、阶段解锁或每轮最低行动保障。
- **若未来加入群体 AI、共享敌方资源或反制逻辑**：需另建子文档，不塞进遭遇文档。
- **信息公开应足够支撑规划，但不能让所有风险完全静态化**。

## 9. 验收标准

- **GIVEN** 敌人 `每回合槽位` 超出遭遇类型上限，**WHEN** Content 校验，**THEN** 配置非法。
- **GIVEN** 战斗开始，**WHEN** 初始化完成，**THEN** 各敌人按 **各自条目规则** 生成并公开意图槽，且玩家获得先手。
- **GIVEN** 条目引用 Pattern_ApproachStrike 的哥布林（2 槽），**WHEN** 生成意图，**THEN** 移动槽优先 `行动`、攻击槽优先 `攻击`（失败 fallback 技能/能力）。
- **GIVEN** 哥布林意图已公开且执行时主目标不在攻击范围，**WHEN** 敌方执行且条目引用 Pattern 执行规则，**THEN** 移动槽先于攻击槽结算。
- **GIVEN** 条目 **未** 引用距离重排规则，**WHEN** 敌方执行，**THEN** 按条目规定的固定槽序执行。
- **GIVEN** 抽牌使抽牌堆变空，**WHEN** 该敌人有条目定义的底牌，**THEN** 立即打出底牌并结算，视为特殊牌打出。
