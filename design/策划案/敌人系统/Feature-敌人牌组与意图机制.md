# 《VibeGame》敌人牌组与意图机制

> **文档状态**：草案 v0.3  
> **Layer**：Feature
> **Priority**：MVP  
> **关联总案**：[`../游戏粗略策划案.md`](../游戏粗略策划案.md)  
> **Quick reference**：关键依赖 战斗系统、六边形战斗规则、状态效果、地形、遭遇

## Summary

敌人系统定义敌方牌区、公开意图、三牌顺序执行流程及玩家干涉敌方牌局的方式。玩家应在敌人行动前读懂威胁并通过移动、构筑与状态改变结果；具体敌人牌组见 Content 条目文档。

## 1. 文档定位

本文件是敌人系统的主文档，负责定义敌方牌组、公开意图、执行流程以及玩家如何与敌方「打牌」。

本文件负责：

- 敌方牌区与信息公开层级。
- 敌方意图的生成和执行框架。
- 玩家干涉敌方牌局的方式。
- 防止敌人系统被完全锁死的约束规则。

本文件不负责：

- 敌人在六边形空间中的移动合法性。
- 具体地形词典与地形效果。
- 状态词条表本身。

## 2. 玩家体验目标

- **可预判**：玩家能看到足够信息，从而通过移动和构筑做出决策。
- **有变化**：相同敌人在不同洗牌与地形下不会完全按脚本重复。
- **可干涉**：玩家不只承受攻击，还能影响敌人下一轮会如何出牌。
- **可读性优先**：不要求玩家记住敌人整套牌库才能做出合理选择。
- 敌人也拥有牌局节奏：每回合三牌顺序执行构成可阅读的行动组合。
- 首领需要最低行动保障，避免玩家彻底锁死首领。

## 3. 详细设计

### 3.1 核心规则

#### 敌方牌区

建议每个主要敌人拥有以下数据：

| 区域/信息 | 对玩家是否公开 | 说明 |
| --- | --- | --- |
| 敌人牌库构成摘要 | 部分公开 | 遭遇开始时显示关键词，例如「冲撞 / 燃烧 / 防守」 |
| 抽牌堆 | 数量公开，顺序隐藏 | 首领可通过阶段改变牌库 |
| 当前意图手牌 | 公开且有序 | 展示敌方下一敌人回合准备依次打出的`3`张牌、顺序及目标范围 |
| 弃牌堆 | 可查看 | 玩家可判断危险牌多久可能再次出现 |
| 消耗/封印区 | 公开 | 记录被永久处理或阶段性禁用的敌方牌 |

普通敌人应使用规则清晰、易于读懂的小型个人牌组；首套哥布林牌组为`9`张，以支持每回合`3`张牌的连续行动节奏。精英和首领应拥有更鲜明的牌组循环。

#### 敌方执行流程

```text
敌方意图生成：每个敌人从自己的牌组抽取 3 张牌，并公开有序意图
  -> 玩家回合读取威胁并做出响应
  -> 敌方执行公开意图：按抽牌顺序依次打出这 3 张牌
  -> 已打出、未执行或被打断的牌分别进入对应牌区
  -> 敌方生成下一轮可见意图
```

确定规则：

- 每个敌人每回合从自己的卡组中抽取`3`张牌。
- 敌人在该敌方执行窗口内按照抽牌顺序依次打出抽到的`3`张牌。
- 为使玩家能针对敌方牌局移动和出牌，对应敌方回合将执行的三张牌应作为有顺序的公开意图，在其执行前展示给玩家。
- 战斗开始时先为第一轮敌方回合生成并公开三牌意图，再给予玩家先手。
- 抽牌堆不足`3`张时，立即将弃牌堆洗回抽牌堆，并继续补抽至`3`张或牌堆完全无牌。
- 某张牌因没有合法目标、路径被阻挡或被状态打断而无法生效时，仍视为打出该牌，但无效果，随后进入弃牌堆并继续执行后续牌。
- 所有敌人都拥有「抽牌堆抽光时」触发的专属增益效果。该效果视为打出一张特殊卡牌，用于后续触发「敌方打牌」「特殊牌打出」等相关机制。
- 抽牌过程中每当抽取使抽牌堆变为空时，立即触发该敌人的抽空增益；若还需要继续补抽，则在触发后洗回弃牌堆并继续抽牌。

#### 玩家与敌人「打牌」的交互类型

| 交互方式 | 规则概念 | 示例 |
| --- | --- | --- |
| 躲避 | 离开意图攻击覆盖区 | 敌人展示直线突进，玩家移出直线 |
| 阻挡 | 通过防御或地形使牌收益降低 | 骑士升起掩体挡住射线 |
| 诱导 | 改变敌人位置或可选目标 | 嘲讽后将重击引向高格挡角色 |
| 打断 | 满足条件后取消公开意图 | 眩晕敌人，使其蓄力攻击进入弃牌堆 |
| 污染牌组 | 向敌方牌堆加入弱化牌/状态牌 | 向敌人弃牌堆塞入「卡壳」 |
| 窃取/复制 | 获得敌人牌的临时友方版本 | 精英掉落或职业特色机制 |
| 强迫出牌 | 令敌人提前在不佳位置执行牌 | 诱发冲撞撞墙或提前引爆区域 |

#### 抽空牌堆增益

| 规则项 | 说明 |
| --- | --- |
| 触发时机 | 敌人抽牌时，抽取动作使抽牌堆从非空变为空 |
| 表现归类 | 视为敌人打出一张特殊卡牌 |
| 牌区处理 | 默认不加入普通抽牌堆、弃牌堆或消耗牌堆，除非敌人条目另行说明 |
| 效果来源 | 由具体敌人条目定义，例如哥布林为`力量+3` |
| 多次触发 | 每次抽牌堆被抽空都可触发 |

#### 玩家塞入的状态牌（MVP）

| 规则项 | 说明 |
| --- | --- |
| 入口 | 战士 **塞牌** 体系 `敌方塞牌`；牌面指定塞入 **抽牌堆** |
| 卡壳 | MVP 默认 token：**卡壳** — 抽到时 **无效果**，立即进入敌方 **弃牌堆**，不占用意图槽 |
| 洗牌 | 塞入后若需洗牌，按敌方抽牌堆规则洗入 |
| 首领抗性 | 首领可 Post-MVP 增加「塞牌 −1 张」；MVP 酋长不免疫 |

与 [`Feature-战士体系-塞牌.md`](../职业系统/战士/Feature-战士体系-塞牌.md)、[`Foundation-卡牌词缀与效果语义.md`](../设计规范/Foundation-卡牌词缀与效果语义.md) 一致。

### 3.2 状态与流转

| 阶段 | 行为 |
| --- | --- |
| 意图生成 | 抽`3`张并公开顺序 |
| 玩家回合 | 玩家响应威胁 |
| 意图执行 | 按顺序依次打出 |
| 牌区更新 | 弃牌/保留/消耗 |
| 下一轮准备 | 重新生成意图 |

### 3.3 与其他系统的交互

| 类型 | 主要内容 |
| --- | --- |
| 上游依赖 | 战场位置、敌人模板、敌方牌组、状态效果、地形约束、遭遇编排 |
| 系统产出 | 敌方公开意图、敌方执行结果、敌方牌区变化、敌人压迫节奏 |
| 下游影响 | 玩家移动与出牌决策、打断与诱导选择、遭遇难度表现 |

## 4. 边界情况

- **若干涉敌方牌组的卡牌过多**：需控制数量与费用，首领保留抗性、阶段解锁或每轮最低行动保障。
- **若未来加入群体 AI、共享敌方资源或反制逻辑**：需另建子文档，不塞进遭遇文档。
- **信息公开应足够支撑规划，但不能让所有风险完全静态化**。

## 9. 验收标准

- **GIVEN** 战斗开始，**WHEN** 初始化完成，**THEN** 第一轮敌方三牌意图已公开且玩家获得先手。
- **GIVEN** 敌方意图已公开，**WHEN** 敌方执行窗口开始，**THEN** 按公开顺序依次打出`3`张牌。
- **GIVEN** 抽牌使抽牌堆变空，**WHEN** 该敌人有抽空增益定义，**THEN** 立即触发并将效果视为特殊牌打出。
