## 1. 敌人定位

夺心魔是 **第一章章末首领备选型**，主题 **读心、塞牌、触手控位、邻格处决**——与酋长「撞障/地形」形成对照：玩家须管理 **手牌污染**、**意图可读性** 与 **被复制出牌** 的风险。

**与酋长差异（设计意图）**

| 维度 | 部落酋长 | 夺心魔 |
| --- | --- | --- |
| 主轴 | 障碍/残骸/冲撞 | 复制出牌、眩晕 token、触手拉拽 |
| 威胁距离 | 邻格 + 直线冲撞 | 射程 2 鞭挞 + **邻格 50** 处决 |
| 玩家对策 | 破障、站位、撞障收益 | 少打关键牌、清手牌、杀触手、避免贴脸 |

## 4. 核心卡牌规则

### 4.1 思维窃取

| 字段 | 规则 |
| --- | --- |
| 追踪对象 | 夺心魔 **主目标** 玩家（目标选择见 §6） |
| 追踪窗口 | **上一完整玩家回合**（自该玩家回合开始至结束） |
| 记录条件 | 该玩家每 **打出并结算** 1 张 **`类别=攻击` 或 `技能`** 的牌，覆盖写入 `lastMirroredCard`；**能力 / 行动** **不** 记录 |
| 执行 | 复制 `lastMirroredCard` 的 **牌面效果** 并 **立即结算**（目标按夺心魔 AI：攻击类优先打玩家方；技能类按牌面目标语义，对玩家不利方向解析） |
| 失败 | 本回合主目标 **未** 打出过攻击/技能 → 视为打出但 **无效果**，进弃牌堆 |
| 意图展示 | 显示「思维窃取」+ 若已可预判则展示 **将被复制的牌名**（玩家回合结束后更新） |

**设计备注**：鼓励玩家在有「思维窃取」意图时 **先打无害牌** 或 **控费不打**；与遮蔽组合提高读意图成本。

### 4.2 触手牵引

| 字段 | 规则 |
| --- | --- |
| 召唤 | 在夺心魔 **距离 1~2** 内 **2** 个 **不同空格** 各生成 **1** 只 **心灵触手**（见 §4.3） |
| 失败 fallback | 合法空格不足时，每少召唤 1 只，夺心魔 **+3** 格挡 |
| 意图展示 | 显示预计召唤落点 +「下回合拉拽」提示 |

### 4.3 召唤物：心灵触手

| 字段 | 值 |
| --- | --- |
| 生命 | **8**（可调） |
| 牌组 / 意图 | **无**；不参与夺心魔抽牌 |
| 占位 | 占用格子；不可穿过 |
| 行动时机 | **下一次敌方回合开始**、夺心魔按意图槽执行 **之前**，进入 **触手阶段** |
| 行动 | 按触手 **ID 顺序** 轮流：对 **距离内最近** 的玩家尝试 **拉拽 1**（向触手方向）；**本触手阶段全局最多成功 3 次** 拉拽后停止 |
| 中断 | 触手死亡不再行动；拉拽撞 **障碍/残骸/深坑** 按 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md) 与地形 Feature |
| 上限 | 场上触手 **≤ 4**；达上限时「触手牵引」仍 **+3** 格挡 fallback |

### 4.4 精神震爆 · 眩晕牌（玩家 token）

**眩晕牌**（非单位 debuff「眩晕」，见词条登记 §5）：

| 字段 | 值 |
| --- | --- |
| 牌面标签 | `眩晕` |
| 类别 | **状态**（玩家侧 token） |
| 词缀 | **虚无** |
| 费用 | **0** |
| 打出 | **无卡牌效果**；正常进入 **弃牌堆** |
| **虚无 override** | 玩家回合结束时若仍在手牌 → 移入 **消耗堆**（自本场移除；**不** 走 Foundation 默认进弃牌堆） |
| 塞入 | 「精神震爆」加入目标 **弃牌堆**（洗入规则同塞牌）；抽到时入手 |

> 与 **恐惧牌**（敌方 token）不同：眩晕牌污染 **玩家** 牌循环并占用手牌位。

### 4.5 抽取心智

| 字段 | 规则 |
| --- | --- |
| 范围 | **邻格 1** |
| 伤害 | **50** |
| 意图 | 高威胁；Presentation 需 **醒目** 邻格预览 |
| P2 | 入池后玩家需优先 **飘移/杀触手/格挡** 避免贴脸 |

## 5. 槽位与意图规则（首领）

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **首领** |
| `每回合槽位` | **4** |
| `槽位模板` | `移动`, `攻击`, `自由`, `自由` |
| `意图抽牌规则` | **移动/攻击槽**：引用 Pattern_ApproachStrike；**攻击槽** 内「抽取心智」按 **邻格** 判定是否在攻击范围。**两自由槽**：随机 1 张；抽 **技能** 时 **50%** 优先「思维窃取 / 触手牵引 / 遮蔽」（均匀）；P2「精神震爆」权重 +1 |
| `意图执行规则` | **引用** Pattern_Ranged，**override**：攻击范围内有「抽取心智」时 **邻格优先** 判定；**两自由槽** 在移动/攻击槽 **之后** 按槽序执行 |
| `攻击范围判定` | 默认 **射程 2**（鞭挞）；「抽取心智」「精神震爆（对主目标）」按各自牌面 |

**触手阶段** 在 §4.3，**不占用** 意图槽。

## 6. 主目标与复制 AI

| 规则 | 说明 |
| --- | --- |
| 主目标 | 每回合敌方意图生成时：生命值 **最低** 的玩家；并列则 **距离最近**；再并列 **随机** |
| 思维窃取 | 仅复制 **主目标** 的 `lastMirroredCard` |
| 精神震爆 | 仅对 **主目标** 造成伤害与塞牌 |
| 联机 | 触手拉拽可对 **任意** 距离内玩家；拉拽次数仍全局 3 次 |

---

## 7. 与障碍 / 残骸交互

| 情况 | 处理 |
| --- | --- |
| **障碍** 阻挡 LOS | 「心灵鞭挞」遵循 Core §视线 |
| 触手 / 拉拽 | 撞 **障碍** 停步；穿 **残骸** 不穿透（触手为实体单位格） |
| 玩家 copied 位移 | 若复制玩家 **行动** 类（不应被记录）— 不适用 |

## 9. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「遮蔽」 | 仅 UI 隐藏牌名；执行不变 |
| 复制 **消耗** 牌 | 复制效果结算；**不** 复制消耗/移牌区行为（仅效果镜像） |
| 复制带 **位移** 的攻击 | 夺心魔 **不** 移动；仅伤害/状态按牌面结算 |
| 主目标切换 | `lastMirroredCard` **清空** |
| 触手阶段与意图 | 先触手阶段，再夺心魔 4 槽 |
