## 1. 敌人定位

夺心魔是 **精英 / 首领级控制** 敌人：向玩家 **塞牌**、**遮蔽意图** 与 **心灵鞭挞** 远程施压，呼应战士 **塞牌体系** 的镜像对抗。

## 2. 五维定位

| 维度 | 当前表现 | 设计说明 |
| --- | --- | --- |
| 输出 | 中 | 「心灵鞭挞」「吞噬思维」 |
| 生存 | 中 | 「灵能盾」 |
| 移动 | 低中 | 「飘移」微调距离 |
| 费用 | 无专属卡牌 | — |
| 抽牌运转 | 高 | 牌组含多张 **干扰** 技能；抽空底牌大规模塞牌 |

## 3. 牌组构成

夺心魔牌组共 `12` 张牌：

| 卡牌名称 | 类别 | 数量 | 主要维度 | 效果 |
| --- | --- | ---: | --- | --- |
| 心灵鞭挞 | 攻击 | 3 | 输出 | **射程 2** **7** 点伤害 |
| 吞噬思维 | 攻击 | 2 | 输出 + 干扰 | **射程 2** **4** 点伤害；目标抽牌堆 **+1** **恐惧牌** |
| 飘移 | 行动 | 2 | 移动 | 远离最近敌人 **1** 格 |
| 灵能盾 | 技能 | 2 | 生存 | **10** 格挡 |
| 遮蔽 | 技能 | 1 | 干扰 | 随机 **1** 个公开 **意图槽** 显示为 **？**（仍按原牌执行） |
| 低语 | 技能 | 1 | 干扰 | 全体玩家抽牌堆各 **+1** **恐惧牌** |
| 支配 | 能力 | 1 | 规则 | 每 **3** 回合开始对随机玩家 **+2** 恐惧牌（首回合不触发） |
| 合计 | 12 | 输出、干扰、生存 | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **精英**（3 槽）或 **首领**（4 槽，Content） |
| `每回合槽位` | **3**（精英）或 **4**（首领） |
| `槽位模板` | 精英：`移动`, `攻击`, `自由`；首领：`移动`, `攻击`, `自由`, `自由` |
| `意图抽牌规则` | **引用** Pattern_ApproachStrike + **自由** 槽随机；首领第 4 槽 **50%** 优先 **技能**（干扰牌） |
| `意图执行规则` | **引用** Pattern_Ranged（攻击范围 **射程 2**） |
| `攻击范围判定` | **射程 2**（「心灵鞭挞」「吞噬思维」） |

**首领 override**：HP 阶段二可改为固定槽序 **攻击 → 自由 → 自由 → 移动**（条目内联，Post-MVP 细化）。

## 5. 与高台 / 废墟交互

| 情况 | 处理 |
| --- | --- |
| **高台** 阻挡 LOS | 「心灵鞭挞」等 **直线/射程** 攻击遵循 [`Core-六边形战斗规则.md`](../战斗系统/Core-六边形战斗规则.md) §视线 |
| **废墟** | 无专属互动；玩家可借 **废墟** 后打箱换拾取 |
| 塞牌 | 恐惧牌规则见 [`Feature-敌人牌组与意图机制.md`](Feature-敌人牌组与意图机制.md) §3.1.1 |

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 心灵风暴 |
| **类别** | **技能** |
| 效果类型 | 对玩家干扰 |
| 触发时机 | 抽牌堆抽空 |
| 效果 | 全体玩家抽牌堆各 **+2** **恐惧牌**；夺心魔获得 **3** 点格挡 |
| 牌区处理 | 视为打出特殊牌 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「遮蔽」 | 仅 UI 隐藏牌名；执行不变 |
| 无 **射程 2** 目标 | 攻击牌无效果，进弃牌堆 |
| 首领 **4** 槽 | 槽位模板长度须 = **4** |
