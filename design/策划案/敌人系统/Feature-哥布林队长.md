## 1. 敌人定位

哥布林队长是第一章 **唯一精英**，检验玩家构筑是否能在持续压力下成立。

**循环危险点**：每 2 回合发动「战吼」获得力量并召唤 1 只哥布林随从（共用哥布林 AI，低生命）。

**两种破解路径**：

1. **爆发路线**：快速击杀队长，忽略随从。
2. **控场路线**：用格挡/束缚/撞墙处理随从，拖延战吼叠层。

## 2. 五维定位

| 维度 | 表现 | 说明 |
| --- | --- | --- |
| 输出 | 中高 | 邻格打击 + 力量成长 |
| 生存 | 中 | 生命高于普通哥布林（数值见平衡验证） |
| 移动 | 基础 | 接近 + 网索（束缚） |
| 费用 | 节奏 | 战吼为特殊节奏牌 |
| 抽牌运转 | 中 | 12 张牌循环，每回合 3 张 |

## 3. 牌组构成

| 卡牌名称 | 数量 | 效果 |
| --- | ---: | --- |
| 打击 | `3` | 邻格 `6` 伤 |
| 接近 | `3` | 移动 1 |
| 网索 | `2` | 对距离 2 内目标施加 `1` 层束缚 |
| 战吼 | `2` | 获得 `2` 力量；召唤 1 只哥布林（生命 15，使用 [`Feature-哥布林.md`](Feature-哥布林.md) 牌组） |
| 格挡 | `2` | 获得 `8` 点格挡（敌方格挡语义同玩家格挡） |
| 合计 | `12` | — |

## 4. 特殊规则

| 规则 | 内容 |
| --- | --- |
| 战吼间隔 | 两次战吼之间至少间隔 1 回合（即不能连续两回合各打一张战吼） |
| 召唤上限 | 场上哥布林随从最多 2 只；达上限时战吼仍获得力量但不召唤 |
| 随从目标 | 随从独立选目标，AI 同普通哥布林 |

## 5. 意图展示

- 战吼：显示「力量 +2」与是否召唤（含召唤位已满提示）。
- 网索：显示目标与束缚层数。
- 三牌序列按序展示，与通用敌人规则一致。
