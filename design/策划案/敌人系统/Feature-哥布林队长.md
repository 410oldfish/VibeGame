## 1. 敌人定位

哥布林队长是第一章 **唯一精英**，检验玩家构筑是否能在持续压力下成立。

**循环危险点**：每 2 回合发动「战吼」获得力量并召唤 1 只哥布林随从（共用哥布林 AI，低生命）。

**两种破解路径**：

1. **爆发路线**：快速击杀队长，忽略随从。
2. **控场路线**：用格挡/束缚/撞墙处理随从，拖延战吼叠层。

## 2. 五维定位

| 维度 | 表现 | 说明 |
| --- | --- | --- |
| 输出 | 中高 | 邻格打击 + 力量成长 |
| 生存 | 中 | 生命高于普通哥布林（数值见平衡验证） |
| 移动 | 基础 | 接近 + 网索（束缚） |
| 费用 | 节奏 | 战吼为特殊节奏牌 |
| 抽牌运转 | 中 | 14 张牌循环；抽空打出底牌「增援」 |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **精英** |
| `每回合槽位` | **3** |
| `槽位模板` | `移动`, `攻击`, `自由` |
| `意图抽牌规则` | **移动/攻击槽**：引用 Pattern_ApproachStrike 抽法；**自由槽**：从剩余抽牌堆 **随机** 1 张 |
| `意图执行规则` | **移动/攻击槽**：引用 Pattern_ApproachStrike 距离重排（邻格 1）；**自由槽**：在移动/攻击结算 **之后** 按槽序执行 |

## 5. 特殊规则

| 规则 | 内容 |
| --- | --- |
| 战吼间隔 | 两次战吼之间至少间隔 1 回合（即不能连续两回合各打一张战吼） |
| 召唤上限 | 场上哥布林随从最多 2 只；达上限时战吼仍获得力量但不召唤 |
| 随从目标 | 随从独立选目标，AI 同普通哥布林 |

## 6. 意图展示

- 战吼：显示「力量 +2」与是否召唤（含召唤位已满提示）。
- 网索：显示目标与束缚层数。
- **3 个意图槽** 按槽位标签展示；若条目引用 Pattern 执行规则，UI **可选** 标注移动/攻击预计顺序。
- 底牌「增援」在抽牌抽空瞬间弹出，不占用意图槽。

## 7. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 增援 |
| 效果类型 | 召唤 |
| 触发 | 抽光抽牌堆 |
| 效果 | 若场上哥布林随从 **< 2**，召唤 1 只哥布林（生命 15，牌组同 [`Feature-哥布林.md`](Feature-哥布林.md)） |
| 失败 fallback | 随从已达上限时，改为获得 `1` 层力量 |
