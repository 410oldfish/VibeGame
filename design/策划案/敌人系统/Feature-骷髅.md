## 1. 敌人定位

骷髅是 **`bone_pile`** 召唤的 **迷你单位**：**1 槽**、低生命、固定邻格打击，用于填充战场密度而不单独作为遭遇主角。

## 2. 五维定位

| 维度 | 表现 | 说明 |
| --- | --- | --- |
| 输出 | 基础 | 邻格「骨击」 |
| 生存 | 极低 | HP **12**（Content 可调） |
| 移动 | 基础 | 「蹒跚」接近 |
| 费用 | — | 敌人无能量约束 |
| 抽牌运转 | 低 | 8 张短循环；抽空底牌「散骨」 |

## 3. 牌组构成（8 张）

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 骨击 | 攻击 | 4 | 输出 | 爆发 | 邻格 **6** 点伤害 |
| 蹒跚 | 行动 | 3 | 移动 | 接近 | 朝最近敌人移动 **1** |
| 骨盾 | 技能 | 1 | 生存 | 拖战 | 获得 **4** 点格挡 |
| 合计 | 8 | — | — | — | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **召唤物**（不单独遭遇） |
| `每回合槽位` | **1** |
| `槽位模板` | `攻击` |
| `意图抽牌规则` | **引用** [`Pattern_Stationary`](Feature-敌人牌组与意图机制.md) §3.1（仅 **1** 槽；抽 **攻击** 优先，否则 **行动/技能**） |
| `意图执行规则` | **引用** Pattern_Stationary |
| `攻击范围判定` | **邻格 1** |

## 5. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 散骨 |
| **类别** | **能力** |
| 效果类型 | 自我减益 |
| 触发 | 抽光抽牌堆 |
| 效果 | 骷髅 **−4** 生命（不可低于 **1**）；若仍存活，下回合 **+2** 力量 |
| 牌区处理 | 视为打出特殊牌 |

## 6. 与构筑物交互

| 情况 | 处理 |
| --- | --- |
| **`bone_pile`** 移除 | 同格或邻格空格 **spawn** 1 只骷髅 |
| 场上骷髅上限 | Content 默认 **4**；达上限时 **不** 再召唤 |
| **残骸** / **障碍** | 蹒跚 **不可穿**；骨击需邻格 |

## 7. 已确认执行规则

| 情况 | 处理 |
| --- | --- |
| 「骨击」无邻格目标 | 无效果，进弃牌堆 |
| 「蹒跚」已邻接 | 无效果，进弃牌堆 |
| 召唤时格子被占 | 尝试 **邻格** 空格；均失败则 **不** 召唤 |

## 8. 原型验证用途
