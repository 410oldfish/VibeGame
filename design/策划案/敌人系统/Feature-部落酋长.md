## 1. 敌人定位

部落酋长是 **第一章章末首领**，总结「破阵与站位」主题：利用墙体/深坑与 **撞墙收益** 形成压迫，要求玩家主动改写站位而非纯对砍。

**阶段划分（MVP 简化两阶段）**

| 阶段 | 生命阈值 | 行为变化 |
| --- | --- | --- |
| P1 | 100%–51% | 冲撞、重击、偶发「稳固」自保 |
| P2 | 50%–0% | 加入「震地」：对邻格全体伤害 + 破坏 1 格墙体变为残骸 |

## 2. 牌组构成（15 张）

| 卡牌名称 | 数量 | 效果 |
| --- | ---: | --- |
| 重击 | `4` | 邻格 `10` 伤 |
| 冲撞 | `3` | 直线推进 1，碰撞目标额外 `6` 伤；若撞墙额外 `4` 伤 |
| 稳固 | `2` | 获得 `2` 层稳固 |
| 战鼓 | `2` | 获得 `3` 力量 |
| 震地 | `2` | **P2 才加入抽牌池**；邻格全体 `5` 伤；随机 1 邻格墙体变残骸 |
| 接近 | `2` | 移动 1 |
| 合计 | `15`（P1 有效 13，P2 替换 2 张接近为震地） | — |

## 3. 机制职责

- **冲撞 + 墙体/深坑**：迫使玩家规划落点，与战士撞墙/深坑构筑形成镜像对抗。
- **稳固**：限制击退流无脑解场。
- **P2 震地**：总结章节地形主题，破坏墙体改变战场。
