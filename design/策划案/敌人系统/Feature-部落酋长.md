## 1. 敌人定位

部落酋长是 **第一章章末首领**，总结「破阵与站位」主题：利用 **障碍/残骸/深坑** 与 **撞障碍收益** 形成压迫，要求玩家主动改写站位而非纯对砍。

**阶段划分（MVP 简化两阶段）**

| 阶段 | 生命阈值 | 行为变化 |
| --- | --- | --- |
| P1 | 100%–51% | 冲撞、重击、偶发「稳固」自保 |
| P2 | 50%–0% | 加入「震地」：对邻格全体伤害 + 随机 **1** 格 **障碍** 变为 **`propId: wood_crate`**（HP **4**） |

## 3. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `遭遇类型` | **首领** |
| `每回合槽位` | **4** |
| `槽位模板` | `移动`, `攻击`, `自由`, `自由` |
| `意图抽牌规则` | **移动/攻击槽**：引用 Pattern_ApproachStrike；**两自由槽**：各随机 1 张（可抽出稳固、战鼓、震地 P2 等） |
| `意图执行规则` | **引用** Pattern_ApproachStrike 重排移动/攻击（邻格 1；冲撞/重击按攻击槽牌距离）；**两自由槽** 在移动/攻击 **之后** 按槽序依次执行 |
| 阶段 | P2 牌池加入「震地」见 §2 牌组表；**意图规则 ID 不变** |

## 4. 机制职责

- **冲撞 + 障碍/残骸/深坑**：迫使玩家规划落点，与战士撞障碍/深坑构筑形成镜像对抗。
- **稳固**：限制击退流无脑解场。
- **P2 震地**：总结章节地形主题，将 **障碍** 转为可互动 **残骸** 并可能掉落拾取物。
