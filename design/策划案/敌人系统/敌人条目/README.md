## 分类标准

1. 已有可运行的敌人定义、牌组和关键行为实现。
2. 已接入非 Debug 的正式冒险遭遇流程。
3. 已有对应的验证记录或测试证据。

敌人只有在“实现完成、正式遭遇接入、关键验收通过”三项均满足后，才从“未投入使用或未完成实现”移动到“已投入使用并实现”。仅存在卡牌资源、数据库定义或 Debug 沙盒不视为正式投入使用。
