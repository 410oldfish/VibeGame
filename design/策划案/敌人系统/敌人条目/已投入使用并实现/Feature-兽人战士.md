## 1. 敌人定位

兽人战士是第一层 **2 级普通怪物**，以可预览的 **直线冲锋 → 命中 → 击退** 制造站位压力。它不能单独生成，必须与至少 1 只 1 级杂兵共同出现。

## 2. 五维定位

| 维度 | 表现 | 说明 |
| --- | --- | --- |
| 输出 | 中 | 冲锋命中 **8** 点伤害；邻格重斩 **7** 点伤害 |
| 生存 | 中 | 基础生命 **22**；架势获得 **6** 点格挡 |
| 移动 | 高 | 直线最多推进 **3** 格，命中后击退目标 |
| 费用 | 无专属牌 | 敌人不受玩家能量约束 |
| 抽牌运转 | 中 | 10 张常规牌组；抽空触发底牌「再度冲阵」 |

## 3. 牌组构成（10 张）

| 卡牌名称 | 类别 | 数量 | 施压维度 | 子维度 | 效果 |
| --- | --- | ---: | --- | --- | --- |
| 直线冲锋 | 攻击 | 4 | 移动 / 输出 | 直线 / 击退 | 沿六方向之一最多推进 **3** 格；命中首个玩家时造成 **8** 点伤害并击退 **1** 格 |
| 重斩 | 攻击 | 3 | 输出 | 爆发 | 对邻格目标造成 **7** 点伤害 |
| 逼近 | 行动 | 2 | 移动 | 接近 | 朝主目标移动 **1** 格 |
| 架势 | 技能 | 1 | 生存 | 防御 | 获得 **6** 点格挡 |
| 合计 | — | 10 | — | — | — |

## 4. 槽位与意图规则

| 字段 | 值 |
| --- | --- |
| `敌人等级` | **2 级** |
| `基础生命` | **22** |
| `遭遇类型` | **普通** |
| `生成限制` | 每场生成 **1～2** 只；至少搭配 **1** 只 1 级杂兵 |
| `底牌资格` | **有**（2 级及以上） |
| `每回合槽位` | **2** |
| `槽位模板` | `移动`, `攻击` |
| `意图模式` | `Pattern_LineCharge` |
| `主目标` | 距离最近的玩家；并列时按稳定目标 ID |

抽牌规则：

- **移动槽**：优先抽「逼近」；没有行动牌时抽「架势」；仍无牌则随机抽 1 张非攻击牌。
- **攻击槽**：存在合法直线冲锋目标时优先抽「直线冲锋」；已经邻接主目标时可抽「重斩」；均不满足时仍可公开「直线冲锋」，但执行时使用失败回退。
- 意图预览必须显示冲锋方向、途经格、预计命中目标、击退方向和预计落点。

## 5. 直线冲锋结算

1. 从兽人战士所在格的六个直线方向中，寻找距离 **1～3** 且路径无单位、障碍或深坑阻断的玩家。
2. 有多个合法目标时，选择距离最近者；再并列时按稳定目标 ID。
3. 兽人战士移动至目标前一格并停止，不与目标重叠。
4. 对命中目标造成 **8** 点伤害，再沿冲锋方向击退 **1** 格。
5. 击退落点及构筑物碰撞遵循六边形战斗与地形通用规则；本牌不额外附加碰撞伤害。
6. 执行时若已没有合法直线目标，改为朝当前主目标 **逼近 1 格**，不造成伤害和击退；该牌仍进入弃牌堆。

## 6. 底牌

| 字段 | 内容 |
| --- | --- |
| 底牌名称 | 再度冲阵 |
| **类别** | **能力** |
| 效果类型 | 自我增益 |
| 触发时机 | 抽牌使抽牌堆变为空 |
| 效果 | 获得 **1 层冲阵强化**：下一张成功命中的「直线冲锋」伤害 **+2**、击退距离改为 **2**，随后移除 |
| 叠加规则 | 最多 **1 层**；已有时刷新，不叠加 |
| 牌区处理 | 视为打出特殊牌，不进入常规牌区 |

## 7. 边界与失败处理

| 情况 | 处理 |
| --- | --- |
| 直线路径被障碍、深坑或单位截断 | 截断点之后的目标不合法 |
| 目标在执行前离开冲锋线 | 使用失败回退：逼近 1 格，不攻击 |
| 目标无法被击退 | 仍承受冲锋伤害；击退按通用失败规则处理 |
| 强化冲锋执行失败回退 | 不消耗冲阵强化，保留至下一次成功命中 |
| 场上没有玩家目标 | 当前意图无效果并进入弃牌堆 |

## 8. 原型验证用途

| 观察项 | 用途 |
| --- | --- |
| 冲锋路径与击退落点是否一眼可读 | 验证意图预览 |
| 玩家主动离开直线的比例 | 验证站位压力 |
| `1 兽人 + 2 杂兵` 与 `2 兽人 + 1 杂兵` 的难度差 | 验证正常池权重 |
| 强化冲锋击退 2 是否过强 | 验证底牌循环压力 |
