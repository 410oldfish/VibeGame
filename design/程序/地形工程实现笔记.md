## 分层

| 层 | 代码类型 | 说明 |
| --- | --- | --- |
| Zone | `HexTerrainZoneType` | `Normal` / `Pit` … 地面属性 |
| Structure | `HexTerrainStructureType` | `None` / `Barrier` / `Ruin` |
| Prop | `propId` + `HexPropDefinition` | Content 实例 |
| Overlay | `HexTileEffectState` | 临时覆盖 |

## Tile MVC

- `TileModel`：纯数据（zone、structure、prop 字段、effects）
- `TileView`：结构形态 + Ruin HP 条
- `TileController`：`SetProp` / `CanEnter` / `DamageStructure` / LOS 等 API
- `HexTile`：MonoBehaviour 兼容壳 + `IHexAttackTarget`

## 调试入口

- 场景：`Assets/Scenes/BattleSandbox.unity`
- Scenario：`Resources/Debug/BattleSandbox_Default.asset`
- Bootstrap：`HexBattleSandboxBootstrap`（`HexGameModule` 对 BattleSandbox 跳过冒险引导）

## 攻击目标

- `IHexAttackTarget`：单位与可攻击 Ruin 统一标识
- 玩家单体攻击可指定空 Ruin 格

## Prop 效果

- 配置表全量登记图鉴可映射 `propId`
- 运行时 `PropEffectStub`：`field_pickup` 桥接现有拾取；其余 stub 日志
