# Game Design System

Use the shared studio workflow at `../ccgs-vibegame-studio`.

1. Read `../ccgs-vibegame-studio/SKILL.md`.
2. Read `../ccgs-vibegame-studio/references/workflow-catalog.md`, Systems Design Workflow.
3. Read `../ccgs-vibegame-studio/references/document-templates.md`, System GDD.
4. Read `../ccgs-vibegame-studio/references/role-review-checks.md` when the system affects multiple disciplines.
5. Inspect existing GDDs, source, prefabs/scenes, and related implementation before writing.
6. Produce or update a GDD with goal, player behavior, rules, data/tuning, feedback, edge cases, dependencies, acceptance criteria, and QA notes.

When design implies Unity assets, scenes, prefabs, or editor changes, route through the Unity execution rules first.
