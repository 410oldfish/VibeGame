# Game Dev Story

Use the shared studio workflow at `../ccgs-vibegame-studio`.

1. Read `../ccgs-vibegame-studio/SKILL.md`.
2. Read `../ccgs-vibegame-studio/references/workflow-catalog.md`, Dev Story Workflow and Epics, Stories, Sprint Workflow.
3. Read `../ccgs-vibegame-studio/references/document-templates.md`, Story and QA Plan.
4. Read linked GDDs, ADRs, code, scenes, prefabs, ScriptableObjects, and assets before implementing.
5. Keep scope small and trace each change to acceptance criteria.
6. For Unity asset or editor work, read `../ccgs-vibegame-studio/references/unity-project-execution.md`.
7. Verify with tests, compile/build output, asset inspection, screenshots, logs, or performance numbers.

Update the story evidence when the project tracks status in `production/`.
