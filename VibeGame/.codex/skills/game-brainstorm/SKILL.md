# Game Brainstorm

Use the shared studio workflow at `../ccgs-vibegame-studio`.

1. Read `../ccgs-vibegame-studio/SKILL.md`.
2. Read `../ccgs-vibegame-studio/references/workflow-catalog.md`, Concept Workflow.
3. Read `../ccgs-vibegame-studio/references/document-templates.md`, Concept Brief.
4. Inspect existing `design/`, `docs/`, `production/`, `Assets/Scripts`, and relevant Unity assets before proposing ideas.
5. Present 2-4 concept directions or refinements when the user has not already chosen one.
6. Produce or update a concise concept brief with pitch, player fantasy, pillars, anti-pillars, core loop, MVP, risks, and validation plan.

If the brainstorm leads to Unity work, load `../ccgs-vibegame-studio/references/unity-project-execution.md` before acting.
