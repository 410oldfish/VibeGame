# Document Templates

Use these lean templates when creating project artifacts. Keep documents concise and specific to the current feature.

## Concept Brief

```markdown
# [Feature/Game/Mode] Concept

## Elevator Pitch

## Player Fantasy

## Pillars

## Anti-Pillars

## Core Loop

## MVP Scope

## Stretch Scope

## Risks

## Validation Plan
```

## System GDD

```markdown
# [System] GDD

## Goal

## Player-Facing Behavior

## Rules

## Data and Tuning

## Feedback and Presentation

## Edge Cases

## Dependencies

## Acceptance Criteria

## QA Notes
```
